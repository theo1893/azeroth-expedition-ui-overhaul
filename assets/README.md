# 视觉资产说明

## `locked/`

这里保存当前唯一可用于后续实现和生图的视觉基准。

- `chat/`：聊天框游戏内基准和独立艺术母版。
- `quests/`：任务详情与任务追踪基准。
- `map/`：大地图与小地图基准。
- `character/`：角色属性面板 V3 基准。

早期探索图和过程对照已经从仓库移除。后续实现只能使用这里的锁定基准，不得从外部旧稿反向覆盖。

## `references/`

这里保存结构参考，而非可直接发布的运行时贴图。当前包含用户提供的 60 级香草角色面板截图；只参考截图左侧角色面板，右侧第三方插件区域不属于角色模块基准。

聊天模块 2026-07-29 的四张实机截图已归档到
`references/chat/session-2026-07-29/`，用于记录背景替换不足、pfUI
拖动与 Tab 闪烁、偏好的凌乱旧书风格以及被否决的过度规整版本。

## `source/chat/v3/`

这里保存聊天模块本轮可迁移的高分辨率透明母版、色键原始稿与
`440 × 320` 实装预览。它们是运行时贴图的确定性导出输入，目前仍属于
V3 候选，不等同于 `locked/` 中的最终视觉基准。

## 未来资源规则

- 无文字母版与运行时文字分离。
- 可平铺中心、边缘、角件与装饰覆盖层分离。
- 不覆盖原始装备、法术、任务或地图内容图层。
- 新文件必须标明模块、用途、状态和版本。
