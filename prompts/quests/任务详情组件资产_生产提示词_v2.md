## 美术基准继承

- 最高视觉权威是锁定任务详情图与
  [任务模块_视觉原型提示词_v1.md](任务模块_视觉原型提示词_v1.md) 的组合；
  后续每个独立批次都必须重新链接并提取该 provenance。
- 必须继承“正式公会双页卷宗”的物件身份、2004 年前后香草魔兽粗厚手绘
  轮廓、夸张体积、明确明暗切面、低饱和暖赭／烟褐／暗酒红／旧黄铜配色、
  左上暖光、统一磨损尺度与安静正文安全区。
- 每批只把上述 DNA 转译到自己持有的 runtime 对象；页码、书签、蜡封、
  黄铜件、按钮、滚动条、任务行和奖励槽必须由各自批次持有，不能从完整原型
  烘焙进其他背景。
- `assets/source/` 中的 QL-A1 母版只承担明确的结构或相邻材料职责，不能
  覆盖锁定基准的综合色感和绘制语言。
- `42%／58%` 是未来信息列，不是物理纸页宽度；正面 UI 与内部书页统一为
  正对玩家的浅俯视；冲突时按锁定图／原始 prompt、模块规范、全局基线、
  组件合同和次级 source 的职责裁决。

## 共同前缀

为 Turtle WoW 1.18.1 制作《魔兽世界》60 级香草时代视觉语言的手绘位图 UI
生产母版。模块身份是“冒险者公会任务卷宗”：正式展开的双页厚任务簿，与已
锁定的战地旧书聊天框来自同一批旧纸、深胡桃皮革、暗酒红皮革、氧化黄铜、
褪色织物和暗红蜡，但轮廓与装订方式不同。

保持 2004 年前后香草魔兽 UI 的粗重手绘轮廓、略夸张体积、温暖明暗分层和
可读的材料关系。不要照片级古董写实，不要现代网页 UI，不要《暗黑破坏神
3》式尖刺黑铁，也不要《上古卷轴 5》式极简文字菜单。

所有对象正面平视、无透视、光从左上方稳定照入。输出真正 RGBA 透明背景；
若执行器无法可靠生成透明背景，则只能使用完全均匀的纯 `#00FF00` 色键，
对象之间至少保留清晰空隙。不要添加投向背景的大面积环境阴影。

不得生成中文、英文、数字、伪文字、任务名称、按钮文字、物品图标、人物、
游戏场景或完整 HUD。文字和动态图标全部由游戏运行时绘制。

## 共同负面约束

- 禁止半透明黑色方块、玻璃面板、背景模糊、圆角卡片和胶囊按钮。
- 禁止单像素现代描边、霓虹外发光、镜面金属、宝石灯和科技纹样。
- 禁止骷髅、恶魔角、尖刺、黑铁牢笼、大型龙头、武器、翅膀和祭坛结构。
- 禁止把左右页面画成两张互不相关的矩形羊皮纸。
- 禁止把按钮、滚动条、任务行、奖励图标或文字烘焙进结构母版。
- 禁止状态之间改变对象尺寸、轮廓、锚点或光照方向。
- 禁止在状态画布中加入标签、编号、分隔文字或说明箭头。

## 执行块 QL-A1：空卷宗结构母版

对应组件：

- `QUEST.LOG.SHELL`
- `QUEST.LOG.LIST.PAPER`
- `QUEST.LOG.DETAIL.PAPER`

生成一件完全空白的“冒险者公会任务卷宗”结构母版，仅包含非交互材料：

- 横向展开的双页厚书，整体宽高比约 `1.45–1.50 : 1`。
- 左页约占内部阅读宽度 42%，右页约占 58%。
- 外层是深胡桃棕与暗酒红厚皮封面，四角有低调氧化黄铜包角。
- 四周和底部明确露出三至四层不齐整毛边书页。
- 中央有真实书脊、缝线、页缝压痕和深而柔和的接触阴影。
- 左页略暗，右页阅读纸面略亮；纸面中心保持安静。
- 左右外侧保留以后挂载织物书签、滚动条和书扣的净空。
- 底部只表现页叠与装订，不出现任何按钮或页码文字。

这是可确定性切成封皮边缘、四角、左右纸面、书脊和页叠的结构源母版，不是
最终整张 UI。所有任务行、标题、按钮、滚动条、蜡封、书签和奖励槽都必须
缺席。

验收：

- 不看文字仍明显是一本双页厚书。
- 中央书脊和多层页厚清楚可见。
- 左右正文安全区没有高对比污渍或装饰。
- 没有任何疑似可点击控件。

## 执行块 QL-B1：目录行与当前选择覆盖

对应组件：

- `QUEST.LOG.LIST.ROW`
- `QUEST.LOG.SELECTION`
- `QUEST.LOG.LIST.CHECK`
- `QUEST.LOG.REGION.TOGGLE`

生成一张透明状态画布，使用等宽等高、彼此留有透明间隔的规则单元格。不要
写状态名称。按从左到右顺序生成：

1. 普通任务行的几乎不可见浅压痕覆盖，只保留极轻微墨线。
2. 悬停任务行：纸张略暖、页边轻微抬起，无发光。
3. 按下任务行：轮廓不变，只让压痕略深、接触阴影收紧。
4. 禁用／不可用任务行：墨迹更淡，但纸张不变灰黑。
5. 未追踪小型空心墨圈。
6. 已追踪羽毛笔墨勾。
7. 当前任务暗酒红织物书签的选中状态。
8. 同一选中书签的悬停状态，边缘略抬起。
9. 同一选中书签的按下状态，阴影收紧。
10. 地区标题“已展开”箭头：普通。
11. 已展开箭头：悬停。
12. 已展开箭头：按下。
13. 已展开箭头：禁用。
14. 地区标题“已收起”箭头：普通。
15. 已收起箭头：悬停。
16. 已收起箭头：按下。
17. 已收起箭头：禁用。

前四个状态必须使用完全相同的长条几何；三个书签状态必须使用完全相同的
轮廓与尺寸；八个地区箭头状态也必须保持各自方向下的固定外接尺寸。选中语义
只由 `QUEST.LOG.SELECTION` 持有，`LIST.ROW` 不得再次烘焙书签。地区箭头
只绑定 `isHeader` 行，不得伪装成任务选择框。`QuestLogTitleNCheck` 是追踪
状态标记，不是独立的任务选择 Button。行覆盖不得形成独立卡片、完整边框或
不透明底色。

## 执行块 QL-B2：任务类型压印与任务状态蜡封

对应组件：

- `QUEST.LOG.TYPE.BADGE`
- `QUEST.LOG.STATE.SEAL`

生成一张透明图标图集。所有图标使用一致的正面平视、相同外接尺寸和相同视觉
重量，不带文字。按从左到右排列：

1. 普通任务：简洁羽毛笔墨印。
2. 精英任务：旧盾牌压印。
3. 地下城任务：石门／拱门压印。
4. 团队任务：小型暗红公会封印。
5. 限时任务：沙漏墨印。
6. 已完成：完整暗红蜡封。
7. 失败：破裂暗红蜡封。

压印使用深褐墨或纸面浅浮雕，蜡封才使用暗红色。图标必须在小尺寸下仍能辨认，
但不能像现代彩色技能图标，也不能包含骷髅、尖刺或发光。

## 执行块 QL-C2：关闭、操作与辅助按钮

对应组件：

- `QUEST.LOG.CLOSE`
- `QUEST.LOG.ACTION.ABANDON`
- `QUEST.LOG.ACTION.SHARE`
- `QUEST.LOG.ACTION.EXIT`
- `QUEST.LOG.TRACK`
- `QUEST.LOG.DETAIL.TOGGLE`
- `QUEST.LOG.LEVELS`

生成一张透明状态画布，按组件分组且每组状态轮廓完全相同：

1. 黄铜书扣式关闭按钮：普通、悬停、按下、禁用。
2. 横向厚皮革操作按钮：普通、悬停、按下、禁用；中心必须为空，供 runtime
   绘制“放弃／共享／关闭”等文字。
3. 追踪复选标记：空心墨圈、羽毛笔勾选、悬停、禁用。
4. 详情页收起／展开折页：向左普通、向左悬停、向左按下、向左禁用；向右四
   状态。
5. 任务等级显示复选框：未选、已选、悬停、禁用。

按钮保持香草魔兽式厚度，使用深胡桃皮革、暗酒红皮革和旧黄铜。不要写任何
文字，不要使用现代 `X` 圆形关闭键，不要通过外发光表达悬停。

## 执行块 QL-D：奖励槽与正文分隔

对应组件：

- `QUEST.LOG.REWARD.SLOT`
- `QUEST.LOG.DETAIL.DIVIDER`
- `QUEST.LOG.DETAIL.TITLE`（layout-only，不生成位图）
- `QUEST.LOG.DETAIL.DESCRIPTION`（layout-only，不生成位图）
- `QUEST.LOG.DETAIL.OBJECTIVES`（layout-only，不生成位图）
- `QUEST.LOG.DETAIL.REWARD_TEXT`（layout-only，不生成位图）

生成一张透明组件画布：

1. 只读奖励物品槽底：普通。
2. 同一槽的悬停覆盖。
3. 同一槽的按下覆盖。
4. 同一槽的禁用覆盖。
5. 正文短墨线的左端帽。
6. 可横向平铺的墨线中段。
7. 正文短墨线的右端帽。

奖励槽像压在任务凭证纸面上的小型皮革／黄铜凭证框，中心完全透明，不能生成
物品图标、品质颜色、数量或名称。按 `L` 打开的 `QuestLogItemN` 只负责查看
奖励，不承担 NPC 交付界面的奖励选择，所以本批不得生成“已选择奖励”状态；
选择覆盖只属于后续 `QUEST.DIALOG.ITEM.REWARD.SELECTION`。分隔线使用克制
的深褐墨迹，不带花哨金属横梁。

四个 `DETAIL.*` 文字区域只在 runtime layout 和中文可读性预演中登记，不得
为它们增加源画布单元、背景卡片或伪文字。

## 文件与执行记录要求

执行结果先进入 `generated/quests/<batch>/<version>/`。只有对象数量、顺序、
轮廓一致性、透明背景和小尺寸辨识全部通过，并经用户确认后，才能进入
`assets/source/quests/`。随后必须建立确定性 crop／atlas manifest，更新
本合同和 `OVERHAUL_TRACKER.md`；不得直接把生成图复制进 addon。
