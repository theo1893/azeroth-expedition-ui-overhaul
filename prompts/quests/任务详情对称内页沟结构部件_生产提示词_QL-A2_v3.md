## 组件合同

### 逻辑对象与数量

最终源画布必须恰好包含 `8` 组逻辑对象：

1. `QUEST.LOG.LIST.PAPER`：左侧顶层纸页。
2. `QUEST.LOG.DETAIL.PAPER`：右侧顶层纸页。
3. `QUEST.LOG.GUTTER.UNDERLAY`：中央凹陷页沟底层。
4. `QUEST.LOG.GUTTER.LEFT_FOLD`：左页内折遮罩。
5. `QUEST.LOG.GUTTER.RIGHT_FOLD`：右页内折遮罩。
6. `QUEST.LOG.GUTTER.STITCH`：单个可重复横向针脚站。
7. `QUEST.LOG.GUTTER.TOP`：顶部小型装订收口。
8. `QUEST.LOG.GUTTER.BOTTOM`：底部小型装订收口。

八组都是非交互普通状态。不得增加按钮、任务行、奖励槽、页码、文字或第九组
装饰。

### 参考 runtime 几何

- pfUI 离线参考：`QuestLogFrame = 676 × 440 UI px`。
- 书本绝对中心线：`QuestLogFrame` 局部 `x=338`。
- 左右物理纸页围绕中心线近 1:1 对称；在 `676 × 440` 重组预演中，两页可见
  物理宽度差不得超过约 `1%`。
- `42%／58%` 只描述未来页内文字列、内边距和滚动控件占用，不得改变纸页
  外接尺寸、页沟位置或装订轴线。
- 页沟、每个重复针脚站、顶部收口与底部收口必须共享 `x=338`；装配后中心
  偏移不得超过 `1 UI px`。
- 最终 runtime 尺寸仍须由 Turtle WoW `/fstack`、截图和 UI Scale 复核；
  上述数值不能直接晋级 `P5`。

### 源画布与排布

- 目标源画布：`1536 × 1024`。
- 优先真正 RGBA 透明背景；若执行器不能可靠透明，只允许完全均匀的纯
  `#00FF00` 色键。
- 上排放置近等外接尺寸的左页和右页，各自拥有连续透明裁切边距。
- 下排沿同一水平中线从左到右放置页沟、左内折、右内折、单个针脚站、顶部
  收口、底部收口，共六个互不接触的单元。
- 每个对象四周保留足够防渗色边距，不得用阴影、污渍或绳线连接相邻单元。

### 拉伸、裁切与层序

- 两张纸页使用九宫格／分区 crop：
  - 中央低频安静填充区允许双轴平铺或有限拉伸。
  - 外侧毛边、页角、底边和专用内缘不可拉伸。
  - 左右页必须分别保留自己的内缘，不允许把一页机械镜像成另一页。
- `GUTTER.UNDERLAY` 只允许纵向中段平铺。
- `LEFT_FOLD`、`RIGHT_FOLD` 只允许纵向中段平铺；顶部、底部与横向宽度不可
  拉伸。
- `GUTTER.STITCH` 是一个独立针脚站，不允许拉伸；runtime 通过离散放置重复，
  不得纵向无缝平铺成连续绳杆。
- `GUTTER.TOP`、`GUTTER.BOTTOM` 不允许拉伸或重复。
- 离线重组固定层序：
  1. 已接受的 `QL-A1` 封皮与外围页叠。
  2. `GUTTER.UNDERLAY`、重复的 `GUTTER.STITCH`、`GUTTER.TOP`、
     `GUTTER.BOTTOM`。
  3. 左右顶层纸页。
  4. `GUTTER.LEFT_FOLD`、`GUTTER.RIGHT_FOLD`，遮住针脚两端。
  5. runtime 文字、任务行、滚动条、奖励和按钮。

### 文字安全区

- 每页中央至少约 `70%` 的阅读区域保持低频、低对比和连续。
- 允许大片淡污渍、轻微纤维与缓慢色差；禁止满页均匀重复的细碎压花、符号、
  裂纹、网纹或高对比噪点。
- 高频磨损只允许出现在不可拉伸页边、页角、外缘和内折附近。
- 左页可略暗暖赭，右页可略亮旧象牙，但必须仍像同一本书中的同批纸张。

### 禁止烘焙

- 任何中文、英文、数字、伪文字、任务名称、任务等级或奖励数量。
- 任务行、地区标题、追踪框、书签、徽记、蜡封、滚动条和任何 Button。
- 物品图标、品质色、金币、经验、法术奖励或完成状态。
- 外置封脊、正面皮革竖条、跨页束带、横梁、端帽、木杆、金属杆或大型阴影。
- 连续纵向麻绳、纵向绳杆、一串机械重复绳结或与中心线不共线的针脚。
- 针脚两端落在正文纸面上的独立结、底板、深色接头或黄铜孔环。
- 现代黑玻璃、圆角卡片、细金线、外发光、暗黑 3 式尖刺黑铁和照片级古董。

### 验收预演与回退

用户复审前必须提供：

1. 原始八对象透明源画布。
2. 使用真实层序、`676 × 440` 参考几何和 `x=338` 中心线生成的确定性重组
   预演；调试中心线只能出现在单独 review 图，不能烘焙进候选。
3. 分别使用 3、5、7 个针脚站的纵向重组检查，确认每个针脚共线、无纵向
   绳杆、无端点跳动。
4. 覆盖真实中文长标题、长正文、目标和多奖励占位的文字安全区预演。
5. 原始、最小、基准和最大尺寸的九宫格／纵向平铺检查。
6. PNG 尺寸、模式、SHA-256、Alpha、绿色残留、可见包围盒和单元间隔检查。

只要出现以下任一项就退回并创建新版本：物理双页明显不等宽；书脊偏移；
针脚不共线；针脚端点没有被内折遮住；存在连续纵向绳杆；纸面高频纹理压过
正文；对象数量不是八组；任何交互件或文字被烘焙。不得用 Alpha 清理、
锐化或后期位移掩盖结构错误。

## 最终执行正文

为 Turtle WoW 1.18.1 制作《魔兽世界》60 级香草时代视觉语言的手绘位图 UI
组件源画布。目标是“冒险者公会任务卷宗”打开后的对称内部纸页、凹陷页沟与
隐藏装订结构，不是完整 UI，也不是从书本外侧看到的封脊。

Image 1 是已经用户接受的空卷宗结构母版，是书本轮廓、封皮厚度、外围页叠、
纸张材料、综合色温、磨损尺度、左上暖光与内部俯视角度的最高权威。Image 2
只提供公会任务卷宗的香草魔兽身份和总体装订关系；忽略其中的任务行、文字
占位、按钮、滚动条、徽记、蜡封、书签和奖励框。不要使用任何旧的 QL-A2
候选作为输入，也不要复制其中的装订针脚或满页纹样。

输出 `1536 × 1024`、无文字、真正 RGBA 透明背景的组件源画布；若无法可靠
透明，只能使用完全均匀、无纹理、无渐变的纯 `#00FF00` 色键。画面必须恰好
包含八组互不接触的逻辑对象。上排从左到右是近等外接尺寸的左页和右页；下排
沿同一水平中线从左到右是中央页沟底层、左内折、右内折、单个横向针脚站、
顶部收口和底部收口。每组四周都保留宽阔、连续的透明或纯绿色裁切间隔。

左右物理纸页必须围绕同一本书的绝对中心线形成近 1:1 对称结构。它们使用
相同高度、接近相同宽度、相同纸纤维尺度和相反方向的内缘弯曲；左页可以略暗
暖赭，右页可以略亮旧象牙，但不能像两种材料。不要通过拉宽右页表达
`42%／58%`；这个比例只属于以后运行时的文字列。

两页中央至少约 70% 的阅读区域必须安静，只保留低频纸纤维、缓慢综合色差和
少量大片淡污渍。高频磨损、裂口与较深污迹集中在外侧毛边、页角、底边和中央
内折附近。绝对不要生成满页均匀重复的细碎压花、符号、网纹、裂纹或装饰性
花纹。纸页必须提供明确的中央填充、外侧边缘、页角和专用内缘裁切空间。

中央页沟是一条向下凹陷、窄而纵向延展的深胡桃装订衬布与柔和接触阴影。
它没有明亮完整描边、凸起边框、皮革竖条、横向束带或外置封脊。左内折和右
内折是轻薄、以透明为主的窄长纸面过渡，分别拥有正确的镜像曲面与同一左上
光源；它们不是独立纸条或毛边页块，并且必须具有足够宽度在重组时遮住针脚
端点。

单个装订针脚站只包含一小段横向跨过中央窄缝的粗麻线弧，以及两端极少量、
向透明渐隐的接触阴影。它必须以自己的水平中点对称，左右端点尺度一致，能够
在 runtime 中作为离散单元沿同一纵向轴线重复放置。绝对不要连续纵向麻绳、
纵向绳杆、一至两个竖向绳结、皮革底板、棕色竖条、金属孔环、矩形框或投向
背景的大阴影。针脚视觉上从两侧内折下方穿出、跨过凹陷页沟，再回到内折
下方；端点不能像两个独立按钮贴在纸面上。

顶部和底部收口是两个独立、克制、正面俯视的小型麻线收束，只比页沟略宽，
与针脚使用相同麻线尺度；它们不是横梁、端帽、扇形大阴影或底部页块。两个
收口在源画布下排中左右分离，不上下堆叠。

所有八组对象共享 Image 1 的香草魔兽粗重手绘轮廓、略夸张体积、左上暖光、
材料年代和观察角度。禁止现代 HUD、黑色透明卡片、细金属线、霓虹、照片级
写实、暗黑 3 式尖刺黑铁，以及任何文字、控件、任务行、物品图标或完整界面。

最终自检：上排两页物理宽度近等；下排恰好六组并在同一水平线上；针脚是一
个横向单元且没有纵向绳杆；左右内折足以遮住针脚端点；八对象总数准确；正文
中央没有密集高频纹样；背景是真透明或完全均匀的纯 `#00FF00`。
