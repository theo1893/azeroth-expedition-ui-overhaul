## 共同前缀

为 Turtle WoW 1.18.1 制作《魔兽世界》60 级香草时代视觉语言的手绘位图 UI
生产母版。模块身份是“冒险者公会任务卷宗”：正式展开的双页厚任务簿，与已
锁定的战地旧书聊天框来自同一批旧纸、深胡桃皮革、暗酒红皮革、氧化黄铜、
褪色织物和暗红蜡，但轮廓与装订方式不同。

保持 2004 年前后香草魔兽 UI 的粗重手绘轮廓、略夸张体积、温暖明暗分层和
可读的材料关系。不要照片级古董写实，不要现代网页 UI，不要《暗黑破坏神
3》式尖刺黑铁，也不要《上古卷轴 5》式极简文字菜单。

所有对象正面平视、无透视、光从左上方稳定照入。输出真正 RGBA 透明背景；
若执行器无法可靠生成透明背景，则只能使用完全均匀的纯 `#00FF00` 色键，
对象之间至少保留清晰空隙。不要添加投向背景的大面积环境阴影。

不得生成中文、英文、数字、伪文字、任务名称、按钮文字、物品图标、人物、
游戏场景或完整 HUD。文字和动态图标全部由游戏运行时绘制。

## 共同负面约束

- 禁止半透明黑色方块、玻璃面板、背景模糊、圆角卡片和胶囊按钮。
- 禁止单像素现代描边、霓虹外发光、镜面金属、宝石灯和科技纹样。
- 禁止骷髅、恶魔角、尖刺、黑铁牢笼、大型龙头、武器、翅膀和祭坛结构。
- 禁止把左右页面画成两张互不相关的矩形羊皮纸。
- 禁止把按钮、滚动条、任务行、奖励图标或文字烘焙进结构母版。
- 禁止状态之间改变对象尺寸、轮廓、锚点或光照方向。
- 禁止在状态画布中加入标签、编号、分隔文字或说明箭头。

## 执行块 QL-A1：空卷宗结构母版

对应组件：

- `QUEST.LOG.SHELL`
- `QUEST.LOG.LIST.PAPER`
- `QUEST.LOG.DETAIL.PAPER`

生成一件完全空白的“冒险者公会任务卷宗”结构母版，仅包含非交互材料：

- 横向展开的双页厚书，整体宽高比约 `1.45–1.50 : 1`。
- 左页约占内部阅读宽度 42%，右页约占 58%。
- 外层是深胡桃棕与暗酒红厚皮封面，四角有低调氧化黄铜包角。
- 四周和底部明确露出三至四层不齐整毛边书页。
- 中央有真实书脊、缝线、页缝压痕和深而柔和的接触阴影。
- 左页略暗，右页阅读纸面略亮；纸面中心保持安静。
- 左右外侧保留以后挂载织物书签、滚动条和书扣的净空。
- 底部只表现页叠与装订，不出现任何按钮或页码文字。

这是可确定性切成封皮边缘、四角、左右纸面、书脊和页叠的结构源母版，不是
最终整张 UI。所有任务行、标题、按钮、滚动条、蜡封、书签和奖励槽都必须
缺席。

验收：

- 不看文字仍明显是一本双页厚书。
- 中央书脊和多层页厚清楚可见。
- 左右正文安全区没有高对比污渍或装饰。
- 没有任何疑似可点击控件。
