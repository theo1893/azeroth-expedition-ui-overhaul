# 任务追踪组件资产兼容草案 V2

## 元数据

- 类型：`deferred-compatibility-draft`
- 状态：暂停；任务追踪由外部插件提供，provider 与真实对象尚未纳入仓库
- 执行状态：禁止执行；不得提交生图、不得进入 `assets/source/quests/`
- 未来固定执行器：`imagegen-0-143-0`／`@openai/codex@0.143.0`
- 目标客户端：Turtle WoW `1.18.1`／Interface `11200`
- 对应合同：[QUEST_COMPONENT_SPEC.md](../../docs/implementation/QUEST_COMPONENT_SPEC.md)
- 视觉基准：[任务追踪面板_视觉基准_v1.png](../../assets/locked/quests/任务追踪面板_视觉基准_v1.png)
- 禁止用途：不得把带固定高度和伪任务行的整张图直接作为 runtime 背景

本文件只保留已锁定的“行军便笺”视觉语言与未来可能需要的组件拆分，不是
可执行生产提示词。以下 `QUEST.TRACKER.*` 均为逻辑 ID，不代表已经发现对应
Frame、Button、FontString、事件或数据对象，也不得把原生 `QuestWatchFrame`
当作默认 provider。

取得外部任务追踪插件源码后，必须先记录其顶层 Frame、任务组、目标行、更新
生命周期、数据状态、点击／移动／收起能力和回退路径，再基于证据新建版本化
`production-draft`。在此之前，下面各节只能用于视觉讨论，不能原样提交给
固定执行器。

## 共同前缀

为 Turtle WoW 1.18.1 制作《魔兽世界》60 级香草时代手绘位图 UI 生产母版。
模块身份是“行军便笺”：从公会任务卷宗中抽出、固定在游戏视野右侧的一叠窄长
旧纸页，用于快速扫读任务名称和目标。

它与任务卷宗和战地旧书共享旧纸、深胡桃皮革、暗酒红织物、氧化黄铜、暗红蜡
和左上光源，但必须明显更轻。它不是缩小版书籍，不存在完整厚封皮，也不存在
四周封闭金属框。

保持 2004 年前后香草魔兽 UI 的粗重手绘轮廓、略夸张体积和温暖奇幻质感。
正面平视，无透视。输出真正 RGBA 透明背景；若执行器无法可靠生成透明背景，
只能使用完全均匀的纯 `#00FF00` 色键，对象之间保留清晰空隙。

不得生成任务名称、目标文字、数字、伪文字、角色、游戏场景、完整 HUD 或
任务图标。所有文字和进度由游戏 runtime 绘制。

## 共同负面约束

- 禁止半透明黑色面板、玻璃、模糊、圆角卡片和网页列表。
- 禁止每条任务独立拥有背景卡片、完整边框或彩色条。
- 禁止完整厚封皮、四角金属框、书脊和左右双页结构。
- 禁止现代发光、霓虹、镜面黄铜、精密细金线和科技字体。
- 禁止《暗黑破坏神 3》式尖刺、骷髅、黑铁和火焰。
- 禁止照片级真实旧纸和《上古卷轴 5》式无材质极简列表。
- 禁止把顶部、可拉伸中段和撕裂底边黏成无法拆分的一张固定高度图片。
- 禁止状态之间改变组件尺寸、轮廓、锚点和光照。
- 禁止在状态画布中加入标签、编号、说明箭头或文字。

## 视觉预拆分 QT-A1：顶部固定件与徽记

对应组件：

- `QUEST.TRACKER.HEADER`
- `QUEST.TRACKER.EMBLEM`

生成一张透明组件画布，放置彼此分离的以下对象：

1. 顶部皮带左端帽：磨损深胡桃皮革与一枚氧化黄铜铆钉。
2. 顶部皮带可横向平铺的中段。
3. 顶部皮带右端帽：与左端不完全镜像，含一枚氧化黄铜铆钉。
4. 独立的羽毛笔与旧黄铜指南针组合徽记。

皮带有明确厚度和压住纸张的接触阴影，但不能像重型窗框。徽记体积小、轮廓
清楚，不含发光宝石，不接收点击。三个皮带部件拼接后必须形成自然连续结构，
中段左右边缘可无缝衔接。

---

## 视觉预拆分 QT-A2：动态纸面与叠页边

对应组件：

- `QUEST.TRACKER.PAPER`

生成一张透明组件画布，放置以下可伸缩部件：

1. 灰赭旧纸的无缝中央填充块，纹理低对比。
2. 可纵向平铺的左侧毛边，后方露出第二、第三张错位纸页。
3. 可纵向平铺的右侧毛边，轻微不对称。
4. 左上纸面连接角，不含皮带。
5. 右上纸面连接角，不含皮带。

中央填充必须适合长中文任务文字，不能有明显大污渍、折线或高对比图案。
左右页边拥有真实纸张厚度，但不能形成封闭边框。纵向平铺时不出现可见重复
接缝。

---

## 视觉预拆分 QT-A3：自然撕裂底边

对应组件：

- `QUEST.TRACKER.BOTTOM`

生成一张透明组件画布：

1. 撕裂底边左端。
2. 可横向平铺的撕裂底边中段。
3. 撕裂底边右端。
4. 后方第二层错位纸页底端。
5. 后方第三层错位纸页底端。

底边不规则但仍适合小尺寸 UI，不得生成过长垂落纸条。所有底边只允许横向
拼接，禁止被纵向拉伸。纸张颜色、厚度与 QT-A2 一致。

---

## 视觉预拆分 QT-B1：收起拉环状态

对应组件：

- `QUEST.TRACKER.COLLAPSE`

生成两组完全一致几何的皮革折页／收起拉环状态：

- 展开含义：普通、悬停、按下、禁用。
- 收起含义：普通、悬停、按下、禁用。

展开与收起通过折页朝向和小型黄铜箭头区分。悬停仅使皮革略暖、边缘略抬起；
按下材质下沉且阴影收紧；禁用降低对比。禁止圆形按钮、现代 `+/-` 图标、
发光和文字。

## 视觉预拆分 QT-B2：任务与目标状态覆盖

对应组件：

- `QUEST.TRACKER.OBJECTIVE`
- `QUEST.TRACKER.FOCUS`
- `QUEST.TRACKER.SEAL`
- `QUEST.TRACKER.TIMER`

生成一张透明小型状态图集，全部图标使用一致的视觉重量和外接尺寸：

1. 未完成目标：空心墨圈。
2. 已完成目标：羽毛笔墨勾。
3. 当前重点任务：一小段暗酒红织物页边标记。
4. 整项完成：小型完整暗红蜡封。
5. 失败：小型破裂暗红蜡封。
6. 限时普通：沙漏墨印。
7. 限时警告：同一沙漏使用更深暗红墨迹，不发光。
8. 任务间分隔线左端。
9. 可横向平铺的短墨线中段。
10. 任务间分隔线右端。

图标必须能在小尺寸下辨认，但不能像彩色技能图标。织物标记和蜡封不能遮挡
文字；分隔线必须轻、短、低对比。

---

## 视觉预拆分 QT-B3：可选的行交互覆盖

对应组件：

- `QUEST.TRACKER.ENTRY`

只有在外部 provider 确认存在稳定任务行点击对象、且新版本生产提示词得到
用户确认后，未来批次才可以生成四个完全相同几何的透明长条覆盖：

1. 普通：完全透明，只保留极轻微纸面压痕。
2. 悬停：纸张略暖、左边缘轻微抬起。
3. 按下：纸张下沉、阴影收紧。
4. 禁用：对比降低。

覆盖不得形成卡片、完整边框或不透明矩形。若目标 provider 只有 FontString
且没有稳定点击对象，未来批次也应保持未执行，不为了使用美术而新增伪交互。

## 恢复生产前的必备记录

当前不得产生执行结果。外部插件完成 provider 映射、提示词重写并再次获得
用户确认后，结果才可先进入 `generated/quests/<batch>/<version>/`，且在
用户确认前不得进入 `assets/source/quests/`。届时必须：

1. 记录每个对象的顺序、逻辑 ID、裁切矩形和状态。
2. 用确定性脚本验证顶部／中段／底部拼接和不同内容高度。
3. 在一项、五项、满追踪、完成、失败与限时任务场景中制作无损预演。
4. 更新 `QUEST_COMPONENT_SPEC.md` 和 `OVERHAUL_TRACKER.md`，记录实际
   provider，不得沿用未经验证的原生对象名。
5. 只有完成 Lua adapter 与目标客户端实机测试后，才复制 runtime TGA 到
   addon。
