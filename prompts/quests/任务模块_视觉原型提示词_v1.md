## 共同提示词正文

为《魔兽世界》香草时代视觉语言设计一套手绘位图 UI 美术资源，服务于
Turtle WoW 1.18.1。整体属于“艾泽拉斯远征手记”设计体系，与已确定的厚重
旧书聊天框拥有相同的材质精度、绘制手法、光照方向和年代感，但不能直接复制
聊天框结构。

保持 2004 年前后香草魔兽 UI 的手绘感、厚轮廓、略夸张的体积、清晰的明暗
分层和温暖奇幻气质。使用旧羊皮纸、深色磨损皮革、氧化黄铜、胡桃木、墨迹、
蜡封和褪色织物。色彩低饱和，以赭黄、烟褐、暗酒红、森林绿和旧黄铜为主。

《上古卷轴 5》仅作为沉重材质与低饱和配色参考；组件轮廓、按钮厚度和装饰
比例必须保持香草魔兽式的手绘与夸张，不能变成极简文字菜单。

正面平视的游戏 UI 资源，轮廓清晰，主要信息区平整安静，装饰集中在外沿。
单独呈现组件本体，不要生成完整游戏截图。如果无法输出透明背景，使用纯净的
深灰背景，便于后续抠图。

## A：完整任务簿框体

设计一个按 L 打开的完整任务详情面板，表现为一本正式的“冒险者公会任务
卷宗”。

任务簿正面展开，横向双页结构，宽高比约 1.45:1。左页约占 42%，用于任务
目录；右页约占 58%，用于任务正文。中央存在清晰但不过宽的书脊、缝线、压痕
和页缝阴影。

外围露出深胡桃棕与暗酒红色的厚皮封面，四周能看见三至四层高低不齐的书页
截面。页边有轻微卷曲、缺口、污渍和压合阴影，使它首先被识别为一本厚重的
书，而不是两块羊皮纸面板。

左页稍暗，右页阅读区域稍亮。书本侧边插有森林绿、暗酒红和褪色蓝灰色织物
书签。底部内侧具有真实页码位置、折角和翻页痕迹。使用少量氧化黄铜书扣和
包角，不使用大型龙头、武器或尖刺。

保留大片干净的文字安全区，不生成可读文字，不放置游戏场景、角色、动作条
或其他 UI。

禁止胶囊按钮，禁止扁平矢量图标，禁止霓虹颜色和科技字体。

需要文字的位置只保留干净安全区或短墨线占位。

## B：追踪面板纸页主体

设计一个游戏画面右侧使用的任务追踪面板空白框体，表现为从公会任务卷宗中
抽出的“行军便笺”。

纵向狭长轮廓，宽高比约 1:2.4。由两至三张错位叠放的灰赭色旧羊皮纸组成，
纸张拥有真实厚度、页边阴影、折痕、污渍和自然撕裂的底边。顶部被一条窄皮带
或黄铜地图钉固定，不能出现完整厚封皮。

整体比聊天框和任务详情轻巧，不使用四周封闭边框。正文区域保持连续，不把
不同任务拆成独立卡片。纸页中段应能纵向延展，顶部和底部保持不可拉伸的手绘
结构。

标题固定件是一条磨损的深棕皮带，由两个氧化黄铜铆钉固定。中央嵌有小型羽毛
笔与指南针组合徽记，右侧设置能够收起面板的小型折页或皮革拉环。

独立 UI 资源，正面平视，不生成文字、游戏场景或其他 HUD。
