# 任务追踪面板风格确认稿

## 共通风格

为《魔兽世界》香草时代视觉语言设计一套手绘位图 UI 美术资源，服务于 Turtle WoW 1.18.1。整体属于“艾泽拉斯远征手记”设计体系，与已确定的厚重旧书聊天框拥有相同的材质精度、绘制手法、光照方向和年代感，但不能直接复制聊天框结构。

保持 2004 年前后香草魔兽 UI 的手绘感、厚轮廓、略夸张的体积、清晰的明暗分层和温暖奇幻气质。使用旧羊皮纸、深色磨损皮革、氧化黄铜、胡桃木、墨迹、蜡封和褪色织物。色彩低饱和，以赭黄、烟褐、暗酒红、森林绿和旧黄铜为主。

《上古卷轴 5》仅作为沉重材质与低饱和配色参考；组件轮廓、按钮厚度和装饰比例必须保持香草魔兽式的手绘与夸张，不能变成极简文字菜单。

正面平视的游戏 UI 资源，轮廓清晰，主要信息区平整安静，装饰集中在外沿。单独呈现组件本体，不要生成完整游戏截图。如果无法输出透明背景，使用纯净的深灰背景，便于后续抠图。

## 追踪面板纸页主体

设计一个游戏画面右侧使用的任务追踪面板空白框体，表现为从公会任务卷宗中抽出的“行军便笺”。

纵向狭长轮廓，宽高比约 1:2.4。由两至三张错位叠放的灰赭色旧羊皮纸组成，纸张拥有真实厚度、页边阴影、折痕、污渍和自然撕裂的底边。顶部被一条窄皮带或黄铜地图钉固定，不能出现完整厚封皮。

整体比聊天框和任务详情轻巧，不使用四周封闭边框。正文区域保持连续，不把不同任务拆成独立卡片。纸页中段应能纵向延展，顶部和底部保持不可拉伸的手绘结构。

标题固定件是一条磨损的深棕皮带，由两个氧化黄铜铆钉固定。中央嵌有小型羽毛笔与指南针组合徽记，右侧设置能够收起面板的小型折页或皮革拉环。

独立 UI 资源，正面平视，不生成文字、游戏场景或其他 HUD。

## 负面约束

禁止现代化 MMO HUD，禁止半透明黑色玻璃面板，禁止背景模糊，禁止圆角卡片，禁止胶囊按钮，禁止扁平矢量图标，禁止霓虹颜色和科技字体。

禁止《暗黑破坏神 3》式尖刺、骷髅、恶魔角、黑铁牢笼和高对比火焰金属。禁止《上古卷轴 5》式纯文字极简菜单。禁止照片级真实古董书，必须保持香草魔兽的手绘夸张感。

禁止把任务追踪画成缩小版完整书籍。禁止每条任务拥有独立卡片和完整边框。禁止生成完整游戏截图、人物、环境、动作条、小地图、头像框和无关装饰。禁止伪造难以辨认的文字；需要文字的位置只保留干净安全区或短墨线占位。
