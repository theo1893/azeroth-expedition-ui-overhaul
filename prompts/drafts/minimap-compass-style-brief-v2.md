# 小地图罗盘风格确认稿 V2：插件挂载轨道

> [!CAUTION]
> **状态：已弃用。** 本 V2 小地图提示词仅作为失败探索存档，不得用于后续生成或实现。当前基准见 [地图模块视觉规范_远征地图卷与黄铜航向罗盘_v1.md](../../docs/modules/map/地图模块视觉规范_远征地图卷与黄铜航向罗盘_v1.md)。

## 继承要求

以 V1 小地图黄铜罗盘为直接编辑目标，保留圆形地图视野、深皮革外圈、双层氧化黄铜刻度环、四个方向件、顶部北方指针、右侧缩放控件、底部铭牌和右下皮革吊牌。

继续遵守“艾泽拉斯远征手记”的香草魔兽手绘位图语言。不得变成现代雷达、汽车导航、科幻 HUD、精密机械表或复杂蒸汽朋克仪器。

## 插件图标挂载结构

1. 将最外层深色皮革圆环正式设计为第三方插件图标挂载轨道。
2. 在北、东、南、西四个大型方向件之间设置八个均匀的标准吸附槽，每个象限两个槽位。
3. 风格确认图中展示六个已挂载插件徽章和两个空槽，证明外圈能够承载真实插件使用场景。
4. 插件保留不同的中央图案，但原始方框、圆框和发光外边全部统一包装成小型氧化黄铜或深皮革“制图徽章”。
5. 单个徽章具有厚轮廓、暗哑黄铜包边、小型铆钉和清晰点击面积；其中一个徽章可以表现轻微悬停抬起状态。
6. 插件徽章不得遮挡东、南、西、北方向件，也不得进入中央地图区域。

## 固定系统控制区

- 缩放、追踪、邮件、日历和地图设置属于固定系统控制，集中在罗盘右侧和右下方，不参与插件自动排列。
- 底部铭牌只用于时间、坐标或地区名称，不放置插件图标。
- 中央地图有效直径不得低于整体直径的 70%。

## 溢出工具袋

1. 将 V1 右下方皮革吊牌明确改造成“制图工具袋”入口。
2. 当插件超过八个时，额外图标收纳到工具袋内。
3. 收起状态只显示皮革吊牌、小型黄铜扣和克制的数量提示，不继续向外圈堆叠按钮。
4. 风格确认图只表现收起状态，不展开现代网格菜单。

## 视觉收敛

- 为给插件徽章留出空间，现有右侧和底部附属装饰体量缩小约 10%–15%。
- 罗盘环仍需厚重，但不能像金属牢笼。
- 插件徽章应像挂在制图工具上的实体吊牌，不像现代桌面快捷方式或杂乱按钮环。
- 使用暗哑黄铜、深胡桃皮革、少量珐琅与手绘图案，不使用霓虹发光。

## 负面约束

禁止插件图标自由重叠，禁止按钮围绕罗盘形成无间距完整圆环，禁止原始插件边框互相冲突，禁止现代托盘菜单、胶囊计数器、玻璃拟态和扁平矢量图标。

禁止把中央地图面积压缩到 70% 以下。禁止大型龙头、翅膀、骷髅、尖刺、齿轮、管道和发光宝石。

正面平视，单独呈现小地图组件，使用纯净深灰背景，不生成完整游戏截图、角色、任务追踪器或其他 HUD。
