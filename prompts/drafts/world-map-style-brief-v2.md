# 大地图风格确认稿 V2：重型远征地图卷

> [!CAUTION]
> **状态：已弃用。** 本 V2 大地图提示词仅作为失败探索存档，不得用于后续生成或实现。当前基准见 [地图模块视觉规范_远征地图卷与黄铜航向罗盘_v1.md](../../docs/modules/map/地图模块视觉规范_远征地图卷与黄铜航向罗盘_v1.md)。

## 继承要求

以 V1 大地图为直接编辑目标，保留横向羊皮卷、上下卷轴杆、左侧制图索引、右侧图例、顶部标题区、底部缩放尺和大面积中央地图纸面的基本结构。

继续遵守“艾泽拉斯远征手记”的香草魔兽手绘位图语言：低饱和旧羊皮纸、深胡桃木、磨损皮革、氧化黄铜、厚实手绘轮廓和清晰接触阴影。不得复制聊天框或任务卷宗的书本结构。

## V2 核心目标

解决 V1 相比聊天框和任务卷宗显得偏轻的问题，使它像一件沉重、耐用、能够经历长期远征的制图装备，同时保持“羊皮地图卷”而非书本、木板或金属窗口的身份。

## 厚重感增强规则

1. 顶部和底部深胡桃木卷轴杆整体体量增加约 12%–18%，木材颜色更深，纹理更粗重，端部黄铜套箍更厚。
2. 卷轴杆增加四组宽皮革固定带、黄铜铆钉和压合夹具，表现纸张与卷轴杆之间真实受力关系。
3. 羊皮纸背后增加一层暗酒红与深胡桃色的厚皮革承托，只在四周露出约 18–28 px，不形成规则矩形卡片或完整金属框。
4. 左右卷曲纸边增加更多可见卷层、纸张厚度与深色接触阴影，使卷起部分具有真实重量。
5. 地图四角增加克制的皮革压片或黄铜页夹，固定羊皮纸，但不得形成四周连续边框。
6. 顶部标题皮革铭牌更厚，增加暗金铆钉、压印和更深的投影；底部黄铜制图尺增加实体凹槽和滑块重量。
7. 左侧索引标签统一挂载在一条深色皮革纵带和黄铜环扣上，避免像漂浮按钮。
8. 整体阴影更深、更靠近物件边缘，纸张中心稍微压暗，降低 V1 过亮、过轻的感觉。

## 信息面积约束

- 中央地图有效区域仍需占整体可用面积的 78%–82%。
- 新增厚重结构只能出现在地图外围、卷轴杆、皮革承托和固定件上。
- 不得用大型雕像、龙头、武器、翅膀或黑铁尖刺制造重量。
- 不得让暗色结构侵入道路、地名、任务范围和地点标记。

## 视觉目标

正面平视的独立 UI 美术资源。它应像一张装载在重型旅行卷轴匣中的远征地图：深色木轴、厚皮革承托、氧化黄铜夹具、厚羊皮纸卷层与强烈但克制的实体阴影。

保留香草魔兽式夸张与手绘感，禁止照片级真实、现代网页地图、蒸汽朋克、半透明黑色面板、现代卡片、《暗黑破坏神 3》式尖锐金属和《上古卷轴 5》式极简文字地图。

不要生成完整游戏截图、角色或其他 HUD。地图内容仅作低细节占位，不生成难以辨认的正式地名。
