## 产品约束

聊天框下方不再承载公会、背包空间、耐久、好友、延迟、时钟、金币或区域等
常驻信息 panel。不得生成三联状态栏、单个可复用状态字段、现代 HUD 数据条，
也不得在主书框上为这些字段预留固定凹槽。

pfUI 的 widget 数据与点击逻辑继续保留，但默认没有聊天框视觉挂载点。未来若
某项信息确需展示，必须作为新的独立组件立项，拥有自己的对象、显示条件、
交互状态和提示词，不得恢复旧三联底栏。

## 后续控件生成正文

Create a production-ready modular sprite source for the remaining controls of
the locked “Azeroth Expedition Journal / Battlefield Old Book V1” chat frame.
Use the confirmed V3 book as the highest authority for parchment, leather,
restrained oxidized brass, irregular hand-painted edges, wear density and
light direction.

Produce exactly three separate, text-free objects on one transparent sheet:

1. one normal chat-input writing strip;
2. one focused chat-input writing strip with the identical canvas and
   silhouette;
3. one small dark-purple-red wax seal or cloth-knot unread marker.

The input strip is a shallow writing zone laid into the lower parchment page,
not a framed dashboard. Normal and focused states share the same geometry;
focus only deepens the ink baseline and adds a faint candle-warm edge. The
unread marker is a quiet pre-modern page marker, not a notification dot,
jewel, icon button or glowing badge.

Design for a `440 × 320` runtime chat window: input visible size
`376–380 × 24–26 UI px`, unread marker `14–16 × 14–16 UI px`, with the
`380 × 236 UI px` message rectangle unchanged. Use true transparency,
orthographic front views, aligned baselines and generous spacing.

Do not include any bottom-status field, guild/bag/latency readout, three-panel
dashboard, permanent data rail, labels, text, icons, runes, sheet-wide frame,
glossy gold, modern glass, black translucent rectangles or one-pixel borders.
