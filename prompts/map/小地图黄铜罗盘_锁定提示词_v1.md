# 完整生成提示词

## 共通风格

为《魔兽世界》Turtle WoW 1.18.1 设计“艾泽拉斯远征手记”UI 体系中的地图模块，美术主题为“远征制图师套件”。

保持香草时代魔兽 UI 的手绘位图质感、厚实轮廓、略微夸张的体积、清晰明暗分层和温暖奇幻气质。与既有战地旧书聊天框、公会任务卷宗和行军便笺拥有相同的制作年代、材质精度和光照方向，但不得复制它们的书籍轮廓。

基础材质为低饱和旧羊皮纸、深胡桃色磨损皮革、氧化黄铜、少量深色木材、手绘墨迹和克制的珐琅标记。纸张承担世界与地理信息，黄铜承担导航、刻度与控制，皮革承担固定、收纳与连接。

整体应像艾泽拉斯冒险者长期使用的真实制图装备，具有磨损、折痕、手工装配和远征痕迹，但不能变成现代仪表盘、照片级古董或复杂蒸汽朋克机械。

地图内容始终是视觉主体。装饰集中在地图边缘、卷轴固定件和罗盘外环，不得压缩地图面积或干扰道路、地名、任务范围和地点标记。

## 右上角小地图

设计游戏画面右上角使用的圆形小地图，将其表现为一件“远征制图师黄铜航向罗盘”。

小地图主体是一枚经过长期使用的圆形导航仪器。中心保留清晰、完整的圆形地图视野，地图显示面积至少占总体直径的 70%。地图外围由两层氧化黄铜罗盘环包围，内环刻有细小方向刻度，外环刻有香草魔兽式手绘的东、南、西、北方向标记。

最上方设置明显但不过大的北方指针，造型为厚实的黄铜三角尖冠。罗盘环背后露出少量深胡桃色皮革垫层和固定带，使它与聊天框、任务卷宗处于同一制作体系。

黄铜具有暗哑高光、细小刮痕、边缘磨损和极少量青绿色氧化痕迹，但不能变成明亮黄金、现代精密仪表或复杂蒸汽朋克机械。罗盘不使用齿轮、管道、玻璃霓虹、科技刻度或大量活动机械。

缩放控制表现为罗盘右侧的小型黄铜旋钮或上下拨片。追踪菜单表现为挂在罗盘侧面的皮革制图标签。时间和坐标位于罗盘下方的小型黄铜铭牌或窄羊皮签上，不使用数字屏幕。

邮件、日历、插件入口和其他小地图按钮不能环绕整个罗盘形成杂乱按钮圈。将次要按钮集中在罗盘右下方的一条短皮革挂带或折叠工具扣上；非悬停状态下只保留必要入口。

玩家、队友、尸体、任务、商人、飞行点和资源节点使用统一手绘的小型珐琅针、墨印或黄铜标记，必须保留经典魔兽的清晰轮廓和颜色识别。

小地图首先应被识别为黄铜罗盘，其次才是圆形 UI 窗口；但罗盘边框不能过厚，不能牺牲实际地图面积。

正面平视，单独呈现小地图组件，使用纯净深灰背景。不要生成完整游戏截图、角色、任务追踪器或动作条。不要加入大型龙头、翅膀、骷髅、尖刺和发光宝石。

## 负面约束

禁止现代网页地图、玻璃拟态、半透明黑色面板、背景模糊、圆角卡片和悬浮工具栏。

禁止现代军用雷达、汽车导航仪、科幻 HUD、精密 CAD 刻度和电子数字显示。禁止复杂齿轮、管道、压力表和蒸汽朋克机械。

禁止《暗黑破坏神 3》式骷髅、恶魔角、尖刺黑铁、火焰金属和高对比红黑配色。禁止《上古卷轴 5》式纯文字极简地图。禁止照片级真实古董罗盘，必须保持香草魔兽手绘夸张感。

禁止把小地图画成厚重金属牢笼。禁止让按钮围绕小地图形成完整按钮环。禁止大型雕像、龙头和翅膀侵占地图显示面积。
