### 提示词转译约束

最终交给 imagegen 的专业提示词不能脱离项目基线自由发挥。每一批提示词都
必须明确包含下列基线信息：

1. **物件身份**：屏幕左下角正在使用的旧战地书籍，而不是覆盖游戏画面的
   复古面板。
2. **不可变特征**：深棕厚封皮、两至四层毛边书页、暖赭烟熏纸面、插入
   书页上沿的皮革索引签、略微不对称的手绘轮廓。
3. **结构原则**：香草结构与 pfUI 实际控件优先，美术只增强材质，不发明
   新槽位、新控件或新的操作结构。
4. **时代与精度**：经典魔兽二维手绘、低分辨率时代的清晰材质分块；细节
   可以精致，但不能变成摄影级产品渲染或规则工业制品。
5. **材料层级**：纸张为信息主体，旧皮革形成实体边界，氧化黄铜仅作克制
   包角和铆钉。
6. **模块化要求**：文字与真实控件由 pfUI 绘制；生成图不得烘焙 Tab、
   按钮、输入框、状态字段或滚动条。
7. **统一禁止项**：现代卡片、网页标签、玻璃拟态、科技 HUD、霓虹、规则
   网格、暗黑式尖锐金属框、上古卷轴式极简文字浮层、大型龙饰与持续发光。

## 二、V4 否决原因

V4 不是靠调整 UV 或边距就能修复，必须舍弃：

1. 整体像精密制作的规则木铜面板，不像使用多年的战地旧书。
2. 主框把四个 Tab 槽、右侧滚动轨道和底部字段全部烘焙在一张图中。
3. pfUI 的真实 Tab 从容器左侧开始排列，和背景固定槽位发生双重结构。
4. 右上、右下角件高于相邻横边，切成九宫格后上下不能形成共同基线。
5. 底部固定字段与 pfUI 输入框、左底栏拥有不同宽度和分段逻辑。
6. 规则直线、重复分隔和高密度铜边违反“略微不对称、手绘、非现代网格”
   的锁定要求。

## 三、pfUI 几何合同

### 已知运行环境

- 客户端：Turtle WoW `1.18.1` / Interface `11200`
- 唯一功能依赖：pfUI
- 当前测试角色 pfUI 原始左聊天框：`380 × 275` UI 单位
- 当前适配最小值：`440 × 320` UI 单位
- pfUI 字号：`12`
- `tabdock = 1`
- 1024 × 1024 纹理已确认不会出现绿色占位

### 下一步必须先测量的对象

在进入图像生成前，先用纯色调试框记录以下真实边界：

1. `pfUI.chat.left`
2. `pfUI.chat.left.panelTop`
3. 每个 `ChatFrameNTab` 的点击框、文字框和排列起点
4. 每个选中、普通与悬停 Tab 的统一底基线
5. `pfUI.chat.editbox` 与 `ChatFrameEditBox`
6. `pfUI.panel.left` 以及 left／center／right 三段
7. 正文 `ChatFrameN` 的安全区域

调试测量完成前，不根据截图肉眼猜测最终锚点。

### 运行时分层

从下到上固定为：

1. 模块化九宫格书本底框
2. 低对比度纸张暗角／磨损覆盖层
3. 连续、无固定槽位的顶部索引签承托带
4. pfUI 实际 Tab 的独立状态贴图
5. 聊天正文与 Tab 文字
6. 输入区、状态栏和未读提示

主书框不得再包含固定 Tab、文字、滚动条、输入框、状态字段或按钮槽位。

### 资源到 pfUI 对象的唯一映射

下表用于防止一张美术图同时承担多个互相冲突的几何职责。尺寸是当前
`0.3.1` 的候选值，必须在纯色调试测量后才能锁定：

| 资源 | pfUI／原生对象 | 当前候选几何 | 实现约束 |
|---|---|---|---|
| 主书框九宫格 | `pfUI.chat.left` | 外扩左右各 10，上 26、下 16；正文内缩左右 42、上 50、下 58 | 只跟随 owner 尺寸和位置 |
| Tab 承托带 | `pfUI.chat.left.panelTop` 所在区域 | 左右内缩 35，高 64，上移 24 | 连续无槽，不决定 Tab 数量 |
| Tab 三段贴图 | `ChatFrameNTab` | 高度由 pfUI 字号与 `panelTop` 决定，宽度由真实 Tab 决定 | 不改 Parent、Point、Width、Height 或点击框 |
| 未读蜡封 | `ChatFrameNTab` 的覆盖层 | 当前候选 15 × 15 | 只响应 `TabFlash`，不参与布局 |
| 输入区三段贴图 | `ChatFrameEditBox` | 当前候选高 26、左右文字内边距 12 | 只换肤；最终锚点服从 pfUI |
| 底栏三段贴图 | `pfUI.panel.left.left/center/right` | 当前候选高 22、段间距 3 | 三个真实字段分别实例化 |

一个“看起来像”的固定槽位。

## 四、需要制作的源资源

### A. 主书框母版

文件：`ChatBookFrame_BaseMaster_v2.png`

- 原始生成图长边不得低于 1536 px；首选工作母版为 `2048 × 1536`
- 不得把小图机械放大后冒充高精度母版
- 正交正视图，不使用透视
- 真透明背景，不使用黑底
- 无文字、无固定 Tab、无按钮、无滚动条、无底栏字段
- 主体为深棕旧封皮包围两至四层毛边书页
- 中央烟熏羊皮纸低对比度、可平铺、没有大污渍
- 四角可局部不对称，但九宫格连接线必须水平／垂直对齐
- 上下横边必须共享明确基线；角件只能向透明安全区外伸
- 金属占比低于纸张和皮革，仅使用暗哑氧化黄铜
- 不出现龙头、尖塔、宝石底座、符文光效或规则工业网格

由该母版确定性导出九宫格：

- 左上角、右上角、左下角、右下角
- 上边、下边、左边、右边
- 中央纸张填充

运行时可以打包为一个 `1024 × 1024` 图集，但 Lua 必须按九个独立区域绘制。

### B. 顶部连续承托带

文件：`ChatTabShelf_Master_v2.png`

- 建议源尺寸：`1024 × 128`
- 横向可平铺或三段拉伸
- 旧皮革／书页夹层结构
- 不包含任何竖向分隔、固定槽位或标签轮廓
- 与主书框上沿材料一致，但对比度更低
- 作用仅为承接 pfUI 的真实 Tab
- 运行时固定拆为左端、可重复中央段和右端，避免两端被横向拉伸

### C. Tab 状态母版

文件：`ChatTabStates_Master_v2.png`

状态：

1. 普通
2. 悬停
3. 选中
4. 禁用

每个状态必须：

- 使用同一个透明画布尺寸和完全相同的底基线
- 无文字；频道名由 pfUI 绘制
- 是插入书页边缘的旧皮革索引签，不是黄铜铭牌或网页标签
- 普通态后退、低对比度
- 悬停态只增加轻微暖金边缘
- 选中态上抬约 4–6 UI 单位并变暖，不改变点击框位置
- 禁用态降低饱和度和亮度
- 中央必须能横向拉伸，端部铆钉和磨损不能被拉伸

运行时采用三段式，而不是整张拉伸：

- 左端帽
- 中央可重复／可拉伸段
- 右端帽

四种状态共十二个切片，可打包为一个 `1024 × 512` 图集。

其中普通、悬停、选中和未读覆盖是当前 pfUI 接入的运行时必需状态。
禁用态来自锁定视觉规范，先保留在源图集中；只有在几何测量中确认 pfUI
存在可稳定判断的禁用状态后才接入 Lua。

### D. 未读提示

文件：`ChatUnreadSeal_v2.png`

- 运行时 `64 × 64`
- 暗紫红蜡封或布质线结
- 真透明背景
- 默认不发光；未读时短暂出现
- 不使用红点、数字气泡或现代通知徽章

### E. 输入区

文件：`ChatInputStrip_Master_v2.png`

状态：

1. 默认
2. 输入焦点

要求：

- 书页内部的墨线／浅压痕／稍深纸带
- 不使用黑色矩形输入框
- 三段式：左端、可拉伸中央、右端
- 焦点态只加深墨线或增加非常轻微的暖色边缘
- 不包含文字和光标

### F. pfUI 左底栏

文件：`ChatPanelSegment_Master_v2.png`

- 一个可复用的三段式皮革／书页字段
- 应用于 pfUI left／center／right 三个真实段
- 无固定宽度、无文字、无图标
- 三个段之间只保留 2–3 UI 单位间隙
- 不得烘焙成主书框下沿的一部分

## 六、最终运行时物理文件

本轮需要 34 个逻辑切片，但只打包为以下 6 张物理纹理：

| 文件 | 建议画布 | 内容 |
|---|---:|---|
| `ChatBookFrameAtlas.tga` | 1024 × 1024 | 主框九宫格 |
| `ChatTabAtlas.tga` | 1024 × 512 | 四状态、三段式 Tab |
| `ChatTabShelf.tga` | 1024 × 128 | 连续承托带三段 |
| `ChatInputAtlas.tga` | 512 × 256 | 默认／焦点输入区 |
| `ChatPanelAtlas.tga` | 512 × 128 | 三段式底栏字段 |
| `ChatUnreadSeal.tga` | 64 × 64 | 未读提示 |

全部运行时资源必须：

- 32 位 TGA
- 2 的幂尺寸
- 真 Alpha
- UV 周围保留至少 4 px 防渗色边距
- 不含任何文字
- 不依赖大面积顶点染色修正颜色

### 精度约束

- Turtle WoW 当前只验证过 `1024 × 1024` 纹理；高分辨率用于源母版，不
  直接把未经验证的 2048 纹理交给客户端。
- 九宫格和三段式切片在图集中按实际屏幕占用分配像素，不能让大面积透明区
  挤占主要像素预算。
- 缝线、铆钉和毛边等最细的有效结构，在标准 `440 × 320` 预演中不得细于
  2 个屏幕像素；更细的随机噪声会在双线性采样后变脏，应删除。
- 所有缩放只允许发生在中央纸面、横边中段、竖边中段和控件中央段；端帽、
  包角、铆钉、缝线结与缺口必须保持原始比例。
- 预览必须同时提供 100% 像素视图和游戏内合成视图，不能只看放大的 PNG。

## 七、生成批次

不再一次生成完整 UI。建议分三批：

1. 主书框母版
2. Tab 承托带与四状态索引签
3. 输入区、底栏字段与未读蜡封

每一批流程固定为：

1. 用户确认该批专业提示词
2. 使用已授权的参考图执行 imagegen
3. 只保存原始候选到 `generated/`
4. 本地去背景、切片并制作三尺寸预览
5. 用户确认后才进入 `assets/source/` 和运行时目录

未经确认的生成图不得进入 `assets/locked/`。

## 八、验收尺寸

每批资源至少预演：

- 紧凑：`400 × 300`
- 标准：`440 × 320`
- 展开：`540 × 420`
- 当前实机截图比例：约 `1.29`

检查项：

- 四角不被横向或纵向拉伸
- 上下横边在同一基线连接，无台阶
- Tab 在切换状态时只换贴图，不改变父级、锚点和点击框
- 第一个 Tab 不覆盖左侧书脊
- Tab 数量变化时背景不暴露固定空槽
- 输入区与三个底栏字段独立对齐
- 正文安全区左右至少 28 UI 单位，上下至少 22 UI 单位
- 第一眼仍然是旧书，而不是规整复古面板
