# 字体系统与运行时策略

## 状态

本文件定义 UI overhaul 的第一版字体实现基线。

- 美术职责：已收敛。
- 字体文件与许可证：已纳入仓库。
- Turtle WoW `1.18.1` 实机兼容：待验证。
- 全局替换客户端字体：明确禁止。

## 设计原则

艾泽拉斯感不能依赖一款“奇幻字体”覆盖所有文字。字体必须服从香草魔兽原有的信息层级：

1. 旧书、卷宗与远征笔记负责冒险和征程感。
2. 厚重衬线标题负责庄重和史诗感。
3. 客户端原有英文、数字与高密度字体负责香草辨识度和战斗可读性。

中文字体不应呈现明显的现代网页排版，也不能因过度书法化而把西方奇幻世界变成东方武侠或古籍界面。

## 已纳入字体

| 文件 | 版本／状态 | 主要职责 | 发布状态 |
|---|---|---|---|
| `LXGWWenKaiGB-Medium.ttf` | 1.522，官方静态 TTF | 任务名、聊天频道签、地图注释、卷宗标签 | 运行时候选 |
| `NotoSerifSC-SemiBold.ttf` | 2.003-H1，`wght=600` 静态实例 | 面板主标题、章节标题、庄重短标签 | 运行时候选 |
| `NotoSansSC-Medium.ttf` | 2.004-H2，`wght=500` 静态实例 | 高密度中文信息的二级回退 | 可选运行时候选 |
| 客户端本地字体 | 不进入仓库 | 英文标题、战斗数字、聊天正文、团队信息 | 运行时引用 |

字体文件位于 `addon/AzerothExpeditionUI/Media/Fonts/`。来源、许可证和校验值位于 `third-party/fonts/`。

## 组件映射

| 组件 | 标题／标签 | 正文／数字 |
|---|---|---|
| 战地旧书聊天框 | 频道签和书页短标题使用霞鹜文楷 | 聊天内容、时间戳和玩家名优先使用客户端高可读字体 |
| 任务详情 | 章节主标题使用 Noto Serif；任务名可使用霞鹜文楷 | 长正文优先使用客户端正文；后续单独验证衬线正文 |
| 任务追踪 | 短标题和任务名可使用霞鹜文楷 | 进度、计数和等级优先使用客户端字体 |
| 大地图 | 地图标题使用 Noto Serif；手写注释使用霞鹜文楷 | 坐标和缩放信息优先使用客户端字体 |
| 小地图 | 方位或区域标题使用客户端／Noto Serif | 坐标、时间、插件按钮计数优先使用客户端字体 |
| 角色面板 | 面板主标题和分区标题使用 Noto Serif | 属性值、等级、耐久和装备信息优先使用客户端字体 |
| 团队、DPS、仇恨、消耗品 | 不使用装饰性字体 | 使用客户端高可读字体；缺失时回退 Noto Sans |

Noto Sans SC 不是默认美术层。只有客户端中文字形缺失、异常或在目标分辨率不可读时，才允许按组件启用；不能借它把全套 UI 重新做成现代无衬线界面。

## 推荐视觉参数

这些数值是实现起点，需要结合 UI Scale 实机微调。

- 羊皮纸正文：深棕 `#2B1B10` 至 `#3B2A1D`，不使用粗描边。
- 深皮革或金属标题：旧象牙 `#D2B77E` 或暗金 `#C4A15A`。
- 标题阴影：右下 1px，低透明深棕；禁止发光和 2–3px 粗黑描边。
- 标题字号：约 16–20px。
- 正文字号：约 12–14px。
- 战斗和团队字号：按信息密度缩小，但不得使用霞鹜文楷。
- 不使用 Light 字重，不使用持续外发光，不以大面积纯白代替纸张和金属对比。

## 加载与回退

1. 从插件目录按相对路径加载字体，不写入或覆盖游戏安装目录的全局 `Fonts`。
2. 首选静态 TTF；不在目标客户端验证之前加载变量 TTF、TTC／OTC、WOFF／WOFF2。
3. 每个装饰性字体职责必须有客户端字体回退路径；Noto Sans 只处于客户端中文字体之后。
4. 字体加载失败不得阻止模块加载；只回退文字外观。
5. 不在仓库中保存客户端自带字体二进制。

建议回退顺序：

```text
叙事标题：LXGWWenKaiGB-Medium.ttf → 客户端中文字体
庄重标题：NotoSerifSC-SemiBold.ttf → 客户端中文字体
高密度中文信息：客户端字体 → NotoSansSC-Medium.ttf
英文与数字：客户端香草字体 → 客户端默认字体
```

## 实机验收清单

- 冷启动与 `/reload` 后字体都能正常加载。
- 下列样例无缺字、方框或错误替换：
  - `艾泽拉斯远征任务聊天角色属性`
  - `伤害 仇恨 治疗 暴击 100%`
  - `：；，。！？“”‘’（）【】—…·`
- 中文、英文、数字和品质色文字基线一致。
- `1920×1080`、常见 4:3、16:9、超宽屏及不同 UI Scale 下不糊成一片。
- 四十人团队、DPS 和仇恨数字在高法术亮度背景中仍能快速扫描。
- 长任务名、服务器自定义名称和插件本地化文本不会越界。
- 对比首次加载前后的内存占用；若多份全字库同时常驻代价过高，允许按模块延迟加载、禁用 Noto Sans 回退或只保留一份外部字体。

## 锁定条件

只有完成目标客户端实测后，才能把“运行时候选”改为“发布字体”。如果 Noto 静态实例无法稳定加载，第一版应保留霞鹜文楷作为叙事标题字体，并让庄重标题和高密度信息回退到客户端字体；不得为了保留设计稿效果而修改整个客户端字体环境。
