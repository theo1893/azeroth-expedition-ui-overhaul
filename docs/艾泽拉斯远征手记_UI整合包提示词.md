# 艾泽拉斯远征手记：魔兽世界乌龟服 UI 整合包提示词

## 项目背景

本项目面向《魔兽世界》1.18.1 乌龟服，使用 pfUI 及各种单体插件作为功能基础。

现有界面的主要问题：

- pfUI 的视觉语言过于现代、扁平和轻量，削弱了经典魔兽原本厚重、史诗和奇幻的氛围。
- 不同单体插件使用了互不相关的边框、字体、状态条、按钮和材质，造成明显的视觉割裂。
- 战斗功能虽然齐全，但地图、聊天、单位框架、伤害监控、仇恨监控和消耗品监控之间缺少统一的美术体系。

本整合包的目标不是简单复刻原版界面，而是在保留经典魔兽美术气质的前提下，建立一套更完整、更统一、更具史诗感与魔幻感，同时适合长期游玩的 UI 设计系统。

主题名称：**艾泽拉斯远征手记**

---

# 第一部分：总体设计提示词

你是一名熟悉《魔兽世界》经典版本、乌龟服插件生态与奇幻游戏界面的资深 UI 美术总监。请为《魔兽世界》1.18.1 乌龟服设计一套完整、统一、可长期扩展的 UI 整合包视觉系统，以 pfUI 及各种单体插件作为功能基础，重新建立统一的美术外观。

这套 UI 的主题名为“艾泽拉斯远征手记”。整体感觉应当像由探险者、战地书记官、矮人工匠与奥术师共同制作的一套冒险装备：厚重、古老、手工打造、经历过战火，同时带有克制的史诗感与魔法感。

不要追求现代、扁平、轻量或科技化的界面。保留经典魔兽 UI 的手绘质感、实体材料感、夸张轮廓与奇幻装饰，但要提升整体一致性、信息层级和战斗可读性。所有插件看起来都必须属于同一个世界，而不是来自不同作者的独立窗口。

## 统一视觉语言

基础材质限定为五类：

- 做旧羊皮纸：用于地图、任务、说明和世界信息。
- 深棕色旧皮革：用于聊天、背包、消耗品和辅助面板。
- 锻造黑铁：用于战斗、单位框架、技能栏和高强度功能。
- 氧化黄铜或暗金：用于边框、铆钉、刻度、标题和重要交互。
- 魔法符文与宝石：仅用于激活、施法、预警和特殊状态，不作为大面积装饰。

主色调使用炭黑、黑铁灰、牛血棕、旧皮革褐、羊皮纸米黄、氧化黄铜和烛光金。奥术蓝紫、自然绿、圣光金、邪能绿与危险红仅作为状态色。避免大面积高饱和颜色。

所有窗口共享同一套边框厚度、圆角方式、铆钉、角饰、按钮、标签、标题牌、滚动条、状态条和悬浮反馈。造型以略微不规则的手绘边缘、切角、金属包边和磨损痕迹为主，但不要让污渍或纹理干扰文字。

## 地图系统

世界地图和区域地图采用展开的旧羊皮卷结构，带有卷边、折痕、磨损、淡淡水渍和手绘墨线。上下使用深胡桃木卷轴杆与氧化黄铜端帽固定，皮革只作为少量连接件，不使用连续厚皮背板。

地图按钮设计成黄铜徽章、蜡封或小型皮革标签；任务标记与地点标记采用手绘图章和珐琅徽记。小地图采用“羊皮卷地图嵌入黄铜罗盘”的结构，保留清晰的方向、时间、追踪和缩放信息，不要因装饰牺牲地图面积。插件图标允许在罗盘附近挂载，但不得固化为环绕整个小地图的永久按钮轨道。

## 聊天系统

聊天框表现为一本摊开的旧战地日志或皮革封面的冒险者手记。文字区域使用略暗的烟熏羊皮纸，避免亮色纸张影响战斗环境中的阅读。

聊天标签设计成夹在书页边缘的布质书签或皮革索引；输入框表现为墨水书写区域；频道、密语、系统和战斗记录使用克制、统一的颜色体系。非交互状态下弱化封面与边框，鼠标悬停时再显示完整书本结构，避免聊天框长期占据过多视觉注意力。

## 玩家、目标、小队与团队框架

玩家和目标框架采用锻造黑铁主体、旧黄铜包边和少量皮革衬底，整体像战士的护甲铭牌或收藏英雄肖像的战争圣龛。

玩家与目标头像放在圆形或盾形黄铜肖像章中；生命、法力、怒气和能量条嵌入金属凹槽。职业颜色只用于细边、宝石或短刻度，不要铺满整个框架。

小队框架使用简化的盾牌铭牌结构。团队框架进一步精简为“军团名册”：不显示复杂肖像，以紧凑黑铁铭牌、清晰生命条、职业印记、职责符号、距离、死亡、驱散和减益状态为核心。装饰集中在团队面板外框，不要给每个成员重复复杂花纹。

## DPS 与仇恨监控

DPS 监控表现为“战地书记官的战果账簿”：深色皮革或旧木板底座、羊皮纸标题条、黄铜排名数字以及墨迹式数据条。职业色仅作为窄条或徽记，数值右对齐，重点突出排名、伤害、秒伤和占比。

仇恨监控表现为“战争指挥板”：使用更坚固的黑铁框架和符文刻度。当前坦克以暗金标记，玩家接近仇恨阈值时依次出现烛火黄、琥珀色和深红色反馈；获得仇恨时使用一次短促的红色符文脉冲，不要让整个窗口持续闪烁。

两个监控窗口必须共享相同的标题栏、列表间距、状态条造型、按钮和缩放逻辑。

## 消耗品监控

消耗品监控设计成“炼金师药剂腰包”或展开的皮革卷袋。食物、药剂、合剂、卷轴、武器油、毒药、施法材料和职业专属物品分别放在统一的皮革槽位中。

保留原始物品图标以保证辨识度，只统一图标外框、计数角标、冷却遮罩和缺失状态。数量充足时低调显示；数量偏低时出现琥珀色蜡封；完全缺失时使用破裂的红色封印；增益即将结束时出现缓慢燃烧的金色边缘。

## 其他需要纳入统一设计的模块

- 动作条、姿态栏、宠物栏与背包栏：黑铁与皮革腰带式插槽。
- Buff、Debuff 与冷却：黄铜符文框；负面效果使用轻微破损或尖角轮廓。
- 施法条：刻有符文的金属导槽，魔法能量在槽内流动。
- 姓名板：远距离保持极简，只在选中、施法或危险状态下增强装饰。
- 任务追踪：钉在皮革板上的冒险便笺。
- 背包、银行和仓库：旅行箱、皮革包与黄铜锁扣。
- 角色、声望、技能、法术书、专业和天赋：冒险者档案册与魔法典籍。
- 商人、拍卖、邮件和交易：沿用羊皮纸、皮革与黄铜组件，不另创美术体系。
- 战利品、掷骰、准备确认、复活、驱散、首领警报和任务完成提示。
- Tooltip、菜单、配置界面、移动解锁模式以及插件错误提示。

## 默认布局与信息层级

保持屏幕中央大面积无遮挡。玩家与目标框架位于屏幕中下方；动作条位于两者下方；施法、重要冷却与消耗品位于视线附近；聊天位于左下；DPS 与仇恨位于右侧并可切换；小地图位于右上；任务追踪靠近地图；小队和团队框架位于左侧。

界面需适配不同分辨率与缩放比例。非战斗模块可以拥有较丰富的材质，战斗模块必须降低纹理复杂度并突出数值、血量、施法、减益和仇恨状态。

## 字体与动态效果

标题使用厚重、略带碑刻感的奇幻衬线字体；正文和数字使用高辨识度字体。中文界面避免使用难以阅读的伪古典字体，可在标题中采用克制的碑刻或书卷气质，正文仍以清晰为先。

动效只使用短促、低频的符文亮起、余烬脉冲、墨迹展开、羊皮卷舒展和金属高光。普通操作不要持续发光或播放粒子效果。所有效果必须保证旧客户端的稳定性和团战性能。

## 禁止出现的风格

禁止现代扁平化、玻璃拟态、透明亚克力、科技 HUD、霓虹描边、纯黑极简卡片、统一大圆角、纤细无衬线字体、移动应用式布局、大面积渐变、过度留白以及零售版魔兽式现代面板。

同时避免另一极端：不要堆满骷髅、尖刺、巨大龙头和高亮符文；不要让每个窗口使用不同材质；不要用重度污渍掩盖文字；不要改变玩家已经熟悉的物品、技能和状态图标含义。

最终方案应首先建立共享的组件与材质规范，再分别设计各插件皮肤；所有模块即使单独关闭或移动，也仍能明显属于“艾泽拉斯远征手记”这一套完整视觉体系。

# 第三部分：公共风格前缀

为《魔兽世界》1.18.1 乌龟服设计“艾泽拉斯远征手记”主题 UI 组件。保留经典魔兽界面厚重、手绘、夸张、奇幻和实体材质的感觉，消除 pfUI 过于现代、扁平、轻量和科技化的视觉特征。

所有组件必须属于同一套材质系统：世界与任务信息使用做旧羊皮纸；社交与辅助功能使用旧皮革和书本；战斗功能使用锻造黑铁与氧化黄铜；魔法、激活和预警状态使用克制的符文、宝石与能量光效。

主色为炭黑、黑铁灰、牛血棕、旧皮革褐、羊皮纸米黄、暗金和氧化黄铜。职业色、法术色、危险红与仇恨橙只作为窄边、徽记、宝石、刻度或状态提示，不得大面积铺满组件。

采用经典奇幻游戏的二维手绘材质表现，而不是写实摄影材质。所有边框、角饰、铆钉、标签、按钮、状态条和滚动条使用统一造型。界面应当像真实存在于艾泽拉斯世界里的远征装备，但信息可读性始终高于装饰性。

基础版本保持阵营中立。联盟、部落和职业主题仅通过可替换的纹章、角饰和强调色体现，不改变组件结构。

# 第四部分：组件级提示词

## 1. 整体 HUD 布局

设计一套适用于单人探索、五人小队、团队副本和 PvP 的完整 HUD 布局。保持屏幕中央大面积无遮挡，让玩家能够清楚观察角色、敌人、地面效果和战斗环境。

玩家与目标框架位于屏幕中下方，动作条位于两者下方；施法、重要冷却和消耗品靠近中心视线，但不得遮挡角色脚下区域。聊天框位于左下，小队与团队框架位于左侧，地图位于右上，任务追踪位于地图下方，DPS 与仇恨监控位于右侧并支持切换或折叠。

提供探索、五人副本和团队副本三种信息密度。非战斗时保留较丰富的书本、羊皮纸与金属细节；进入战斗后自动弱化非必要边框、标题和背景，强化血量、施法、仇恨、减益、冷却和消耗品状态。

## 2. 世界地图与小地图

将世界地图设计成展开的远征羊皮卷。使用一整张连续羊皮纸、磨损卷边、浅折痕、墨线、淡水渍和局部修补痕迹，上下由深胡桃木卷轴杆与氧化黄铜端帽固定，皮革只作为少量固定带。纹理必须低对比度，不能干扰地形、道路、区域名称和任务范围。

地图标签使用皮革索引，区域切换按钮使用黄铜徽章，任务目标使用手绘墨水标记，重要地点使用珐琅徽记。玩家、队友、尸体、商人和任务标记必须保持明显不同的轮廓。

小地图采用“羊皮卷地图嵌入黄铜罗盘”的结构。方向刻度刻在双层氧化黄铜圆环上，顶部保留明确的北方指针；时间、坐标、追踪与缩放融入底部铭牌、右侧拨片和右下皮革吊牌。邮件、日历和插件入口可在罗盘附近挂载，但默认母版不得形成永久插件槽环或杂乱按钮圈。

## 3. 聊天框与战斗记录

将聊天框设计成摊开的战地日志或皮革封面的冒险手记。文字区域使用偏暗的烟熏羊皮纸，边缘能够隐约看到书页层叠和皮革封面，但不要绘制厚重立体书本遮挡游戏画面。

综合、队伍、公会、密语和战斗记录标签设计成夹在书页边缘的布质书签或皮革索引。当前标签使用烛光金边，未读密语使用短暂的紫色蜡封提示。文字输入框表现为书页下方的墨水书写区域，频道选择按钮表现为小型羽毛笔或黄铜印章。

未交互时降低封面、边框和按钮存在感；鼠标进入后再显示完整标签、缩放、锁定和滚动控件。频道颜色保持清晰，但整体降低荧光感。

## 4. 玩家、目标、宠物与目标的目标

玩家和目标框架采用锻造黑铁主体、氧化黄铜包边与深色皮革衬底，造型类似英雄护甲铭牌或战争圣龛。玩家和目标头像放入圆形或盾形肖像章中，肖像周围使用克制的职业纹章、精英冠饰、稀有标记和 PvP 标记。

生命、法力、怒气、能量和其他资源条嵌入金属凹槽。生命条保持高度清晰，损失部分呈现暗色凹槽；资源条使用对应颜色，但降低现代 UI 式纯色饱和感。生命百分比、实际数值、等级、姓名和状态必须拥有稳定的信息层级。

宠物框架使用尺寸更小的同系金属铭牌。目标的目标使用简化盾牌框，仅保留姓名、生命、敌友关系和仇恨指示。死亡、离线、超出距离、不可攻击、被控制和施法状态均需设计独立状态。

## 5. 小队与团队框架

小队框架设计成由黄铜铰链连接的一组小型盾牌铭牌，可以保留简化肖像。每个成员显示生命、资源、职业、职责、距离、死亡、离线、仇恨和可驱散减益。队长、主坦克和标记目标通过小型金属徽章区分。

团队框架设计成紧凑的“军团名册”。成员单元使用黑铁底板、黄铜细边和皮革标签，不显示复杂肖像。职业色只作为左侧窄条或角标；团队分组使用皮革标题签连接。

可驱散减益必须优先于装饰显示；关键减益可扩大图标，但不能覆盖全部生命信息。团队装饰集中在整个面板的外框和分组标题，避免给几十个成员重复添加复杂花纹。

## 6. 姓名板

姓名板采用轻量化的锻造金属铭牌，只保留生命、姓名、等级、施法和必要状态。普通非目标单位使用低对比度深铁条；当前目标增加黄铜包边；精英和首领增加小型冠饰；友方与敌方通过文字、细边和徽记区分。

仇恨安全时保持暗金刻度，仇恨上升时转为琥珀色，获得仇恨时显示短促的深红符文。施法条嵌在生命条下方，可打断法术与不可打断法术使用不同的符文端点。不要给每块姓名板加入肖像或厚重装饰。

## 7. 动作条、姿态栏与微型菜单

将动作条设计成一条由皮革腰带连接的黑铁技能插槽。保留技能图标原始画面，只统一外框、冷却遮罩、按键文字、层数、不可用状态和触发高亮。

技能可用时出现非常轻微的黄铜边缘高光；触发重要技能时使用一次符文点亮；资源不足、距离过远和冷却中必须能够快速区分。不要持续播放旋转光圈或高亮动画。

姿态、形态和宠物技能栏使用较小的徽章式插槽。背包、角色、法术书、任务和系统菜单采用黄铜吊牌或皮革工具扣造型，在非悬停状态下保持低调。

## 8. Buff、Debuff、冷却与施法条

Buff 图标使用完整、平滑的黄铜符文框；Debuff 图标使用轻微破损、尖角或暗红铆钉边框。保留原始法术图标，统一层数、持续时间、可驱散类别和来源标记。

即将结束的增益出现缓慢消退的金色边缘；高危减益使用一次短促红色脉冲。不要让所有 Buff 同时发光。

施法条设计成符文雕刻的金属导槽，施法能量在凹槽内推进。不同法术类型可使用克制的奥术蓝紫、自然绿、火焰橙和圣光金。引导法术显示黄铜刻度，不可打断状态通过封闭式端点或锁定符文表现。

## 9. DPS 监控

将 DPS 监控设计成“战地书记官的战果账簿”。主体使用深色皮革或旧木板，顶部嵌入羊皮纸标题签，排名使用黄铜数字，数据条表现为写在账簿中的墨迹条或嵌入木板的低浮雕条。

每行显示排名、职业徽记、姓名、总伤害、秒伤和占比。职业色仅用于狭窄的数据条或小型徽记。当前玩家使用暗金定位线，不要使用大面积高亮背景。

切换战斗记录、伤害、治疗、承伤、驱散和死亡时，使用统一的皮革索引标签。重置、报告、锁定和关闭按钮设计成小型黄铜印章，默认隐藏在悬停状态中。

## 10. 仇恨监控

将仇恨监控设计成“战争指挥板”，视觉上比 DPS 账簿更加坚固、紧迫。使用黑铁底座、黄铜刻度、皮革姓名签和少量符文状态。

当前坦克以暗金盾牌标记；安全目标使用低亮度黄铜条；玩家接近仇恨阈值时依次出现烛火黄、琥珀橙和深红色。获得仇恨时使用一次红色符文冲击，并在玩家所在行留下清晰的危险标识。

面板顶部显示当前目标肖像章、名称和仇恨阈值。DPS 与仇恨监控应共享尺寸、标题栏、列表行高、滚动条和按钮，可在同一容器内通过“战果／威胁”皮革标签切换。

## 11. 消耗品与职业资源监控

将消耗品监控设计成展开的“炼金师皮革卷袋”。药水、合剂、食物、卷轴、武器油、毒药、绷带、施法材料和职业专属物品分别放入统一的皮革槽位。

数量充足时仅显示低调计数；数量偏低时出现琥珀色蜡封；完全缺失时显示破裂的红色封印；物品正在冷却时使用统一的暗色径向遮罩。增益已激活、即将结束和未激活必须拥有明显但克制的差异。

支持“冒险、地下城、团队、PvP”四套预设清单。非战斗时可展开为完整清单，战斗中折叠成只显示缺失、即将结束和可立即使用项目的快捷条。

## 12. 任务详情、任务追踪与任务对话

任务模块采用“公会任务卷宗与行军便笺”设计体系。

按 `L` 打开的任务详情面板表现为一本正式装订的冒险者公会任务卷宗：横向双页厚书、清晰中央书脊、三至四层毛边书页、深胡桃与暗酒红封皮、氧化黄铜包角以及插在书页侧边的织物章节书签。左页用于地域分组与任务目录，右页用于任务标题、叙述、目标和奖励。当前任务由暗酒红织物书签指示，不能使用现代高亮卡片。

游戏页面中的任务追踪表现为从任务卷宗中抽出的行军便笺：两至三张纵向错位的灰赭纸页，由顶部窄皮带与黄铜铆钉固定，底部保留自然撕边。多个任务共用连续纸面，通过留白、短墨线和小型书签区分，不得把每个任务做成独立卡片，也不得出现完整封皮或四周封闭边框。

任务标题使用较厚墨迹，目标正文保持清晰；完成目标使用羽毛笔勾记并降低墨色，整项完成增加小型暗红蜡封。普通、连续、精英、地下城、团队和限时任务分别使用羽毛笔、锁链、旧盾牌、石门、公会封印和沙漏等小型压印区分。

NPC 任务对话保持经典羊皮纸书页感，接受、继续和完成按钮使用黄铜印章或蜡封。任务完成可出现一次非常短的金色墨迹扩散，不要采用现代横幅通知。

任务详情、任务追踪和聊天框共享纸张、皮革、氧化黄铜、笔触和光照方向，但装订方式与外轮廓必须明显不同。完整锁定规范见：[任务模块视觉规范_公会任务卷宗与行军便笺_v1.md](./modules/quests/任务模块视觉规范_公会任务卷宗与行军便笺_v1.md)。

## 13. 背包、银行、战利品与掷骰

背包和银行设计成打开的旅行箱、皮革背包或补给箱内部。物品格使用统一的深皮革凹槽与黄铜细边，保留物品品质颜色，但只作用于细框和角标。

分类标签表现为缝在包袋上的皮革牌，搜索框表现为行李清单。新获得、任务物品、装备、材料、垃圾和已锁定物品需要清晰状态。

战利品窗口设计成展开的小型战利品清单；需求、贪婪、放弃采用不同的黄铜徽章。高品质物品可以增强边框和短暂光效，但不要改变原始物品图标，也不要持续大面积发光。

## 14. 角色、声望、法术书、天赋与专业

角色界面采用已锁定的“香草同构角色面板 V1”。它不是横向“英雄档案与军械册”，而是对 60 级香草 `CharacterFrame / PaperDollFrame` 的紧凑同构重绘：中央完整人物纸娃娃，左右两列经典装备槽，下方双列属性，底部三个武器／圣物槽，以及 `角色／声望／技能／PVP` 四个小型页签。外轮廓保持近矩形，材料使用深胡桃旧皮革、暖赭羊皮纸和暗哑氧化黄铜；品质色只作为低饱和窄内沿。

角色面板不得增加大型肖像章、龙头、翅膀、祭坛、拱门、涡卷宝石底座、彩色数值格、横向双栏或现代人物仪表板。完整锁定规范见：[角色属性模块视觉规范_香草同构角色面板_v1.md](./modules/character/角色属性模块视觉规范_香草同构角色面板_v1.md)。

声望界面表现为外交名册，阵营纹章作为主要识别；法术书保留厚重魔法典籍感；天赋界面使用符文树、黄铜节点和羊皮纸说明；专业界面表现为工匠手册与材料清单。

这些大型系统窗口必须共享页签、标题、关闭按钮、滚动条和底部操作区，不允许每个面板使用完全不同的书本或金属造型。

## 15. 商人、拍卖、邮件与交易

将经济与社交交易界面设计成“艾泽拉斯商会账簿”。商人和交易窗口使用皮革账本、羊皮纸清单与黄铜价格牌；金币、银币和铜币拥有统一且清晰的排列。

拍卖行采用信息密度更高的账簿式布局，减少不必要装饰，确保搜索、筛选、排序、价格和竞价信息清晰。邮件界面采用信纸、信封、蜡封和邮戳元素，附件放置在皮革收纳槽中。

购买、出售、寄送、竞价和确认等不可逆操作使用一致的黄铜印章按钮，并通过文字与状态反馈区分，不能只依赖颜色。

## 16. Tooltip、菜单与确认窗口

Tooltip 设计成一张铺在深色皮革底板上的小型羊皮纸卡片，使用黄铜细边和轻微投影。物品名称、品质、等级、绑定、属性、套装、售价和比较信息建立明确层级。

右键菜单采用紧凑的皮革菜单条；普通确认窗口使用黄铜锁扣与羊皮纸正文；危险操作使用暗红蜡封和明确文字。不要把所有弹窗都设计成厚重的大型书本。

Tooltip 必须能在明亮雪地、昏暗洞穴和高饱和法术环境中保持可读性，并避免纹理穿过小号文字。

## 17. 首领警报与战斗提示

将首领警报设计成“符文战争号令”。普通机制提示使用窄型黑铁铭牌，重要机制增加暗金端点，致命机制使用深红符文与一次短促冲击。

倒计时条表现为刻有分段刻度的金属导轨。首领技能图标保留原貌，提示文本直接、醒目，装饰只出现在条形两端。屏幕中央的警报必须短暂出现并快速退场。

不使用现代霓虹横幅、持续屏幕闪烁或大量粒子。危险等级必须同时通过颜色、轮廓、符号和动效强度表达，避免仅依赖红绿色差异。

## 18. 设置、编辑模式与性能状态

将整合包设置界面设计成“工匠工作台手册”。左侧是皮革目录，右侧是羊皮纸配置页；复选框使用黄铜铆钉，滑杆使用带刻度的金属导轨，下拉菜单使用皮革标签。

编辑模式为所有 HUD 模块显示低透明度黄铜轮廓、模块名称、锚点、尺寸和吸附参考线。锁定后这些辅助元素必须完全消失。

插件错误、延迟、帧率、耐久和背包空间等状态集中在小型“远征仪表”中，使用黄铜表盘和皮革标签，不要散落成多个风格不同的小插件窗口。

# 第五部分：统一验收尾缀

为该组件同时定义默认、悬停、按下、选中、禁用、缺失、警告、危险、离线、死亡、超出距离和战斗状态；并说明组件在紧凑、标准和展开三种信息密度下的表现。

装饰边框不得占据战斗组件超过约 10% 的有效面积，非战斗窗口不得超过约 15%。单一组件同时出现的主要材质不超过三种。

保证中文、英文、数字和百分比均可清晰显示。适配常见的 4:3、16:9 与超宽屏布局，支持缩放、移动、锁定和隐藏，但不同尺寸下不得改变核心视觉身份。

检查该组件与地图羊皮纸、聊天书本、黑铁单位框架、DPS 账簿和消耗品皮革卷袋能否自然共存。禁止扁平化、玻璃拟态、科技 HUD、霓虹描边、统一大圆角、现代移动应用卡片和无意义的持续发光。

建议依次完成以下阶段：
