# 全局 Overhaul 美术基线 Prompt

这是整个项目唯一的跨模块美术基线。模块 Prompt 必须继承它，但不能机械复制
其他模块的物件轮廓。目标客户端是 Turtle WoW `1.18.1`／Interface `11200`。

## 可直接继承的全局 Prompt

为《魔兽世界》60 级香草时代制作一套统一的二维手绘位图 UI overhaul，
主题为“艾泽拉斯远征手记”。首先保留 2004 年前后香草魔兽原组件的轮廓、
布局、信息密度和操作习惯，其次才以远征装备的材料与磨损强化厚重、史诗、
魔幻和长期冒险感。最终界面必须像艾泽拉斯世界中真实使用的装备，而不是把
现代 HUD 染成棕色。

使用粗厚、略不规则且带手工误差的轮廓，明确的亮面／中间面／阴影切面，
略微夸张但清晰可读的实体厚度，以及香草时代低分辨率手绘位图质感。所有模块
共享左上方暖光、低饱和综合色温、相同磨损尺度和相同绘制精度。装饰集中在
不可拉伸边缘、连接件和交互件；主要文字、地图、角色模型、图标与战斗信息区
保持安静、连续、低对比。

共用材料为暖赭烟熏羊皮纸、深胡桃旧皮革、暗哑氧化黄铜、少量深胡桃木和
克制黑铁。纸张负责阅读与记录，皮革负责包覆、连接和承托，黄铜负责包角、
铆钉、刻度与重要交互，木材只用于合理的卷杆或承托，黑铁只用于必要的战斗
结构。材料必须有不同厚度、接触阴影、磨损和反光方式，不能只用颜色区分。

推荐色域：旧书页 `#B8955C`，纸页高光 `#D2B77E`，纸页阴影
`#76512E`，深棕封皮 `#28180E`，氧化暗金 `#80602D`，墨迹黑褐
`#24170F`。黄铜高光短促且不连续；魔法色只用于状态识别、窄边或短脉冲，
不能成为常亮霓虹。

每个组件首先像香草魔兽中的原组件：动作条保留双头狮鹫和经典技能格，角色
面板保留 CharacterFrame／PaperDollFrame，任务日志保留双页任务簿，地图
保留原地图内容与导航习惯。不同模块必须拥有不同物件身份，不能为了统一而都
变成书本、羊皮纸卡片或黑铁面板。

所有动态文字、数字、图标、物品、法术、地图内容、按钮状态和列表行由游戏
运行时绘制。完整效果原型只用于锁定综合色感；生产资产必须按真实 pfUI、
Blizzard 或外部 provider 对象拆分，并为独立状态、点击几何、文字安全区、
拉伸区、层序和 UV 分别建立合同。

禁止现代扁平化、玻璃拟态、透明亚克力、半透明黑卡、统一大圆角、精密工业
网格、移动应用式标签、细金属网页边框、科技 HUD 和持续霓虹。禁止
《暗黑破坏神 3》式尖刺黑铁、骷髅、祭坛、恶魔角和大面积黑红；禁止
《上古卷轴 5》式极简黑色文字浮层。禁止照片级古董、镜面黄金、大型龙头、
翅膀、宝石底座、持续发光符文和镜像四角装饰。

## 模块身份

| 模块 | 必须首先识别为 | 不得退化为 |
|---|---|---|
| 聊天 | 厚封皮、多层毛边书页的战地旧书 | 半透明聊天板、规则复古面板 |
| 任务 | 正式公会任务卷宗；独立的行军便笺 | 聊天书复制品、现代任务卡片 |
| 地图 | 单张羊皮地图卷；黄铜航向罗盘 | 双页书、雷达、永久插件按钮环 |
| 技能书 | 冒险者随身私人法术秘典 | 任务日志复制品、现代技能列表 |
| 角色 | 香草同构纸娃娃角色面板 | 横向英雄仪表板、装备神龛 |
| 动作条 | 经典技能格与双头狮鹫 | 细长现代技能条 |
| 单位／团队 | 香草头像与状态信息结构 | 黑铁战争圣龛 |
| DPS／仇恨 | 战地账簿与指挥刻度 | 现代透明数据卡 |
| 消耗品 | 炼金师皮革卷袋 | 现代网格 Dashboard |

## 字体基线

- 叙事短标题、任务名、地图注释：`LXGWWenKaiGB-Medium.ttf`。
- 庄重面板标题、章节标题：`NotoSerifSC-SemiBold.ttf`。
- 聊天正文、团队、DPS、仇恨、数字和高密度信息：优先客户端高可读字体；
  中文缺字时才回退 `NotoSansSC-Medium.ttf`。
- 不用一款古风字体覆盖全 UI，不使用 Light 字重、粗外发光或现代网页排版。
- 三份仓库字体目前仍是运行时候选，必须通过 Turtle WoW 实机加载与内存测试。

## 组件级转译要求

模块与子模块 Prompt 必须明确写出：

1. 从本全局 Prompt 继承哪些时代语言、材料、光照、磨损和反模式。
2. 当前模块独有的物件身份与香草结构。
3. 当前子模块真实拥有的对象、状态和几何。
4. 从完整原型中明确排除哪些由其他运行时对象持有的内容。
5. 锁定图、模块 Prompt、组件合同与派生 source 冲突时的裁决。

不得以“同风格”“更史诗”或“更厚重”代替上述具体约束。
