# 艾泽拉斯远征手记：统一美术方向

## 文件职责

本文是整个 UI overhaul 的跨模块美术基线，不是可以直接提交给生图模型的
执行提示词。任何运行时资产都必须先完成组件拆分、pfUI 对象映射和尺寸合同，
再在 `prompts/<module>/` 中重写为对应组件的生产提示词。

## 项目目标

面向 Turtle WoW `1.18.1`／Interface `11200`，以 pfUI 的功能、数据和生命周期
为基础，大规模重构其视觉层与必要的布局层：

- 首先保留 60 级香草魔兽的结构辨识度、信息密度和操作习惯。
- 消除 pfUI 的现代窄边、扁平面板和不同单体插件之间的风格割裂。
- 增强厚重、史诗、冒险和长期使用后的旧物质感。
- 战斗信息的可读性、响应速度和旧客户端性能高于装饰。

主题名称为“艾泽拉斯远征手记”。它应像一套真实存在于艾泽拉斯世界中的
远征装备，而不是套在现代 HUD 上的棕色主题。

## 不可变的时代语言

- 2004 年前后香草魔兽式二维手绘位图。
- 厚轮廓、明确明暗切面、略微夸张的实体厚度。
- 可见手工误差、局部不对称和磨损，但不能变成摄影级古董。
- 组件首先像香草魔兽原组件，其次才表现主题材料。
- 不使用现代网页卡片、玻璃拟态、精密工业网格或零售版魔兽的轻薄面板。

## 共用材料与配色

所有模块共享综合色温、磨损尺度、笔触和左上暖光，但不要求都长成同一种
书本或金属框。

| 材料 | 主要职责 | 使用限制 |
|---|---|---|
| 暖赭烟熏羊皮纸 | 地图、任务、说明、聊天正文 | 文字安全区低对比、避免大污渍 |
| 深胡桃旧皮革 | 书本边界、页签、背包和辅助结构 | 不做现代黑色卡片 |
| 暗哑氧化黄铜 | 包角、铆钉、刻度和重要交互 | 只作次要材料，不形成满框亮金边 |
| 深胡桃木 | 地图卷杆、少量承托件 | 不做规则家具面板 |
| 克制黑铁 | 战斗组件的结构强化 | 避免尖刺、祭坛、骷髅和《暗黑破坏神 3》式黑红框 |
| 魔法状态色 | 施法、预警、职业与危险状态 | 只作窄边、短脉冲或局部符号 |

推荐基础色：

- 旧书页 `#B8955C`
- 纸页高光 `#D2B77E`
- 纸页阴影 `#76512E`
- 深棕封皮 `#28180E`
- 氧化暗金 `#80602D`
- 墨迹黑褐 `#24170F`

## 模块身份

### 聊天

一本仓促修补、长期使用的战地旧书。厚封皮、二至四层毛边书页、皮革索引签
和纸面文字不可变；不能退化为半透明聊天板或规则复古面板。

### 任务

任务详情是正式的公会双页卷宗；任务追踪是从卷宗中抽出的纵向行军便笺。
两者共享纸张与装订语言，但不得复制聊天书本的轮廓。

### 地图

大地图是一整张开阔羊皮地图卷，使用上下胡桃木卷杆；小地图是双层旧黄铜
航向罗盘。不得使用重型连续皮革背板，也不得固化永久插件按钮环。

### 角色与大型系统窗口

角色面板严格继承香草 `CharacterFrame / PaperDollFrame` 的紧凑纸娃娃
结构。其他大型系统窗口应先继承原版布局，再统一页签、标题、滚动条和按钮。
禁止横向英雄仪表板、装备神龛和大型龙饰。

### 动作条与单位框架

动作条必须保留香草双头狮鹫及经典技能格辨识度，只增强皮革、黄铜和磨损。
玩家、目标、小队与团队框架必须从香草轮廓出发，不能重新解释为现代黑铁
战争圣龛。四十人团队框架以清晰生命、减益、距离和职责为主，装饰集中在
分组与外框。

### 数据监控与消耗品

DPS／治疗／承伤使用战地账簿式列表；仇恨使用更紧凑的指挥刻度；消耗品
使用炼金师皮革卷袋。它们可以共享标题、列表行和按钮组件，但不能把动态
数据烘焙进背景。

## 信息与状态

- 保留原始技能、物品、装备、法术和地图内容图层。
- 状态必须同时通过轮廓、明暗、符号和文字表达，不能只依赖颜色。
- 战斗模块装饰占有效区域不超过约 10%；非战斗窗口不超过约 15%。
- 普通操作不持续发光；只允许短促、低频的金属高光、蜡封、墨迹或符文反馈。
- 中文、英文、数字、百分比和长名称都必须有稳定安全区。
- 字体职责与回退见 [`FONT_SYSTEM.md`](implementation/FONT_SYSTEM.md)。

## 统一禁止项

- 现代扁平化、玻璃拟态、透明亚克力、科技 HUD、霓虹描边。
- 统一大圆角、纯黑卡片、纤细网页字体、移动应用式标签。
- 《暗黑破坏神 3》式尖刺黑铁、骷髅、祭坛、恶魔角和大面积黑红。
- 《上古卷轴 5》式极简文字浮层或现代暗色菜单。
- 大型龙头、翅膀、宝石底座、持续发光符文和镜像四角堆砌。
- 为了“统一”而让地图、聊天、任务、背包和战斗框全部变成同一物件。
- 在单张背景中画死真实按钮、页签、输入框、滚动条或动态文字。

## 权威优先级

1. `assets/locked/<module>/` 中用户确认的视觉基准。
2. `docs/modules/<module>/` 中对应模块规范。
3. 本文的跨模块原则。
4. `assets/source/<module>/` 中已确认的透明母版。
5. `assets/references/` 中明确标注角色的结构或故障参考。

运行时实现、资产拆分和提示词状态以
[`OVERHAUL_TRACKER.md`](implementation/OVERHAUL_TRACKER.md) 为准。
