# 小地图罗盘：插件图标承载评估

## 评估范围

- 评估对象：小地图黄铜罗盘风格确认 V1
- 用户目标：保留香草魔兽插件图标挂载在小地图附近的使用习惯，同时维持地图有效面积与统一美术风格
- 证据截图：[小地图黄铜罗盘_视觉基准_v1.png](../../assets/locked/map/小地图黄铜罗盘_视觉基准_v1.png)
- 结论：**有条件通过；美术语言能够承载，但当前构图不能直接作为最终运行时挂载结构。**

## 当前优势

1. 圆形皮革外圈天然适合作为插件图标的挂载轨道。
2. 黄铜、皮革和挂件语言能够把来源不同的插件按钮统一成“制图师徽章”。
3. 右下方现有皮革吊牌可以自然改造成插件溢出入口，不需要另加现代菜单按钮。
4. 插件图标可以停留在地图视野之外，不必遮挡中央地图。

## 当前风险

1. 北、东、南、西四个大型方向件已经占用四个主要挂载位置。
2. 右侧缩放拨片、右下吊牌、加减按钮和底部铭牌占用较多外环空间。
3. 如果直接沿整圈摆放原始插件按钮，约六个之后就会开始显得拥挤；不同插件的边框、尺寸和高光还会破坏统一性。
4. 静态效果图无法证明拖动、点击、提示框、不同 UI 缩放和大量插件时的实际表现。

## 推荐结构

### 1. 环形插件轨道

- 将深色皮革外圈明确设定为插件挂载轨道。
- 保留八个标准可见槽位，位于方向件之间的斜向位置。
- 北、东、南、西方向件属于永久保留区域，插件图标不能与其重叠。
- 每个槽位容纳一个统一尺寸的“黄铜制图徽章”。

### 2. 固定系统控制区

- 缩放、追踪、邮件、日历等系统入口集中在右侧。
- 系统入口不参与插件自动排布。
- 底部铭牌只承担时间、坐标或区域名称，不放插件按钮。

### 3. 溢出工具袋

- 默认显示用户固定的六至八个插件图标。
- 超出容量的图标收纳到右下方皮革吊牌所代表的“制图工具袋”。
- 点击吊牌后展开附着于罗盘的短皮革挂带或两列小徽章面板。
- 收起后只保留吊牌和一个小型数量标记。

### 4. 插件图标统一皮肤

- 保留插件原始图标中央图案与点击行为。
- 移除来源不同的圆框、方框和发光边缘。
- 外层统一包裹为小型黄铜或暗皮革徽章。
- 悬停时徽章轻微抬起并加深接触阴影；提醒状态使用小型蜡点或黄铜钉，不使用持续发光。

## 建议容量

| 状态 | 建议容量 |
|---|---:|
| 当前构图直接挂载 | 约 4–6 个 |
| 调整方向件和附件体量后 | 6–8 个舒适可见 |
| 最大常驻数量 | 不建议超过 8 个 |
| 额外插件 | 进入溢出工具袋 |

## 可用性约束

- 单个插件图标点击区域建议不小于 30–32 px。
- 外环装饰与图标不能把中央地图有效直径压缩到总直径的 70% 以下。
- 不得仅依赖图标颜色表达激活、禁用或提醒状态。
- 允许拖动排序时，应沿环形槽位吸附，避免自由拖动造成重叠。
- 必须保留原插件提示框、鼠标点击和右键菜单行为。

## 验收条件

- 同时挂载八个插件图标时没有重叠。
- 方向标记、缩放和追踪入口仍可立即识别。
- 中央地图不被任何插件按钮遮挡。
- 插件来源不同，但外部轮廓仍属于同一套制图师美术。
- 超出八个图标时出现明确的溢出入口，而不是继续挤压环形空间。
- 在不同 UI 缩放下，图标点击区域仍然可靠。

## 证据限制

本次只能根据静态风格确认图判断空间与视觉承载能力。实际插件按钮数量、拖动行为、点击脚本、提示框位置和不同分辨率下的缩放仍需要运行时原型验证。
