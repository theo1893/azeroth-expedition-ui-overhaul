# 小地图罗盘：插件图标承载评估

## 结论

锁定的 V1 黄铜罗盘可以承载香草时代“插件图标挂在小地图附近”的功能，但
必须由运行时动态锚点和溢出入口实现，不能把永久槽环、固定图标或八个空槽
烘焙进罗盘母版。

- 对应组件：`MAP.MINI.ADDONS`
- 视觉基准：
  [`小地图黄铜罗盘_视觉基准_v1.png`](../../assets/locked/map/小地图黄铜罗盘_视觉基准_v1.png)
- 当前阶段：功能方案 `P2`，真实 Frame 和生产资产尚未定义

曾尝试增加完整插件徽章轨道和额外加厚外圈，导致罗盘过重、中央地图缩小，并
破坏 V1 的简洁轮廓；该方向已经弃用。

## 运行时结构

### 动态环形锚点

- 在皮革／黄铜外缘之外计算若干不可见锚点，不在底图画空槽。
- 仅为实际存在的插件按钮创建包裹 Frame。
- 北针、缩放、追踪和底部信息牌占用的圆弧必须避让。
- 插件数量或 UI Scale 变化时重新计算一次位置；普通维护循环不持续改锚点。
- 保留插件原始点击、右键、拖动、提示框和通知行为。

### 可见容量与溢出

- V1 外形下建议同时显示 4–6 个常用插件按钮。
- 超出容量的按钮进入右下方“制图工具袋”溢出入口。
- 展开后使用短皮革挂带或紧凑两列面板，不继续挤压罗盘外环。
- 用户固定、排序和隐藏结果属于 SavedVariables，不属于美术母版。

### 可选统一外壳

保留插件原始图标中央图案，只替换来源各异的外框：

- 小型暗皮革或氧化黄铜图标托；
- 普通、悬停、按下、激活、禁用五种状态；
- 通知使用小蜡点、布结或短促黄铜高光；
- 不使用持续发光、红色数字气泡或现代圆角按钮。

统一外壳是独立 `IconSocket` 资产，不能画在罗盘背景上。

## 需要拆分的组件

| 子组件 | 逻辑对象／状态 | 资产策略 |
|---|---|---|
| 动态锚点 | 若干不可见位置 | 无位图，只记录运行时几何 |
| 插件图标托 | 普通、悬停、按下、激活、禁用 | 共用画布的状态图集 |
| 通知覆盖 | 无／未读／警告 | 独立小覆盖层 |
| 溢出工具袋 | 普通、悬停、按下、展开 | 独立 Button 状态 |
| 展开挂带 | 收起／展开；动态行数 | 上／中／下三段式 |

在确认 `pfUI.modules/addonbuttons.lua` 的真实 Button、拖动和保存逻辑前，不编写
这些资产的 `production` 提示词。

## 可用性约束

- 单个按钮点击区域不小于约 `30–32 UI px`。
- 中央地图有效直径不低于罗盘总直径的 70%。
- 插件按钮不能遮挡北针、缩放、追踪或地图内容。
- Tooltip 根据屏幕边缘自动换向，不能被展开挂带遮挡。
- 状态不能只靠颜色表达。
- 收起溢出面板后，罗盘底图上不留下空槽或多余厚重结构。

## 实机验收

1. 分别测试 0、1、4、6、10 个插件按钮。
2. 验证左键、右键、拖动、Tooltip 和插件自己的闪烁／通知。
3. 验证常见 4:3、16:9、超宽屏与不同 UI Scale。
4. 验证按钮不会进入中央地图或屏幕外。
5. 验证溢出面板展开、排序、收起和重载后的持久化。
6. 确认关闭所有插件入口后，视觉仍完全等同于锁定 V1 罗盘，而不是带空槽的
   重型版本。
