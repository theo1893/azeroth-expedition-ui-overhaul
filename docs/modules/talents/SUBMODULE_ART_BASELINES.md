# Talents 子模块美术基线 Prompt

以下方向继承 [主模块基线](ART_BASELINE.md)，当前暂停，不构成生产授权。

- `TL.FRAME／VIEWPORT`：经过维修的粗厚皮革案夹，完整开放动态职业背景窗口；
  不是第二本书、相框或现代卡片。
- `TL.NODE／RANK`：粗粝暗黄铜／墨黑皮革徽座，中央动态图标完整；未学、可学、
  已学、满级、悬停、按下分态，Rank 独立。
- `TL.BRANCH／ARROW`：32×32 可拼接的墨线／暗黄铜导线，满足为低饱和暖金，
  不满足为冷灰；不得发光或烘焙到背景。
- `TL.TAB／POINTS／SCROLLBAR／CLOSE`：分别使用不齐课程签、窄羊皮题签、旧皮革
  滑槽与短皮革扣；动态文字和真实交互保持独立。
