# Unit Frames 子模块美术基线 Prompt

以下条款全部继承 [Unit Frames 主模块 Prompt](ART_BASELINE.md) 与
[全局 Prompt](../../GLOBAL_ART_BASELINE.md)。下列方向已由用户在
`UF-PRIMARY-SIM-V1` 中确认；它们是正式生产的冻结可见约束，但不是 P4 source
接受记录。只有具体生产候选再次获得用户明确接受后，才能凝结为锁定资产条款。

## `UF.PLAYER.SHELL`

绘制一个无文字、无图标、真透明的横向行军身份牌外壳。主体是深胡桃旧皮革，
左端有一块略歪的短黄铜夹片与两针粗修补线，右端只保留磨损皮革和一枚不居中
铆钉。上下边低频起伏且不平行，但不得侵入 `200×25` 生命与 `200×4` 能量
动态区。生产 source 拆为左右端帽与上下横轨；身份细节集中在固定端帽，横轨
保持安静，接头一像素不得承载唯一识别特征。最终外接 `214×42`，中央必须
完全安静。

## `UF.TARGET.SHELL`

与玩家框属于同一材料家族，但从零绘制而非镜像。右端有更明显的断裂黄铜
压片，左端仅有被磨亮的皮革折边；磨损与缝线位置和玩家框不同。不得烘焙
敌对色、等级、精英冠饰或目标类型。生产 source 同样拆为独立端帽与横轨；
右端身份不得扩散成长轨上的连续花纹，接头一像素不得承载唯一识别特征。
最终外接 `214×42`。

## `UF.TARGETTARGET.SHELL`

绘制紧凑的 `112×34` 身份条：更薄的旧皮革、少量烟褐内衬和两至三处短促
氧化黄铜痕迹。保留粗厚可读轮廓，但删去大框的大部分装饰；不能变成规则小
卡片或把大框直接等比缩小。

## `UF.FOCUS.SHELL`

绘制紧凑的 `112×39` 追踪身份条。主体与目标的目标同族，但一段褪色靛蓝
猎踪布结从右上皮革夹层露出，布结必须被皮革与一枚暗铜钉真实压住。它是唯一
焦点识别元素，面积克制，不侵入动态文字与条形区；不得使用宝石、符文环、
蜡封或蓝色常亮描边。

## `UF.BAR.HEALTH.FILL`／`UF.BAR.POWER.FILL`

生成两条无色灰阶、完全不含文字和状态色的哑光颜料纹。Health 比 Power 略
粗，均只有低频横向刷痕与微弱颜料堆积，左右可被 StatusBar 裁切或延展，不能
出现居中亮点、重复斜纹、镜面高光、渐变玻璃或透明缺口。最终分别导出为
`64×32` 与 `64×16`。

## `UF.STATE.HOVER.RIM`／`UF.STATE.AGGRO.RIM`

不单独进行 ImageGen。由每张用户接受外壳的 Alpha 和边缘色确定性派生：Hover
只在两三段高磨损边出现低 Alpha 暖白响应；Aggro 只在两端和一小段下缘出现
暗红／橙褐响应。不得形成整框连续光圈，派生纹理不得覆盖动态内容或接管鼠标。
