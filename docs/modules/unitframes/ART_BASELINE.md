## 主模块 Prompt

为 Turtle WoW `1.18.1` 的 pfUI 单位框制作“远征队行军身份牌”式二维手绘
位图资源。首先保持 pfUI 现有生命条、能量条、文字、图标、状态反馈和点击
习惯，其次以长期携带的深胡桃旧皮革、少量暗哑氧化黄铜夹件、烟褐内衬与
粗短修补线强化香草时代的重量。

单位框必须像冒险者在营地中手工包边、反复修补的身份牌，而不是一本缩小的
书，也不是精密铸造的金属 HUD。外轮廓略微歪斜；上下边只允许低频起伏；左右
端帽的厚度、缺口、铆钉和修补位置不相同。黄铜只做短夹片、断续包角和少量
铆钉，不形成完整金边。皮革承担主要结构，烟褐内衬负责承托动态条，状态色仍
由游戏绘制。

皮革的具体世界内来源是被远征队重复利用的旧马鞍带、盾牌背带和帐篷捆扎皮，
不是奢侈皮具、家具包边或现代工业制品。粗犷来自手工裁边的低频偏差、局部
厚薄变化、不均匀染色、烟熏、泥渍和少数有受力逻辑的补针；不得用均匀压纹、
密集毛孔、规则滚边、等距针脚或对称铆钉制造“做旧”。

玩家与目标是同一工匠体系的一对大框，但不得左右镜像：玩家左端修补略重，
目标右端磨损略重。目标的目标只保留必要的皮革边与两三处短黄铜痕迹；焦点框
在同样简化结构上夹一小段褪色靛蓝猎踪布结，用于识别追踪对象，不使用宝石、
魔法环或常亮光。

生命／Power 填充纹理使用可被 runtime 着色的无色灰阶哑光矿物颜料纹：低频刷痕、
轻微色料堆积、没有亮玻璃高光、没有重复斜纹。文字与数值直接落在动态条上，
中央必须安静。Mana／Rage／Focus／Energy 等资源类型继续由 pfUI 经典色乘色，
不得为每种资源烘焙一张彩色贴图。悬停与仇恨只通过外壳边缘的短促暖光或暗红
颜料响应，不出现整框霓虹。

禁止规则对称金框、连续细金线、完美圆角矩形、网页卡片、透明黑玻璃、工业
铆钉网格、镜面黄金、黑铁祭坛、骷髅／恶魔角、巨型徽章、圆形头像假槽、
《暗黑破坏神 3》式战争圣龛和把 Chat 书本轮廓缩小复用。禁止烘焙单位名、
等级、生命值、职业色、头像、Buff、Debuff、Raid Icon 或任何状态文字。
