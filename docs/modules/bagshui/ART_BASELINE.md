# 乾坤袋美术基线

方向：远征行囊展开后的分隔内胆。继承全局 2004 香草魔兽手绘、左上暖光、
低饱和、手工误差与磨损尺度。深胡桃皮革包覆外缘，烟褐低对比布料承托图标，
暖赭旧纸仅用于分类短签，暗哑黄铜仅用于小包角和控制件。

保留 Bagshui 的密集分类布局、右侧排布和窗口自适应。装饰不能占用动态内容。
物品数量、图标、品质、冷却、搜索、金币与离线状态永远由 provider 绘制。
禁止巨幅羊皮纸、书脊、人物、格子背景、烘焙分类、现代玻璃卡片、连续黄框、
大面积品质光晕。边角固定，安静中段可伸展／平铺。新 runtime 默认 2 texels/UI，
单边最多 1024；实际显示尺寸与采样尺寸独立。

当前几何预演只用于净空与密度检查，不是生产 source，不作为纹理质量验收。
