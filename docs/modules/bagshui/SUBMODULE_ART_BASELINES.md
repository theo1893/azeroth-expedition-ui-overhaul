# 乾坤袋组件美术基线

- BAG.FRAME：小幅不规则旧皮革边缘与短缝线，四角克制黄铜加固；内部为
  连续安静烟褐布料。拆分边角、重复边段和布面，不能生成固定布局大背景。
- BAG.GROUP：薄皮隔边／低对比缝线，留白承担分组；标题为独立短纸签，
  不把动态名称画入纸签。普通悬停不出现整块黄色矩形，编辑目标保留辨识度。
- BAG.SLOT：薄皮革凹沿，品质窄内边独立，悬停／按下／选中分别接入真实状态；
  不压住图标、数字、任务徽记和库存变化标记，空槽袋型图继续由 provider 持有。
- BAG.TOOLBAR／SEARCH：小型皮革／黄铜底座，已有动态符号独立；禁用／搜索
  展开几何遵从 provider，无高亮光圈。输入底为深色低对比皮革。
- BAG.FOOTER：皮革收口，袋位、金币和状态留白，不烘焙任何图标／数字。

组件共用全局暖光与磨损；可复用已接受 Character／Gear Planner 小控件，
但不能直接把角色外壳或配装整板移作行囊。
