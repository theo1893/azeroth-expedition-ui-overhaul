# ShaguDPS 当前状态

- runtime `5.0.1 / P5`，独立 provider；AEUI 不接管统计决策。
- 跨登录只保存全程、小怪及非战斗复活的累计统计、职业映射与计时；保留有效／过量治疗、过量伤害、技能累计、驱散、打断和光环覆盖汇总，BOSS 汇总继续由全程减小怪计算。
- 当前战斗、最近五场、逐场 BOSS、动作／死亡回放、承伤事件及按目标明细只在本次 UI 会话保留，退出或 `/reload` 后释放。保存表与运行时表独立，后续事件不会膨胀已生成的存档快照。
- 旧缓存首次恢复时迁移为汇总格式；换地图不重复恢复。正常退出或 `/reload` 会先结算未结束的战斗，再保存计时、覆盖率和小怪累计。强制终止进程只能保留客户端最近一次实际写盘的数据。
- 已经大到无法登录的旧存档须在关闭客户端后先备份，再离线迁移对应角色的 `SavedVariables/ShaguDPS.lua`；保留配置及累计汇总。仅更新插件无法在旧文件被客户端读取前清理它。

## 待实机

1. 对照 `/reload` 前后的全程伤害、有效／过量治疗、死亡／驱散／打断及 DPS/HPS；重新进入战斗后继续累计，换地图不回退旧数值。
2. 相邻检查小怪／BOSS 汇总、职业颜色、宠物合并和战斗中 `/reload` 的计时；当次回放可用，重载后历史为空。
3. 无 Nampower 时基础伤害／治疗仍可累计并恢复；关闭 ShaguDPS 后 AEUI 与其他 provider 正常加载。

## 回退

关闭 ShaguDPS 可独立回退。旧版本没有存档体积约束；恢复旧版及原始存档前保留迁移后的汇总副本。
