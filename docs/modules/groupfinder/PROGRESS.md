# Group Finder 进度

## 当前结论

- standalone runtime `0.1.0` 已完成静态接入，目标客户端为 Turtle WoW
  `1.18.1 / Interface 11200`。
- 团长发布后，`AEGF1` 专用频道中的单条消息包含团长说明、当前／目标职业分布、
  T/N/D、最低装等与装备竞争摘要；浏览者不需要先私聊团长。
- 申请走 Turtle 定向 addon whisper，携带职责、职业和客户端计算的平均装等；团长可
  在面板中邀请或拒绝。目录、申请队列都不依赖 LFT 或外部服务器。
- 协议解析器限制消息长度、字段范围和版本，并以服务器事件提供的发送者作为身份。
  `Tests/Protocol_spec.lua` 覆盖中文清洗、往返、畸形消息和职业／职责校验。

## 首版限制

- 只有安装并启用同一插件的在线玩家能发布、浏览和申请；目录不持久化离线团。
- 自定义频道的全服范围、跨阵营行为、频道所有权和服端反刷屏规则必须以当前乌龟服
  实机为准。若频道不能稳定工作，纯客户端方案没有等价的全服目录回退。
- 装等可被修改插件伪造，装备竞争为手工摘要；首版不做物品级申请、自动占位或硬上限。
- 首版不提供筛选、排序偏好、黑名单、历史信誉、日历或外部服务。

## 下一门禁

1. 两个不同账号完整重启客户端，确认 `/aegf` 都显示频道“已连接”，频道消息不出现在
   普通聊天窗；A 发布后 B 无需私聊即可看到所有五行详情。
2. B 在面板切换 D/N/T 并申请，确认低于最低装等时本地阻止；满足时 A 收到姓名、职业、
   职责和自报装等，并可分别完成拒绝和原生邀请。
3. A 更新队伍成员后，B 的当前人数和职业分布自动变化；A 停止招募后 B 条目消失。
   强制离线 A 后确认条目在 150 秒左右过期。
4. 同时上线多个发布者并让新客户端执行 `/aegf sync`，确认错峰回复没有触发服端禁言；
   再确认频道是否同阵营全服、跨阵营可见，以及频道被占用／设密时的行为。
5. 相邻回归：禁用 Group Finder 后 pfUI、原生聊天、LFT 和队伍／团队邀请保持原样。

## 回退

禁用或删除 `AzerothExpeditionGroupFinder` 即完全回退；插件不修改 LFT、pfUI 或其他
插件的 SavedVariables，也不需要迁移服务器数据。
