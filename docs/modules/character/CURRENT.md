### 确定性合同与审查

- ImageGen 输出必须是单张 `1024×1024`；主体 bbox 纵横比必须在 `0.75 ±1%`，
  禁止各向异性拉伸。
- 允许：边缘连通色键、透明 RGB 清零、等比 bbox-fit 至 `768×1024`，再映射
  到原生 `384×512`。
- 按原生坐标拆出 Shell、`233×224` Model、`230×78` Stats 和五张
  `32×29` Resistance；动态／交互区域用固定 mask 清理，禁止 AI 重采样补画。
- 每次输出都用真实字体、动态模型／装备 icon／数值及 4/5 Tabs 做
  `80% / 100% / 120%` 排版预演，并检查空装、典型、密集、低耐久状态。
- 不满足无左上 icon、无动态烘焙、完整 3:4 bbox、真实净空或粗犷非工业风，
  视为不通过；最多五次实际 ImageGen 调用，首个通过稿即停。
