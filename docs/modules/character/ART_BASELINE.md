## 主模块 Prompt

为 Turtle WoW `1.18.1` 制作“艾泽拉斯远征手记”中的角色属性模块。它必须
首先被识别为 60 级香草魔兽 `CharacterFrame / PaperDollFrame` 的同构重绘，
而不是重新设计的奇幻人物 Dashboard。

严格保留紧凑竖向单窗口和近矩形外轮廓：中央完整实时 3D 角色纸娃娃，左右
两列经典正方形装备槽，人物下方两列紧凑属性，底部主手／副手／远程或圣物
三个槽，以及最底部角色／声望／技能／PVP 小型香草 Tabs。顶部只保留短角色
姓名铭牌、紧凑等级／职业信息和右上关闭扣；旋转、头盔与披风入口保持小型。

继承全局香草二维手绘位图、粗厚略不规则轮廓、明确明暗切面、左上暖光、
低饱和综合色温和真实材料厚度。材料只使用深胡桃旧皮革、暖赭低对比羊皮纸
和暗哑氧化黄铜：皮革负责外框、模型底面和槽凹面，羊皮纸负责属性文字区，
黄铜只负责窄包边、铆钉、包角、关闭扣与小交互件。

人物背景为安静的烟褐／深灰绿色旧皮革，足以辨认暗色种族、盔甲和武器，
不出现房间、风景、祭坛、拱门、魔法光柱或戏剧聚光。装备品质色只作为低饱和
窄内沿；空槽使用装备部位的低对比压印；耐久与选择使用小角标、裂纹、材质
下沉和短高光，不使用外发光。

属性名称左对齐、数值右对齐，分组通过留白、短墨线和小型标题件表达，不使用
进度卡、彩色数值格或加号面板。Tabs 保持香草厚度与小尺寸，选中状态只通过
前移、皮革变暖和文字提亮表达。

禁止横向双栏、永久属性附页、装备卡片墙、四个底槽、左上大型肖像章、右下
龙头／涡卷／宝石、大型盾徽、翅膀、祭坛、拱门、宽紫品质框、五个彩色数值
格、近黑人物背景、现代人物仪表板、玻璃卡片、细金框、暗黑祭坛和照片级
古董。

## 字体

- 面板主标题与分区标题：Noto Serif SC SemiBold。
- 属性、等级、耐久、装备与数字：优先客户端高可读字体。
- 不使用叙事楷体承担密集属性数据。

## 生产边界

V3 整体图只锁定结构、材质和综合色感，不能直接切成包含装备槽、Tabs、
属性下拉、旋转与关闭 Button 的背景。生产时必须按
[SUBMODULES.md](SUBMODULES.md) 拆分。
