## 一、设计结论

角色属性模块不是重新设计的奇幻人物仪表板，而是对 60 级香草魔兽 `CharacterFrame / PaperDollFrame` 的同构重绘。

它必须首先被识别为香草时代按 `C` 打开的角色面板，其次才被识别为“艾泽拉斯远征手记”皮肤。厚重感来自旧皮革、羊皮纸、黄铜厚度和手绘明暗，而不是龙头、祭坛、拱门或扩张外轮廓的大型装饰。

## 二、不可变结构

- 使用紧凑的竖向单窗口和近矩形外轮廓。
- 中央保留完整实时 3D 角色纸娃娃，头部、武器和脚部均可见。
- 左右两列经典正方形装备槽紧密环绕人物。
- 装备槽数量、顺序、大小和相对位置遵循香草结构母版。
- 人物下方保留两列紧凑属性文字区。
- 主手、副手、远程／圣物保持为底部三个槽位。
- 最底部保留 `角色／声望／技能／PVP` 四个小型香草页签。
- 顶部只保留短角色姓名铭牌、紧凑等级／职业信息和右上关闭扣。
- 旋转角色、隐藏头盔和隐藏披风入口保持原版量级，不得放大为主按钮。

禁止将主窗口改成横向双栏、永久属性附页、全屏人物页、装备卡片墙或大型装备陈列柜。

## 三、材质与综合色感

材料限定为三个主层级：

1. 深胡桃棕旧皮革：外框、人物底面、装备槽凹面和页签。
2. 暖赭色低对比羊皮纸：基础属性和战斗属性文字区。
3. 暗哑氧化黄铜：窄包边、铆钉、转角、关闭扣和小型交互件。

统一规则：

- 保持 2004 年前后香草魔兽的手绘位图、厚轮廓和略微夸张的材质厚度。
- 光照来自左上方，综合色温温暖、低饱和、沉稳。
- 黄铜高光短促且不连续，带有暗斑、磕碰、磨损和轻微不对称。
- 不使用照片级古董、镜面黄金、精密珠宝或现代仪表质感。
- 与聊天旧书、任务卷宗和黄铜罗盘属于同一制作年代，但不得复制它们的物件轮廓。

## 四、人物纸娃娃区域

- 背景使用烟褐色与深灰绿色旧皮革。
- 明度必须允许深色盔甲、暗色种族和武器轮廓清晰可辨。
- 背景纹样只作为极低对比压印，不得形成独立场景。
- 不出现房间、风景、祭坛、拱门、魔法光柱或戏剧性聚光。
- 人物模型保持主视觉，不得被边框、装饰或属性面板压缩。

## 五、装备槽与状态色

- 槽位继续使用经典正方形图标框。
- 深皮革凹槽为主体，氧化黄铜为外包边。
- 物品品质色只作为低饱和窄内沿，不形成宽紫框或连续灯带。
- 品质色不得比装备图标、皮革或黄铜更醒目。
- 空槽使用对应装备部位的低对比压印。
- 低耐久使用小型暗红破损角标、裂纹或蜡印。
- 可装备、不可装备、选中和悬停状态通过局部色差、材质下沉与短促高光表达，不使用外发光。

## 六、标题、属性与页签

- 标题采用短皮革铭牌，不增加大型圆形肖像章。
- 等级、职业和公会信息保持紧凑，不扩展为第二级信息栏。
- 属性名称左对齐、数值右对齐，使用深褐墨字。
- 属性分组通过纸面留白、短墨线和小型黄铜标题件表达。
- 不使用属性进度条、加号按钮、现代卡片或大面积颜色底。
- 底部页签保持香草式厚度、按压感与小尺寸。
- 选中状态通过页签前移、皮革变暖和文字提亮表达。

## 七、插件扩展边界

- 额外属性可以使用右侧可收起的窄羊皮附页，但默认关闭。
- 附页宽度不得超过主窗口约 45%，不得永久改变主窗口轮廓。
- 附页使用两个小型黄铜页夹连接，不得变成横向双栏仪表板。
- 第三方装备列表、五个彩色数值格或其他插件信息只能作为可选运行时覆盖层。
- 插件覆盖层不得固化进角色面板基础贴图，也不得挤压人物或装备槽。

## 八、装饰边界

允许：

- 小型黄铜包角
- 铆钉、搭扣和连接片
- 一个不抢眼的职业或阵营压印
- 少量皮革压纹和手绘磨损

禁止：

- 大型肖像章
- 大型龙头、翅膀、骷髅、尖冠或盾徽
- 涡卷宝石底座
- 拱门、祭坛和装备展示龛
- 任何越过近矩形轮廓的大型主题构件
- 复制聊天框厚书、任务双页卷宗、地图卷轴杆或小地图罗盘环

## 九、明确弃用

以下设计不得在后续版本中恢复：

- V1 的横向双栏人物仪表板与大型永久属性区。
- V2 左上大型圆形人物肖像章。
- V2 右下大型黄铜龙头、涡卷和宝石底座。
- V2 底部四装备槽结构。
- V2 人物右侧五个彩色数值格。
- V2 大面积高饱和紫色装备框和近黑人物背景。

## 十、后续生成锁定段

> 角色属性面板严格沿用“香草同构角色面板 V1”锁定风格，并以 V3 确认稿和 60 级香草结构母版为共同基准。它必须是紧凑、近矩形的香草 `CharacterFrame / PaperDollFrame` 同构重绘：中央完整人物纸娃娃、左右两列经典装备槽、下方双列属性、底部三个武器／圣物槽以及 `角色／声望／技能／PVP` 四个小型页签。材料只使用深胡桃旧皮革、暖赭羊皮纸和暗哑氧化黄铜；品质色只能是低饱和窄内沿。不得增加大型肖像章、龙头、翅膀、祭坛、拱门、涡卷宝石底座、彩色数值格、横向双栏或现代人物仪表板。

生成时必须把 V3 确认稿与香草结构母版作为实际图像参考附加，而不是只传递文件名或文字描述。
