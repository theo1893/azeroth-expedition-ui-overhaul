# Character 子模块美术基线 Prompt

以下条款继承 [Character 主模块](ART_BASELINE.md) 与
[全局基线](../../GLOBAL_ART_BASELINE.md)。

## `CHAR.FRAME`

生成无文字、无装备槽、无 Tabs 的紧凑香草角色面板外壳。近矩形竖向轮廓，
深胡桃旧皮革为主，暖赭羊皮属性区留白，氧化黄铜仅作窄包边、包角和连接件。
保持手绘不规则、磕碰和短高光，但不越出香草轮廓。不得包含大型肖像章、龙饰、
宝石、拱门、祭坛或横向附页。

## `CHAR.MODEL`

只生成可切片的安静烟褐／深灰绿色旧皮革模型背景与边框。中央必须完全留给
原生 3D 模型，明度能辨认暗色盔甲与武器。禁止场景、纹章墙、聚光、魔法光、
人物剪影或烘焙角色。

## `CHAR.SLOT`

生成经典正方形装备槽：深皮革凹面、厚但克制的氧化黄铜外沿和清楚按压层次。
普通、悬停、按下、禁用几何完全相同。品质色是独立的低饱和 `2–3 px` 窄
内沿；耐久是独立小角标／裂纹覆盖。不得生成宽紫框、连续灯带、外发光或固定
装备图标。每种空槽部位压印作为独立 runtime 图层。

## `CHAR.STATS／RESISTANCE`

属性纸面为安静暖赭羊皮，保留双列名称／数值和短墨线分组的安全区。抗性图标、
数值、下拉内容全部动态。下拉、复选框和状态条按真实对象分别制作，不能画成
五个彩色数值卡。

## `CHAR.TABS`

生成小型香草皮革 Tab 的普通、悬停、选中、禁用状态。选中状态向前并略变暖，
各状态点击几何不变；文字由客户端绘制。禁止网页式标签、胶囊按钮和大面积
品质色。

## `CHAR.CLOSE／MODEL CONTROLS`

关闭扣为小型黄铜搭扣，旋转与头盔／披风入口为低调皮革／黄铜控制件；全部
提供真实 Button 支持的状态。不得放大成主操作按钮或悬浮圆形图标。

## `CHAR.REPUTATION／SKILLS／HONOR／ARENA`

复用主外壳的皮革、羊皮和黄铜语言，但保持香草各页的列表、进度条、展开项、
滚动条和 Tabs。动态列表不生成行卡片；状态条保留高可读填充，并把端帽、
背景和填充分开。

## `CHAR.PET／INSPECT／DRESSUP`

复用角色外壳、模型背景、槽、Tabs 与按钮的相同绘制语言。Inspect 槽是只读，
不得出现可装备／按下语义；DressUp 的 Reset／Cancel 是独立四状态 Button；
Pet 保留宠物经验、训练点和抗性。
