## 主模块 Prompt

为 Turtle WoW `1.18.1` 制作“艾泽拉斯远征手记”中的聊天模块。严格继承
全局香草时代二维手绘位图语言、左上暖光、低饱和暖赭／烟褐／深胡桃／氧化
黄铜色域和真实材料厚度，同时保持聊天模块独有的“战地旧书”身份。

聊天框必须首先被识别为一本放在屏幕左下角、长期携带并反复修补的厚旧书，
随后才被识别为聊天窗口。使用深棕厚封皮、两至四层错落毛边书页、可辨认的
页叠截面与装订阴影、暖赭连续阅读纸面、暗哑小型包角，以及插入上沿书页的
皮革频道索引签。轮廓略微歪斜、不完全对称，四角磨损和修补不同；这种不规则
来自真实使用，而不是随机噪声。

正文区域是最大、连续、平整且低对比的纸面。消息、频道名、发送者、时间、
链接与输入文字由游戏直接绘制，像墨迹落在纸上，不使用消息卡片、气泡或列表
底色。装饰和高频磨损只出现在封皮、毛边、装订、页角和常用标签，不能侵入
主要文字列。当前 runtime 不在正文安全区覆盖压光、阴影面板或逐条消息底色；
纸面必须保持为一张连续材质。

频道 Tab 表现为皮革索引签：普通状态较暗并后退，悬停时边缘轻微变暖，选中
状态略微上抬并与书页衔接，禁用状态降低对比。未读状态使用小蜡封或布结；
输入区域使用浅纸带、墨线或压痕。所有反馈通过材质前移、下沉、局部短高光和
接触阴影表达，不使用整框外发光。

材料优先级始终是纸张第一、旧皮革第二、氧化黄铜第三。与香草双头狮鹫动作条
处于同一制作年代，但聊天框保持纸张为主体，不能变成黑铁战斗面板。

禁止半透明黑色聊天板、现代卡片、毛玻璃、网页 Tab、胶囊按钮、悬浮圆形
按钮、红点通知、细金线深色框、规则对称复古面板、照片级古董、暗黑 3 式
尖刺黑铁和上古卷轴式极简文字浮层。禁止恢复公会／背包／延迟等常驻信息
底栏。

## 字体

- 频道签与短书页标题可使用霞鹜文楷 GB Medium。
- 聊天正文、玩家名、时间和数字沿用 pfUI 当前配置的客户端高可读字体，并
  保留用户所选字号。
- 正文不使用全方向 `OUTLINE`、投影或外发光；复杂频道色通过调整正文基础色
  保持辨识度，不能复制出第二层字形边缘。
- 所有正文颜色都必须像吸入羊皮纸纤维的深色墨迹，而不是屏幕发光色，同时
  必须保留玩家已经熟悉的 Vanilla 色相身份：说话为中性墨，公共频道为深玫瑰，
  系统为赭黄，公会为绿色，小队为蓝紫，团队为焦橙，密语为洋红，警告为红色，
  表情为橙褐。小队与团队禁止复用同一目标色。
- 职业色不得为了追求任意数值距离而重新分配到陌生色域。九职业使用各自
  Vanilla RGB 的等比例深色版本：战士保持棕褐／青铜而非红色，牧师保持无彩
  中性墨，圣骑士粉、猎人绿、盗贼黄、萨满蓝、法师青、术士紫、德鲁伊橙均
  保持原色相。以已接受书页中央代表色 `#CDA155` 为静态代理时，基础频道与
  职业目标色保持约 `4.5:1` 或更高对比，不使用霓虹原色、白芯高光、描边或
  阴影补偿辨识度。
- ChatMOD、pfUI 与原生运行时生成的已知内嵌颜色只在 AEUI 受管聊天框的最终
  显示入口映射；未经审计的第三方颜色若在代表纸色上低于 `4.8:1`，只允许
  等比例压低 RGB 以保留其原色相，已经足够深的自定义色必须原样保留。不得改
  全局 `ChatTypeInfo`、插件 SavedVariables、消息内容或 `|H...|h` 链接载荷。
- 不使用书法体覆盖正文，不使用细窄网页字体、粗外发光或高对比黑色字圈。

## 原型与生产边界

完整旧书原型只锁定物件身份、轮廓、材质、光照和综合色感。生产时必须按
[SUBMODULES.md](SUBMODULES.md) 分为主框、Tab、未读、输入、文字与真实滚动
控件；不得把这些交互对象烘焙为一张背景。
