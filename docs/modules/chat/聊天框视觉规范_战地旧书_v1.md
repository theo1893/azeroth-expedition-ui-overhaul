# 一、设计结论

聊天框不是覆盖在画面上的现代半透明信息面板，而是一本放置在屏幕左下角、正在使用中的旧战地书籍。

它应当让人首先辨认出“旧书”，随后才意识到这是聊天窗口。书本必须具有可感知的厚度、使用痕迹和手工装订感，但正文区域仍需稳定、平整并易于阅读。

本组件最重要的标志是：**厚封皮包围多层毛边书页，频道标签像插在书页中的皮革索引签，聊天文字直接书写在旧纸上。**

本设计刻意保留轻微不对称的外轮廓。这种不规则性是区别于现代矩形卡片的关键，不得为了方便实现而全部拉直。

# 二、不可变视觉特征

以下特征属于硬性锁定项，缺少任意一项都不能称为“战地旧书聊天框”：

1. **实体书籍轮廓**
   - 外框必须表现为厚封皮、书页和装订结构，而不是给矩形面板贴一圈复古花纹。
   - 外轮廓略不对称，左右和上下边缘不完全镜像。

2. **多层毛边书页**
   - 正文区域外围能看到两至四层深浅不同的纸页边缘。
   - 纸页边缘有轻微卷曲、缺口、磨损和厚度，不使用规则直线。
   - 下沿与装订侧必须形成可辨认的页叠截面、页层高低差和压合阴影；即使移除文字与装饰，轮廓仍应被识别为一本厚书，而不是羊皮纸平板。

3. **旧封皮与包角**
   - 最外层为深棕黑色旧皮革或木质封皮。
   - 边角带有暗金、旧黄铜或染色木雕包件。
   - 金属只能表现为长期使用后的暗哑反光，禁止镜面高光。

4. **皮革索引标签**
   - “综合、战斗、队伍、公会”等频道位于书本上沿，表现为插入书页的皮革索引签。
   - 当前频道标签略微抬起并变暖；非当前标签向后退并降低对比度。
   - 禁止使用现代网页标签页、胶囊按钮或纯色矩形按钮。

5. **文字直接印在书页上**
   - 聊天行不使用独立卡片、气泡或列表底色。
   - 文字像墨水直接落在纸面上，通过字号、颜色和缩进区分信息。

6. **书签式辅助控件**
   - 未读、收藏、锁定、滚动到底部等状态使用书签、蜡封、金属扣或页边小标记表达。
   - 控件不得表现为悬浮圆形按钮或现代线性图标。

7. **与底部 HUD 同时代**
   - 聊天框与香草风动作条共享手绘厚边、暗金包角和旧材质精度。
   - 两者可以相邻，但聊天框必须保持纸张为主体，不能变成另一块黑铁战斗面板。

# 三、色彩与材质基准

以下颜色是资源制作的目标范围，不要求所有像素完全一致。最终以基准图的综合色感为准。

| 名称 | 建议值 | 用途 |
|---|---:|---|
| 旧书页 | `#B8955C` | 正文纸张基础色 |
| 纸页高光 | `#D2B77E` | 中央阅读区域与轻微磨损高光 |
| 纸页阴影 | `#76512E` | 毛边、叠页和卷曲阴影 |
| 封皮深棕 | `#28180E` | 最外层封皮、背板和深色装订 |
| 氧化暗金 | `#80602D` | 包角、铆钉、索引签描边 |
| 墨迹黑褐 | `#24170F` | 正文与结构线条 |

色彩规则：

- 整体饱和度偏低，以褐、赭、烟灰和暗金为主。
- 纸张中心比边缘略亮，但不得出现现代柔光渐变。
- 磨损主要发生在页边、折角、装订和常用标签上，正文区域保持安静。
- 频道色沿用经典 MMO 的识别逻辑，但降低荧光感：队伍偏暗绿、公会偏橄榄绿、密语偏灰紫、系统警告偏砖红、战利品偏沉静蓝色。
- 禁止纯白纸张、纯黑背景、亮橙金属和大面积红色。

材质优先级：

1. 旧纸张
2. 深色封皮
3. 暗金包件

任何时候都不得让金属装饰压过书页主体。

# 四、字体规范

## 标题与频道标签

- 使用带经典奇幻气质的粗衬线字体。
- 字形应略窄、笔画有手工刻印感，但不得接近现代奢侈品牌衬线体。
- 英文使用首字母大写，不使用全大写科技标题。
- 中文标签使用具有轻微碑刻或旧印刷感的宋体／楷体混合气质，优先保证识别。

## 聊天正文

- 使用高可读性的旧印刷风格衬线字体。
- 正文不使用书法体、花体或仿手写体。
- 字重高于现代轻量 UI，确保在复杂战斗背景中仍能辨认。
- 行距紧凑但不拥挤，建议约为字号的 1.25–1.4 倍。
- 发送者姓名、频道前缀和正文采用同一字体家族，只通过颜色与字重区分。

## 数字与时间

- 使用与正文协调的衬线数字。
- 禁止等宽终端字体、细窄科技字体和高亮数字胶囊。

# 五、组件结构

从外到内依次为：

1. 深色封皮背板
2. 木雕或暗金包角
3. 多层叠页边缘
4. 主阅读纸面
5. 顶部皮革频道标签
6. 左侧书签式工具栏
7. 右侧未读／收藏书签
8. 正文滚动区域
9. 底部输入区域
10. 隐藏式缩放与拖动区域

结构规则：

- 正文滚动区域必须是最大的连续平面，不被装饰切碎。
- 书页毛边只能侵入外圈，不能进入主要文字列。
- 输入区域位于书页内部，以墨线、浅压痕或较深纸带表示；禁止独立黑色输入框。
- 滚动条应隐藏在页边或装订中，滑块可表现为黄铜页夹。
- 缩放把手伪装为书角包件，只在悬停或编辑模式下增强。

# 六、比例与布局

基准图中的聊天框约占：

- 画面宽度的 26%–28%
- 画面高度的 37%–40%
- 外轮廓宽高比约为 1.2–1.3

这些比例用于视觉校准，不是固定客户端尺寸。

在 1920 × 1080 的标准布局中建议：

- 展开宽度：约 440–540 px
- 展开高度：约 300–420 px
- 顶部标签高度：约 28–36 px
- 外框与叠页总厚度：约 24–36 px
- 正文安全边距：左右至少 28 px，上下至少 22 px

缩放规则：

- 缩小时优先减少可见聊天行数，不压扁包角、标签和叠页。
- 最小尺寸仍需保留至少两层书页、一个完整包角和可辨认的标签轮廓。
- 放大时纸张中心可平铺或拉伸，边缘和包角不得非等比变形。

# 七、交互状态

## 默认状态

- 书本轮廓、纸张和当前频道标签始终可见。
- 辅助按钮降低对比度，但不能把整个聊天框淡化成现代透明面板。

## 悬停状态

- 当前鼠标附近的包角或书签出现轻微暖金高光。
- 左侧工具栏、滚动页夹和缩放书角变得清晰。
- 不使用整块外发光或背景亮起。

## 当前频道

- 对应皮革标签略微上抬。
- 标签表面更暖、文字更亮，底部与书页自然衔接。

## 未读消息

- 对应标签增加小型蜡封、布质书签头或暗紫色线结。
- 禁止红点、数字气泡和现代通知徽章。

## 输入状态

- 底部墨线或纸带轻微加深。
- 输入光标保持简洁，不出现现代搜索框边框。

## 战斗状态

- 聊天框本身不闪烁、不变红、不增加金属装甲。
- 战斗提示仅通过文字色和单行强调表达。

## 锁定状态

- 隐藏拖动、缩放和配置控件。
- 书籍外观保持完整，不能退化成仅有文字的透明区域。

# 八、美术资源清单

后续制作资源时，至少拆分以下内容：

## 可平铺资源

- 旧书页中央填充纹理
- 纸页横向磨损纹理
- 纸页纵向磨损纹理
- 深色封皮中央填充纹理

## 边缘与角件

- 上、下、左、右书页边缘
- 四个不完全对称的书页角
- 四个封皮／金属包角
- 两至四层叠页遮罩
- 底部装订或书脊阴影

## 标签与控件

- 当前频道皮革标签
- 普通频道皮革标签
- 悬停频道皮革标签
- 禁用频道皮革标签
- 未读蜡封／布书签
- 黄铜滚动页夹
- 左侧工具栏底座与按钮
- 右侧收藏／锁定书签
- 输入区域纸带或墨线
- 缩放书角

## 状态覆盖层

- 页边轻微磨损遮罩
- 标签使用痕迹遮罩
- 纸张暗角遮罩
- 非循环的轻微墨迹变化

资源制作要求：

- 先制作无文字母版，所有文字由 UI 层渲染。
- 中央填充、四条边和四个角必须能够独立组合，以支持不同窗口尺寸。
- 角件和毛边保留透明背景。
- 磨损不得在平铺后形成明显重复图案。
- 原始母版保留较高分辨率，运行时版本再根据客户端需要缩减。

# 九、禁止项

以下任一情况出现即视为偏离锁定风格：

- 半透明黑色矩形背景
- 现代卡片、圆角面板或毛玻璃
- 网页式标签页
- 胶囊按钮、悬浮圆形按钮和红点通知
- 细金线框包围深色面板
- 暗黑破坏神式黑红尖锐金属框
- 上古卷轴式纯黑极简文字浮层
- pfUI 式窄边框和高度规整的几何网格
- 大面积镜面黄金、发光符文或高亮粒子
- 规则、完全对称且无页厚的矩形书框
- 把频道或每条消息做成独立卡片
- 为了“干净”而移除书页、封皮、标签或包角

# 十、后续生成提示词锁定段

后续生成任何包含聊天框的游戏内效果图、美术资源或 UI 方案时，必须附加以下要求：

> 聊天框严格沿用“战地旧书聊天框 V1”锁定风格，并以指定基准图左下角聊天框为唯一视觉参考。它必须是一件具有实体厚度的旧书：深棕色厚封皮、暗哑包角、多层毛边书页、暖赭色正文纸面、插在书页上沿的皮革频道索引签、页边书签式工具按钮以及直接印在纸面上的聊天文字。保留略微不对称的手绘轮廓和旧时代低分辨率材质感。不得改成半透明黑色面板、现代卡片、网页标签、暗黑破坏神式尖锐金属框或上古卷轴式极简文字浮层。

使用图像生成工具时，应把基准图片作为实际图像参考附加，而不是只传递文件名或文字描述。

# 十一、验收清单

每次生成或实现后逐项检查：

- 第一眼是否能辨认为旧书，而不是复古面板？
- 是否同时看得到封皮、叠页、主纸面和索引签？
- 外轮廓是否保留轻微不对称？
- 文字是否直接位于纸面，而不是卡片或气泡中？
- 标签是否像皮革书签，而不是网页标签？
- 金属是否暗哑，并且没有压过纸张主体？
- 正文区是否足够安静、平整和易读？
- 聊天框是否与香草风动作条属于同一个时代？
- 是否完全避免暗黑破坏神式战斗面板语言？
- 即使去掉游戏场景背景，组件是否仍然明确属于“艾泽拉斯远征手记”？

任何一项回答为“否”，都应视为未通过风格验收。
