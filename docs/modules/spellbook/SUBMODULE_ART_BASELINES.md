# Spellbook 子模块美术基线 Prompt

以下条款继承 [Spellbook 主模块](ART_BASELINE.md) 与
[全局基线](../../GLOBAL_ART_BASELINE.md)。`SB-SIM-V1` 已由用户接受；每次正式
生产的可执行合同只保存在唯一临时 `CURRENT.md`，接受或放弃后删除。

## `SB.FRAME／PAGE.FIELD`

正面平视的竖向私人法术秘典，严格适配 384×512 香草轮廓与两列×六行内容。
深胡桃旧皮革形成粗厚、略不齐的外缘和可信页层；烟熏羊皮形成连续安静的双列
阅读场。中央仅有浅装订沟和接触阴影，不允许外置书脊压住书页。氧化黄铜只作
短包角和少量维修钉。候选不得包含法术图标、文字、按钮、页码、Tab、关闭或
状态光效；生产后按九切片／独立边件围绕真实安全区重建。

## `SB.SPELL／AUTOCAST`

法术按钮是手工嵌入旧页的独立小型墨线／暗黄铜图标托，保留 37×37 图标和冷却
安全区。普通态安静；悬停只使局部黄铜变暖；按下表现轻微下沉；Checked 用短促
暗金页线识别；禁用降低饱和。自动施法是独立魔法覆盖，不进入底图。不得使用
完全等宽的网页方框、镜像宝石座或持续发光边框。

## `SB.EMBLEM`

当前不生产美术资源。原生左上 58×58 `Spellbook-Icon` 固定隐藏，
`SB.FRAME` 也不得烘焙职业图标、技能书图标或假占位；只有用户明确重开该组件
后，才重新建立独立预演和生产合同。

## `SB.BOOK.TAB`

从书底伸出的短皮革章节签，长度由真实文字决定；三枚轮廓和磨损可以略有不同。
选中态像当前章节被翻到前面，普通／悬停／按下／禁用保持独立。不得做成现代
胶囊标签、等宽工业按钮或烘焙文字。

## `SB.SKILL.TAB`

夹在右侧页边的独立小型皮革／黄铜技能系索引件，中央动态图标完整可读；普通、
悬停、按下、Checked、禁用和 Flash 分层。按实际数量出现，不在主框上画永久
空槽；各索引件可以有轻微手工差异，但真实点击几何一致。

## `SB.PAGE.PREV／NEXT／CLOSE`

翻页控件是嵌在下页边的粗短黄铜页角／皮革拨片，方向清晰且不烘焙页码；关闭
是右上小型皮革搭扣与暗黄铜扣。均提供普通、悬停、按下、禁用，手绘轮廓略有
误差但真实点击区精确。

## 冲突裁决

真实 Blizzard／Turtle 对象和点击区优先于完整预演；主模块 Prompt 优先于临时
候选；用户接受的 tracked source 优先于结构参考。任何完整效果图只提供综合色感，
不得直接作为包含多个交互对象的单张 runtime 背景。
