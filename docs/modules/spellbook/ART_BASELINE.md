# Spellbook 主模块美术基线 Prompt

状态：`SB-SIM-V1` 已锁定。本 Prompt 显式继承
[全局美术基线](../../GLOBAL_ART_BASELINE.md)，并以 Blizzard 1.12.1 的 384×512
技能书结构为第一约束。

## 主模块 Prompt

为 Turtle WoW `1.18.1`／Interface `11200` 重绘 60 级香草魔兽技能书。它必须
首先仍是一眼可识别的香草技能书：竖向 384×512 轮廓、两列法术、每页 12 个
条目、右侧技能系索引、底部书类 Tab、底部翻页与动态页码均保持原操作习惯。
本次只撤掉 pfUI 的半透明规则方框和现代统一按钮，不改变信息结构。

物件身份是“冒险者长期随身使用的私人法术秘典”。一本正面平视打开、页层厚实、
装订可信但略显粗糙的旧皮革魔法书；不是任务日志的正式公会卷宗，不复刻任务书
目录、火漆事务系统或聊天框的横向战地旧书。深胡桃旧皮革承担封边与承托，暖赭
烟熏羊皮承担阅读，氧化黄铜只用于克制包角、维修钉、翻页件和选中标记。

严格继承香草时代二维手绘位图、粗厚且略不规则的轮廓、左上暖光、低饱和
暖赭／深胡桃／氧化黄铜、短促不连续高光、页边毛糙、手工装订误差、烟熏、
墨渍、磨圆和接触阴影。左右页可有轻微不同的磨损，但不能为了粗糙而破坏
384×512 可读结构。中央只能是浅而可信的装订沟，不得出现浮在书页之上的外置
书脊、上下压死的缝线或无法翻页的结构。

主要纸面连续、安静、低对比，法术文字和图标必须是视觉主体。魔法色只来自
运行时法术图标、自动施法和短暂反馈；静态书体不常亮、不按职业染整本书、不
加入大面积蓝紫辉光。交互反馈依靠皮革索引签抬起、局部暗金变暖、页角压痕和
阴影收紧，而不是现代发光描边。

禁止现代扁平化、半透明黑卡、统一圆角、极细规整金边、玻璃、科技 HUD、
移动应用式技能列表、精密工业对称、暗黑 3 尖刺黑铁、骷髅祭坛、持续霓虹
符文、镜面黄金、照片级古董和上古卷轴式极简黑色浮层。禁止把法术名、图标、
等级、页码、Tab 文字、冷却或自动施法状态烘焙进静态大图。

## 字体

- 主标题：`NotoSerifSC-SemiBold.ttf`。
- 法术名、技能系名和等级：优先客户端高可读字体；中文环境可用
  `NotoSansSC-Medium.ttf`，禁止 Light 字重。
- 页码：客户端清晰数字字体，只允许克制暗描边。

## 生产边界

完整预演只锁定物件身份、结构和综合色感。正式生产必须按
[SUBMODULES.md](SUBMODULES.md) 拆分主外壳／页场、法术按钮、书类 Tab、技能系
Tab、翻页和关闭。ImageGen 只提供手绘材料与轮廓 donor；确定性脚本负责精确
尺寸、安全区、原生四块切片、状态派生和 runtime 导出。左上原生
`Spellbook-Icon` 当前固定隐藏，不为其生产或烘焙职业图标。
