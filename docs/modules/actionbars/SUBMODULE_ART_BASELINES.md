# Action Bars 子模块美术基线 Prompt

以下条款继承 [Action Bars 主模块](ART_BASELINE.md)、
[全局基线](../../GLOBAL_ART_BASELINE.md) 与 Character V3 的槽体材料关系。

## `AB.RAIL`

生成可九宫格伸缩或按行列重复的窄型远征动作 Rail：深胡桃皮革／木芯、氧化
黄铜窄外沿、少量铆钉和克制磨损。中心区必须能无缝拉伸，端角只占真实 Frame
外沿，不进入按钮安全区。横向、竖向、`6×2` 与 `4×3` 使用相同厚度。不得
生成固定十二格底板、厚重石台或大面积黑透明背景。

## `AB.SLOT`

基底生成一枚经典正方形技能槽：深胡桃旧皮凹面、克制的氧化黄铜窄沿、左上
短暖高光和右下暗压边。它位于动态图标下方，中央约 `90%` 线性尺寸是安静、
低细节、可被图标完整覆盖的深皮区域；不得包含技能、职业符号、快捷键、数量、
宏名或冷却。轮廓用于 `18–48 UI` 图标尺寸的统一方形缩放，不依赖固定行列。

悬停、当前技能与按压属于 `AB.SLOT.STATE` 的独立 runtime 覆盖，不与基底烘焙。
按下以后只允许复用同一基底并产生 `1 px` 视觉下沉；pfUI 没有独立 disabled
Button cell，不得为其虚构一格。范围红、法力蓝、不可用灰、装备绿与冷却遮罩
继续由 `f.icon`、`f.equipped` 与 `f.cd` 动态提供。

用户于 `2026-08-08` 接受 `AB.SLOT.BASE.V1` 第 5 稿；正式 P4 母版为
[ActionSlotBase_Master_v1.png](../../../assets/source/actionbars/ab-slot/ActionSlotBase_Master_v1.png)，
SHA-256 `6d4a4d16…7dc0`。稳定视觉条款为：深褐旧皮／胡桃色主导，暗黄铜只形成
稀少断续短段；中央保持低频、低对比和无焦点细节；完整轮廓正方、边带轻薄，
缩至约 `19–42` 物理像素时仍退居动态图标之后。该派生 source 低于 Character V3
锁定图及本 Prompt 的视觉权威，只能作为普通／空槽基底；不得反向定义 Rail、
状态覆盖、姿态／宠物、消耗品、饰品或战斗读数的造型。

## `AB.ENDCAP.GRYPHON`

生成左右镜像的一对香草狮鹫动作栏端帽。轮廓紧凑，羽片由深褐旧皮／暗金
手绘切面构成，氧化黄铜只作骨架与擦亮边；头部朝外、身体贴合 Rail，不遮挡
首尾按钮。两端帽分别独立透明，允许按宽度关闭。禁止龙头、恶魔角、大翅膀、
宝石、旗帜、阵营徽章和比动作栏更高的雕塑。

## `AB.STANCE／AB.PET`

复用技能槽几何，但外沿更薄、综合色重更轻。姿态槽可增加低对比压印方向感；
宠物自动施法旋转、攻击态与冷却仍由 provider 覆盖。不得生成职业不存在的
姿态或固定宠物技能。

## `AB.CONSUMABLE.RACK`

生成炼金师随身皮革卷袋的自适应外壳：暖褐旧皮、可见折边、粗细不完全一致的
缝线和少量黄铜扣。推荐 `5×2`，但边／角必须支持 `1–24` 个真实按钮的合法
行列；中部纹理可重复，接缝不能形成假口袋。不得退化为技能条、现代网格卡片
或固定十瓶药水插画。

## `AB.CONSUMABLE.POCKET`

每个口袋是独立正方形开口：软皮翻边、深色袋内与轻微压痕，普通／悬停／按下／
空／禁用几何一致。中央完整留给真实物品图标；数量、冷却、缺货、选中 family
和 Tooltip 全部动态。禁止固定瓶子、食物、文字标签、类别符号和宽品质光圈。

## `AB.CONSUMABLE.POPUP`

候选层像从主卷袋后方翻出的薄皮口袋列，保持清楚 z-order 与每格命中区；连接
处使用短皮带／黄铜扣，而不是悬浮玻璃面板。AutoBar 原有方向和数量未经实机
上限审计前，不生成固定整张弹出背景。

## `AB.TRINKET.DOCK`

生成一对相连但可拆分的深皮革饰品护套：两枚方槽各有独立黄铜扣、轻微内凹和
比普通口袋略厚的边缘。水平／垂直方向都能组合；实际饰品图标、冷却、快捷键、
排队状态与空槽提示保持动态。禁止珠宝柜、发光宝石底座和固定饰品图。

## `AB.TRINKET.MENU`

候选饰品沿护套外侧以薄皮插页展开，选中只用前移、短暖边和小扣状态表达。
当前只锁定隐喻，不锁定几何；必须先测 TrinketMenu 的真实候选数量、方向、
缩放和战斗行为，再形成独立 production Prompt。

## `AB.MOVER／CONFIG`

移动把手与配置入口使用低调黄铜扣／皮带环，只在 unlock 或配置态出现；不得在
战斗常驻、遮挡按钮或成为大型齿轮按钮。拖动、吸附、缩放与重置状态由代码
表达，不烘焙说明文字。

## `AB.FOCUS.CASTBAR`

生成与动作 Rail 同源但更薄的施法读数外壳：深胡桃窄底、单层氧化黄铜细沿、
左上短暖高光和安静的文字安全区。玩家／目标条必须几何同宽并各自贴合单位框；
Focus 条沿用相同语言但留在 Focus Frame。法术图标、名称、Rank、计时、玩家
延迟区、引导方向与可打断状态全部由 pfUI 动态覆盖。禁止固定法术、厚重槽座、
巨大发光读条或把目标警示烘焙成常驻红框。

## `AB.FOCUS.SWING`

生成 `200×12 UI` 可拉伸攻击细轨：深色旧皮／木芯、极薄黄铜上下沿、清楚的
移动 Marker 与两端文字净空。主手与副手上下排列且重量一致，副手可隐藏；远程
条复用同一层并保留 provider 的左／右／警告区。禁止拟物武器插画、固定攻速、
三条同时常驻、霓虹进度光或抢过施法条的粗外框。

## `AB.DOITEDPS.TIMELINE`

只为真实 `318×46 UI` DoiteDPS 时间线提供可选的低重量远征外缘：极暗蓝黑底与
克制的旧黄铜细线可以把它纳入综合色，但 Ready 槽、Forecast 图标、移动轨迹、
ETA、资源、冷却与蓝／绿／橙／红语义必须完整保留为 provider 动态内容。不得
复制旋转逻辑、固定职业技能、把时间线扩成第二排动作格，或改写插件自身拖动、
缩放、锁定和战斗显隐。

## 当前 provenance

- Character V3 仅提供槽体材料、轮廓、暖光、磨损与状态克制程度；不继承角色
  窗口轮廓、属性纸面、装备压印或 Tabs。
- 全局 Prompt 的经典技能格、成对狮鹫与炼金师皮革卷袋身份是模块结构权威。
- `ACTION-BARS-CORE-SIM-V1／V2／V3` 只承担布局与综合色重确认，永远不能成为
  production source、runtime 或 ImageGen reference；V1 的贴底布局已被用户
  否决，V2 因缺少完整战斗信息链进入修订，V3 已于 `2026-08-08` 获用户确认，
  只作为当前 `P2` 布局方向，不提供生产像素。
