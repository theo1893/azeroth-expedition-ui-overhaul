## 主模块 Prompt

为 Turtle WoW `1.18.1` 制作“艾泽拉斯远征手记”的战斗动作区。它必须首先被
识别为香草魔兽的经典技能格、底部动作甲板与成对狮鹫端帽，而不是现代 MMO
热键 Dashboard。所有装饰围绕真实技能按钮让路：图标、冷却、快捷键、数量、
宏名、范围与资源反馈的辨识优先级高于纹样。

动作槽继承 Character V3 的深胡桃旧皮凹面、厚而克制的氧化黄铜外沿、左上
暖光、低饱和综合色与清楚按压层次；但比装备槽更简洁、更坚固，适合高频点击。
每条动作 Bar 使用可伸缩的窄皮革／木质 Rail 和少量铆钉连接真实槽位，不制作
固定宽度的大底板。水平、竖向、单行与多行必须保持同一材料语言；转角只在
真实行列外缘出现。

Bar 1 可使用左右成对的香草狮鹫端帽：旧黄铜骨架、深褐羽片和少量暖金擦亮边，
视觉重量低于技能图标，不遮挡槽位、不扩大命中区。非水平、过窄或紧凑布局中
端帽允许缩小或隐藏，不用龙翼、恶魔角、宝石王冠或大型阵营徽章替代。

消耗品区不是另一排技能格，而是一只炼金师随身皮革卷袋：暖褐旧皮、缝线、
折边与小型黄铜扣形成 `1–24` 个可重排口袋；推荐状态为 `5×2` 十格。口袋保持
正方形真实物品安全区，皮革只包围边缘，不能画入药瓶、食物、绷带、名称或
数量。弹出候选应像从同一卷袋翻出的薄层口袋，而不是网页下拉菜单。

饰品区是一对固定在卷袋旁的深皮革护套与黄铜扣，分别承载当前装备槽 `13`、
`14`。两槽必须比普通消耗品口袋略庄重，但不做成大型珠宝展示台；更换候选
沿护套外侧展开，战斗中仍以当前已装备饰品和冷却可读性为第一优先。

综合色重集中在屏幕下缘，中心主栏最清楚，副栏和侧栏逐级减轻。空槽与脱战
淡出保持低对比，但不能让已绑定动作在战斗中难以辨认。状态通过独立窄内沿、
短高光、按压位移和 provider 色调表达，不使用持续外发光、霓虹描边或整块
彩色按钮。

禁止超薄黑色透明条、玻璃拟态、无边方块、连续金属栅格、赛博霓虹、巨型
石雕底座、复杂徽章墙、每格独立标题卡、固定技能／物品图标，以及把整套 UI
烘焙成一张不可伸缩的底栏图。

## 字体

- 模块／配置标题：Noto Serif SC SemiBold。
- 快捷键、数量、冷却与短状态：沿用 pfUI／客户端高可读字体；不由美术资产
  生成。
- 不在战斗槽内使用叙事楷体或装饰铭文占用图标面积。

## 生产边界

当前方向模拟只确认布局、物件隐喻、材料层级、配色与综合色重；它不是 source、
runtime 或 ImageGen 输入。正式生产必须按 [SUBMODULES.md](SUBMODULES.md)
拆分 `AB.RAIL`、`AB.SLOT`、狮鹫、消耗品卷袋、口袋、饰品护套和候选菜单，
并以真实 provider 尺寸和状态另行授权。
