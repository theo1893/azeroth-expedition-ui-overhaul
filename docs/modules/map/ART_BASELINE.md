# Map 主模块美术基线 Prompt

状态：已锁定。大地图最高参考为
[大地图基准](../../../assets/locked/map/大地图羊皮卷_视觉基准_v1.png)、
[小地图基准](../../../assets/locked/map/小地图黄铜罗盘_视觉基准_v1.png)
只提供随身罗盘的物件身份与材料家族；当前小地图结构以本 Prompt 为最高裁决，
显式覆盖锁定图中的精密对称、外置长铭牌、右侧拨片与吊牌。本 Prompt 继承
[全局美术基线](../../GLOBAL_ART_BASELINE.md)。

## 主模块 Prompt

为 Turtle WoW `1.18.1` 制作“艾泽拉斯远征手记”中的远征制图师地图套件。
严格继承香草时代二维手绘位图、厚实略不规则轮廓、明确明暗切面、左上暖光、
低饱和暖赭／深胡桃／氧化黄铜综合色温和长期使用痕迹。

大地图首先是一张真正展开的宽幅羊皮地图卷：一整张连续旧羊皮，上下深胡桃木
卷杆、克制旧黄铜端帽、少量皮革固定带、顶部窄标题铭牌、左侧层级索引、右侧
provider 过滤入口，以及沿底部卷杆布置的单一层级返回与动态坐标。地图安全区
占纸面约 80%–85%，不出现中央书脊、双页结构或连续厚皮背板；锁定图中的
加号、滑块与完整缩放尺只作旧结构参考，因没有真实对象而不得进入 production。

小地图首先是一枚经过长期野外使用的随身航向罗盘。真实圆形地图始终保持
140×140，不因装饰或文字缩小；约 204×204 的外壳向外生长，由粗粝深胡桃旧
皮革悬托、两层厚薄不一的暗哑氧化黄铜导向环、四处块状固定件和顶部北向冠件
形成闭合结构。外沿装饰要比 V2 丰富，能读出罗盘的机械承托与制作年代，但仍
保持香草魔兽的二维手绘简化：铆钉疏密不均、边缘磨圆、局部凹损和一两块非对称
维修片，不能成为精密齿轮、工业仪表、波浪花边或均匀珠宝环。

区域名和坐标不再压在地图内。罗盘下方固定连接一个短而厚实的“制图信息托架”，
它是携行罗盘自身的皮革／黄铜承托结构，不是悬浮网页铭牌、长吊牌或独立 HUD。
托架只提供两块安静的动态文字安全区；文字由 runtime 绘制，任何地名和数字都
不得烘焙进美术。托架与罗盘的接触、绑带、铆钉和阴影必须说明两者属于同一件
实体，同时不得占用或遮挡 140×140 地图窗口。

插件整合是罗盘携行结构的可动层：真实 `pfMinimapButton` 重绘为附着在配置方向
的短皮革／黄铜锁扣，真实 `pfMinimapButtons` 重绘为从锁扣外侧展开的深色制图
工具卷。V4 不再使用独立 connector：锁扣必须位于工具卷之上并直接压住其连续
受力边，以可见 Alpha 的实体搭接表达固定关系，不能出现漂浮箭头、悬空面板、
多余桥接件或图层断裂。
bottom 方向的锁扣附着信息托架底部，left／top／right 附着罗盘对应外沿；工具卷
只承载实际存在的插件入口，使用可重排九切片。真实插件图标直接落在低对比材料
面上，不叠加统一逐图标装饰框；0 个插件时锁扣和空工具卷全部隐藏。
追踪、邮件、战场和 PVP 使用同一家族的小型独立状态插槽，随真实对象分别显隐，
不能永久画进罗盘底图。

两者共享纸张、皮革、黄铜、墨迹、磨损和制作年代，但必须一眼区分为“展开
地图卷”和“随身罗盘”，不能复制聊天旧书或任务卷宗轮廓。地图内容始终是视觉
主体；正式地形、道路、地名、队伍、任务范围、资源和坐标由游戏动态绘制。

悬停使用黄铜边缘轻微变暖、皮革签抬起或纸面局部提亮；按下使用下沉、压痕和
阴影收紧。禁止现代网页地图、玻璃面板、卫星地图、汽车导航、军用雷达、
科幻 HUD、CAD 刻度、电子屏、复杂齿轮、蒸汽朋克、暗黑 3 尖刺黑铁、照片级
古董和上古卷轴式极简地图。

明确禁止已弃用方向：大地图不增加暗酒红连续厚皮背板、宽固定带或重型压夹；
小地图不增加八槽永久插件环、一圈密集插件徽章、地图内信息栏、漂浮箭头、与
罗盘无接触关系的插件面板，或为了装饰而缩小真实地图可见面积。

## 字体

- 地图主标题：Noto Serif SC SemiBold。
- 手写式短注释与索引：霞鹜文楷 GB Medium。
- 坐标、缩放、时间与密集信息：客户端高可读字体。

## 生产边界

完整基准只锁定综合色感和结构。生产资产必须按
[SUBMODULES.md](SUBMODULES.md) 拆分卷杆、端帽、纸边、真实 Dropdown、单一层级
返回、关闭、复选框，以及小地图 V3 的常驻罗盘／信息托架外壳、圆形 mask、独立
锁扣、状态插槽和 V4 九切片工具卷；插件入口不生产统一外框，独立 connector
不再属于运行时组件。不能把真实
控件、动态文字、地图或图标烘焙进单张背景。小地图真实内容保持 140×140，约
204×204 罗盘环和下置信息托架只向外延展；右上锚定时要按整套外延和展开方向
计算屏幕安全距，不能通过压缩 provider 补偿。
