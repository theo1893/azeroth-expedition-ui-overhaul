# 一、设计结论

地图模块是一套由远征制图师长期使用的导航装备：

1. **大地图：远征制图师世界地图卷**
   - 一张安装在上下木质卷轴杆之间的宽幅羊皮地图。
   - 强调世界探索、地理阅读、地图工具与展开卷轴的实体感。

2. **小地图：黄铜航向罗盘**
   - 一枚包有旧皮革、经过长期使用的圆形黄铜导航仪器。
   - 强调方向识别、即时定位和右上角常驻 HUD 的清晰度。

二者共享纸张、皮革、氧化黄铜、墨线和手工装配痕迹，但必须一眼区分为“展开的地图卷”和“随身罗盘”，不能成为聊天旧书或任务卷宗的变体。

本模块的核心关系是：

> 大地图像铺开的远征地图卷；小地图像固定在装备上的黄铜航向罗盘；聊天与任务则属于记录和阅读工具。

# 二、共享且不可变的视觉语言

1. **香草时代魔兽手绘质感**
   - 使用 2004 年前后经典魔兽 UI 的厚轮廓、手绘位图、略微夸张的体积和清晰的明暗分层。
   - 不能变成现代网页地图、照片级古董、写实道具或精密工业仪表。

2. **稳定的材料分工**
   - 羊皮纸承担地理信息与图例。
   - 深胡桃木承担大地图卷轴杆。
   - 深胡桃色旧皮革承担固定、连接和随身携带感。
   - 氧化黄铜承担刻度、端帽、按钮、铆钉与导航构件。

3. **地图信息优先**
   - 主要地图区域保持连续、低对比度和可读。
   - 磨损、折痕、水渍与装饰集中在外缘。
   - 地形、道路、地名、任务范围、队伍位置和资源标记不得被材质噪声遮盖。

4. **克制的史诗感**
   - 史诗感来自厚木、旧纸、暗金、手工固定结构和真实使用痕迹。
   - 不依赖骷髅、龙头、翅膀、尖刺、火焰、巨大宝石或持续发光。

5. **材质反馈代替现代特效**
   - 悬停使用黄铜边缘变暖、皮革签轻微抬起或纸张局部提亮。
   - 按下使用构件下沉、阴影收紧和压痕变化。
   - 禁止霓虹描边、玻璃高光、背景模糊和大面积色块。

# 三、大地图：远征制图师世界地图卷

## 3.1 物件身份

按 `M` 打开后，首先必须被识别为一张真正展开的宽幅羊皮地图卷，而不是书本、双页卷宗、黑色全屏遮罩或现代网页地图。

大地图需要比任务追踪更正式、比任务详情更开阔；它的视觉重量来自上下卷轴杆、纸张卷层与黄铜端帽，而不是连续厚皮背板。

## 3.2 固定结构

从外到内依次为：

1. 上下两根深胡桃木卷轴杆
2. 卷轴杆两端的氧化黄铜端帽
3. 少量皮革固定带、绳结与黄铜铆钉
4. 一整张连续的旧羊皮纸
5. 顶部居中的窄皮革标题铭牌
6. 左侧垂挂的地图层级索引签
7. 右侧展开的窄幅图例纸
8. 底部嵌入卷轴杆的黄铜制图尺与缩放控件

不可移除的识别特征：

- 上下木质卷轴杆同时可见
- 黄铜端帽具有经典魔兽式厚度
- 左右纸边保留卷曲、页层与接触阴影
- 中央是一张连续纸面，不出现中央书脊
- 左侧索引签与右侧图例形成不完全对称的工具布局
- 顶部标题牌和底部缩放尺均依附在卷轴结构上

## 3.3 比例与地图安全区

- 整体宽高比目标：约 `1.35–1.50 : 1`
- 连续地图安全区：羊皮纸面积的约 `80%–85%`
- 标题铭牌：窄而居中，不遮挡上部地形
- 左侧索引签：位于地图纸面之外或只轻微压住卷边
- 右侧图例：保持窄幅，可收起，不侵占主要地形阅读区
- 底部缩放尺：嵌入卷轴杆，不形成悬浮工具栏

实际游戏中保留原始魔兽地图图层。羊皮纹理只作为低对比度底层与外缘资源，不重新绘制或覆盖正式地形、道路和地名。

## 3.4 导航与控件

- 世界、大陆、地区与副本层级使用垂挂的小型皮革索引签或蜡封图章。
- 飞行点、城镇、队伍成员、任务和重要地点使用统一的手绘墨印或小型珐琅徽记。
- 任务范围使用低透明度墨水圈、铅笔线或蜡笔式阴影。
- 缩放使用底部黄铜制图尺上的滑动标记以及厚实的 `− / +` 端点。
- 关闭按钮表现为右上方挂在卷轴杆上的皮革固定扣与黄铜搭扣。
- 控件文字和图标保留经典魔兽的厚笔画、明确轮廓与按压反馈。

## 3.5 明确禁止的 V2 结构

- 不增加连续的暗酒红厚皮背板。
- 不增加大面积宽皮带、四角压片或重型黄铜夹具。
- 不把木杆、端帽和标题牌继续放大来制造重量。
- 不把有效地图面积压缩到 V1 基准图以下。

# 四、小地图：黄铜航向罗盘

## 4.1 物件身份

右上角小地图必须首先被识别为一枚香草魔兽式手绘黄铜罗盘，其次才是圆形 UI 窗口。它应当结实、温暖、有使用痕迹，但不能像现代仪表盘或厚重金属牢笼。

## 4.2 固定结构

从外到内依次为：

1. 深胡桃色旧皮革外托与固定带
2. 两层氧化黄铜罗盘环
3. 刻度与四个方向标记
4. 中央完整圆形地图视野
5. 顶部明显但克制的北方指针
6. 右侧独立的上下拨片
7. 下方窄幅定位／时间铭牌
8. 右下方短皮革吊牌与小型 `+ / −` 控件

不可移除的识别特征：

- 中央地图视野至少占总体直径的约 `70%`
- 双层旧黄铜圆环与少量青绿色氧化痕迹
- 外围深皮革只作为承托，不形成第三层重型金属环
- 顶部黄铜北方尖冠
- 四个方向件造型厚实、轮廓明确
- 右侧拨片、底部信息铭牌和右下吊牌保持 V1 的非对称构图

## 4.3 地图标记与状态

- 玩家、队友、尸体、任务、商人、飞行点和资源节点使用统一的小型珐琅针、墨印或黄铜标记。
- 标记必须保留经典魔兽的轮廓识别与必要颜色差异。
- 追踪入口表现为侧挂皮革制图标签。
- 坐标与时间位于底部窄铭牌，不使用电子数字屏幕。
- 黄铜仅有暗哑高光、细小刮痕和边缘磨损，不使用镜面黄金。

## 4.4 插件图标兼容边界

香草时代插件图标仍可挂载在小地图附近，但这属于运行时布局能力，不属于基础罗盘母版的永久装饰。

- 默认状态保持 V1 基准图的干净外环，不绘制完整插件徽章环。
- 插件入口优先吸附在右下短皮革吊牌或不遮挡方向件的外缘可用位置。
- 数量较多时可使用一个可展开的“制图工具袋”入口，但必须是可选扩展层。
- 插件原始图案可以保留，外框可统一为小型黄铜／皮革徽记。
- 无论挂载多少入口，都不能遮挡中央地图、北方指针、四向标记、缩放和追踪控件。
- 任何未来插件承载方案都不得改变本规范锁定的小地图基础轮廓。

## 4.5 明确禁止的 V2 结构

- 不使用环绕整个罗盘的八槽永久插件轨道。
- 不在默认效果图中展示一圈密集插件徽章。
- 不增加额外加厚的金属外环或吸附槽层。
- 不以“功能可承载”为理由牺牲中央地图面积和罗盘辨识度。

# 七、资源拆分指导

大地图至少应拆分为：

- 可平铺／九宫格处理的中央羊皮安全区
- 左、右卷边
- 上、下木质卷轴杆
- 黄铜端帽与固定带
- 顶部标题铭牌
- 左侧索引签组
- 右侧可收起图例
- 底部制图尺、滑块与 `− / +`
- 关闭扣与交互状态

小地图至少应拆分为：

- 中央圆形地图遮罩
- 内外黄铜罗盘环
- 深皮革外托
- 北方指针与四向标记
- 右侧上下拨片
- 底部信息铭牌
- 右下皮革吊牌与 `+ / −`
- 地图标记框架与交互状态

拆分必须保留 V1 的轮廓关系，不得因九宫格或锚点实现方便而拉直卷边、压扁端帽或把罗盘改成规则现代圆框。

# 八、统一负面约束

禁止现代网页地图、玻璃拟态、半透明黑色面板、背景模糊、圆角卡片、悬浮工具栏和移动应用式图标。

禁止现代军用雷达、汽车导航、科幻 HUD、CAD 精密刻度、电子数字屏、复杂齿轮、管道、压力表和蒸汽朋克机械。

禁止《暗黑破坏神 3》式尖刺黑铁、骷髅、恶魔角、火焰金属和高对比红黑配色。禁止《上古卷轴 5》式极简文字地图。禁止照片级真实古董质感。

禁止把大地图做成书本或双页任务卷宗。禁止把小地图做成厚重金属牢笼。禁止让大型雕像、龙头、翅膀、徽章环或插件按钮侵占地图显示面积。

# 九、验收清单

生成或实现地图模块时，逐项确认：

- [ ] 大地图与小地图分别匹配各自的 V1 视觉基准，而非 V2 探索稿。
- [ ] 大地图一眼可识别为单张宽幅羊皮地图卷。
- [ ] 大地图保留上下木杆、黄铜端帽、左侧索引、右侧图例和底部制图尺。
- [ ] 大地图没有连续暗酒红厚皮背板、宽皮带或重型压夹。
- [ ] 小地图一眼可识别为旧黄铜罗盘。
- [ ] 小地图中央地图直径不低于总体直径的约 70%。
- [ ] 小地图保留顶部北方指针、四向标记、右侧拨片、底部铭牌和右下吊牌。
- [ ] 默认小地图没有永久八槽插件环或一圈密集插件徽章。
- [ ] 两个组件保持香草魔兽手绘位图语言，没有现代化、暗黑化或写实化。
- [ ] 与聊天旧书、任务卷宗和行军便笺同属一个世界，但轮廓不会混淆。
