# Map 子模块美术基线 Prompt

以下条款继承 [Map 主模块](ART_BASELINE.md) 与
[全局基线](../../GLOBAL_ART_BASELINE.md)。

## `MAP.WORLD.FRAME`

生成正面平视、横向约 `1.35–1.50:1` 的空羊皮地图卷结构资源。中央是一整张
连续、低对比、可承载原生地图图层的旧羊皮；上下各有深胡桃木卷杆，端点为
克制的氧化黄铜端帽。纸边有手绘卷曲、页层和接触阴影，木材、皮革与金属各自
拥有明确厚度。标题铭牌、索引、图例、缩放尺和关闭扣必须作为独立对象，不得
烘焙在可拉伸纸面。禁止中央书脊、双页、厚皮背板和重型夹具。

## `MAP.WORLD.CONTENT`

不生成正式地图内容。只生成极低对比羊皮底层和不可拉伸卷边；原生地形、道路、
地名、标记与任务范围保持运行时图层。任何纹理都不能降低地图可读性。

## `MAP.WORLD.LEVELS／LEGEND／ZOOM／CLOSE`

- 层级入口：小型垂挂皮革索引签或蜡封图章，各真实 Button 四状态。
- 图例：可收起窄幅制图说明纸，不能永久压缩地图。
- 缩放：嵌入底部卷杆的黄铜尺、滑块、减号与加号，分别拆分。
- 关闭：右上皮革固定扣与黄铜搭扣，四状态，无烘焙文字。

真实对象和几何未完成前，这些条款不可直接作为 production Prompt。

## `MAP.MINI.MASK／COMPASS`

生成一枚正面平视的旧黄铜航向罗盘结构。中央圆形透明／遮罩区域至少占总直径
70%；外围仅两层氧化黄铜环与少量深胡桃皮革承托。黄铜有短促暗哑高光、
刮痕和极少青绿氧化，但不是镜面金或精密仪表。罗盘背景不得包含缩放、追踪、
时间、坐标、邮件、战场或插件按钮。

## `MAP.MINI.NORTH／DIRECTIONS／CONTROLS`

北针是顶部厚实但克制的黄铜三角件；四向标记轮廓明确、适合小尺寸。缩放、
追踪、邮件、战场与其他真实 Button 分别提供普通／悬停／按下／激活或禁用
状态。时间、坐标与区域名由 runtime 绘制在窄铭牌上。

## `MAP.MINI.ADDONS`

插件图标托是独立暗皮革／氧化黄铜小型外壳，保留原插件图案和点击行为；提供
普通、悬停、按下、激活、禁用。未读／警告是独立小蜡点、布结或短高光。
溢出入口表现为可展开制图工具袋，展开挂带使用上／中／下三段式。底图不画
空槽，不形成永久按钮环，不遮挡北针、方向、缩放或中央地图。
