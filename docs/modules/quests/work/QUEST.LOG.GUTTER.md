### 必须继承的视觉 DNA

- 首先识别为一册正式、长期保存并反复翻阅的“冒险者公会任务卷宗”，不是
  两块普通羊皮纸、现代棕色面板、古董照片或暗黑祭坛。
- 保持 2004 年前后香草魔兽二维手绘位图语言：粗厚且略有手工误差的轮廓、
  明确明暗切面、略微夸张的实体厚度、温暖奇幻气质和低分辨率游戏美术感。
- 与战地旧书聊天框共享材料精度、笔触、左上暖光、磨损尺度和制作年代，但
  任务详情保持正式双页公会卷宗身份，不能复制聊天框的单页旧书轮廓。
- 综合色彩低饱和：暖赭与旧象牙纸面、烟褐与深胡桃阴影、暗酒红相邻封皮、
  少量氧化旧黄铜色反光。森林绿和褪色蓝灰只属于后续织物书签，本批不生成。
- 纸、麻线和衬布必须有不同的厚度、接触阴影与磨损方式；材料关系依靠手绘
  体积和遮挡表达，不能靠满页复古花纹或照片纹理表达。
- 主要阅读区平整、安静、低对比，装饰与高频磨损集中在不可拉伸边缘；保持
  可承载中文长正文的纸面，而不是均匀压花底板。
- 《上古卷轴 5》只提供沉重材料和低饱和配色，不继承极简文字菜单；禁止
  《暗黑破坏神 3》式尖刺黑铁、黑红高对比、骷髅与祭坛结构。

### 本批组件级转译

- 完整原型中的厚重感在本批由左右纸页的手绘厚边、内缘弯曲、凹陷页沟、
  半藏横向粗麻针脚和与外围书体一致的接触阴影表达。
- “正式公会卷宗”不通过徽记、蜡封或按钮烘焙表达，而通过同批纸张、克制
  装订、近等宽双页、较整齐但仍有手工误差的页缘表达。
- 正面游戏 UI 构图与书内视角统一为浅俯视：整体仍正对玩家，只有纸页表面、
  厚边、内折和页沟拥有一致的轻微深度，不允许单个部件变成侧视或独立 2D
  平板。
- 本批的纸张微纹理以 Image 1 的安静阅读区和原始提示词为准；Image 3 的
  满页细碎压花明确不继承。

### 明确不继承

- 不继承完整原型中的任务行、伪文字、页码、织物书签、黄铜书扣、包角、
  徽记、蜡封、滚动条、按钮、奖励槽和 `42%／58%` 的视觉列宽。
- 上述元素不是被放弃，而是分别属于后续 runtime 组件；本批不得把它们

- 不继承聊天框的横向单页轮廓、索引签、输入条或页码结构。
- 不继承 Image 3 的现有页沟、针脚、满页压花和任何由先前生成造成的漂移。

### 冲突审计

- 原型提示词的左 `42%`／右 `58%` 指信息列；组件合同要求物理双页近 1:1。
  裁决：纸页外接尺寸相同，比例只在未来 runtime 文字布局中实现。
- 原型包含书签、页码、黄铜件和完整封皮；本批只有八个非交互内部结构对象。
  裁决：保留其材料年代和相邻色彩，不生成这些由其他组件持有的实体。
- 原型写“正面平视”，已接受结构 source 带轻微内部俯视。裁决：使用正对玩家
  的浅俯视 UI 视角；所有八对象共享同一表面法线、厚度尺度和左上光源。
- Image 3 的正文有高频压花，而锁定基准和原始提示词要求阅读区安静。
  裁决：Image 1 与其 prompt 优先，Image 3 纹样不继承。
- V3 曾把 Image 3 称为最高权威。裁决：该权威倒置作废；V3.1 的执行正文
  必须明确 Image 1 最高、Image 3 仅为受限结构参考。

## V3 失败后必须改变的结构

1. `GUTTER.UNDERLAY` 不再是完整的织纹竖条。它只能是大部分透明、无硬边、
   无可识别编织网格的凹陷阴影与低对比深胡桃衬布。
2. `LEFT_FOLD`／`RIGHT_FOLD` 不再是带四周完整轮廓和上下毛边的独立纸条。
   它们只能是大部分透明的单侧纸面弯曲渐变遮罩。
3. `GUTTER.STITCH` 必须在正确层序下仍露出中央短段；端点伸入内折遮罩，但
   不能被全部遮没，也不能出现两个深色端部结点。
4. `GUTTER.TOP`／`GUTTER.BOTTOM` 必须是紧凑、不规则、半藏的小线结，不能
   像横向把手、桥、U 形扣或两端带球的杆件。
5. 正文纸面不复制 V3 当时使用的派生母版（本版 Image 3）中的满页均匀细碎
   压花。中央改为低频斑驳、轻纤维和缓慢色差；任何高频纹理只留在不可拉伸
   边缘。

### 源画布与固定排布

- 目标画布：`1536 × 1024`。
- 优先真正 RGBA 透明背景；若不能可靠透明，只允许完全均匀的纯
  `#00FF00` 色键。
- 上排：
  - 左页放在左半区，右页放在右半区。
  - 两页使用相同大小的隐形外接单元和连续裁切边距。

  3. 右内折；
  4. 横向针脚站；
  5. 顶部线结；
  6. 底部线结。
- 下排六个单元不得上下堆叠、接触或通过阴影相连。

### 每个对象的形态门禁

#### 左右纸页

- 两页同高、近等宽、同纸张批次，拥有相反方向的专用内缘曲面。
- 左页略暗暖赭，右页略亮旧象牙，但综合色差必须克制。
- 每页中央至少 `80%` 的阅读面积接近素纸：只允许低频云状斑驳、极轻纤维
  与缓慢综合色差。
- 禁止满页压花、浅浮雕字符、机械重复卷草、密集裂纹、网纹或均匀细碎噪声。
- 外侧毛边、页角、底边与专用内缘不可拉伸；中央安静区允许有限九宫格伸缩。

#### 页沟底层

- 以透明为主，只包含窄幅、向中央变深的柔和凹陷阴影，以及极低对比的深
  胡桃衬布色。
- 左右边缘必须长距离羽化到透明，不能拥有完整明边、硬直轮廓或矩形剪影。
- 不得出现可辨识的编织网格、辫绳、拉链齿、连续纵向绳杆、皮革竖带或外封脊。
- 中段允许纵向平铺，但平铺后不能产生重复花纹节奏。

#### 左右内折

- 每个对象大部分区域为透明，只保留一条单侧纸张高光、内弯综合色差和接触
  阴影。
- 左内折从左侧纸面向右侧页沟渐隐；右内折为正确镜像。
- 不得闭合成拥有四条完整边的纸条，不得有独立上边、下毛边、撕裂底边、
  外侧页叠或矩形填充。
- 中段允许纵向平铺；顶部、底部和横向宽度不可拉伸。

#### 横向针脚站

- 只是一段短小、中央略拱的横向粗麻线，左右端渐暗、渐细并伸入透明。
- 不能有深色圆头、独立绳结、孔环、皮革底板、矩形阴影或纵向绳段。
- 它必须在内折遮罩下隐藏两端，但中央仍可清楚辨认为横向针脚。
- runtime 通过离散放置重复；不得拉伸或纵向无缝平铺。

#### 顶部与底部收口

- 各自是一枚紧凑、不规则、略向页沟内凹的半藏麻线结。
- 两者使用相同线材尺度但不能机械复制。
- 外接宽度只略大于页沟，不得形成 U 形、横向把手、桥、横梁、杆件、
  蝴蝶结或两端带球的轮廓。
- 不允许拉伸、平铺或重复。

### 固定层序

1. 已接受的 `QL-A1` 封皮与外围页叠。
2. `GUTTER.UNDERLAY`、离散 `GUTTER.STITCH`、`GUTTER.TOP`、

3. 左右顶层纸页。
4. `GUTTER.LEFT_FOLD`、`GUTTER.RIGHT_FOLD`，只遮住针脚端部。
5. runtime 文字与控件。
