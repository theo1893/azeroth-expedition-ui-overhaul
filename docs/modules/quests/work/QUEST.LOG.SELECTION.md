## 当前批次边界

QL-B2 只处理当前被选中的一条真实任务目录行。它不生成完整任务行、不创建
新 Button，也不承担地区展开、追踪勾选、类型、计时、完成／失败、滚动条、
Collapse All、操作按钮、奖励槽或动态文字。

生成对象只有一枚 `selected` 基础书签。`selected-hover` 与
`selected-pressed` 必须在 source 被用户接受后，由同一基础像素通过固定
颜色变换和运行时 `1px` 压入偏移派生。这样最终仍有三个可寻址状态，但不会
让 ImageGen 把同一件织物重画成三种不同轮廓。

## 美术基准继承

### 权威顺序

1. Image 1 与 `ART_BASELINE.md`／`SUBMODULE_ART_BASELINES.md` 的任务卷宗
   Prompt。
2. `docs/GLOBAL_ART_BASELINE.md`。
3. `SUBMODULES.md` 的真实对象、状态、层序、几何和禁止烘焙合同。
4. Image 2 作为已接受书体的受限纸面接触参考。

### 必须继承的视觉 DNA

- 首先像香草时代 Quest Log 中的选中提示，再强化为公会卷宗里真实使用的
  短织物页签；不是把现代列表高亮染成棕红色。
- 2004 年前后二维手绘位图：粗厚、略不规则但清楚的外轮廓，少量宽阔明暗
  切面，缩至 `24 × 14 UI px` 后仍能读成织物而不是一根色条。
- 暗酒红、深胡桃与烟褐的低饱和综合色；暖光从左上方进入，亮边短促，
  阴影留在物件自身和纸面接触边，不使用纯红、紫色魔法光或金色常亮描边。
- 织物应有厚实旧布的压痕、软边和极少量磨毛，不出现照片级纤维、密集缝线、
  精密刺绣或依赖高分辨率的花纹。
- 目录纸面保持连续；书签只是从左页外缘探入当前行的短舌，不铺满整行。

### 本批组件级转译

- Image 1 下缘的暗酒红书签只提供材料身份与手绘重量。其垂直悬挂方向必须
  转译为左外右内的水平短舌，不能复制整张图中的彩色书签组合、尺寸或位置。
- 左端表现为仍继续压在纸页外缘之下的平直布端；右端是柔软、略不对称的
  短收口，不形成箭头、燕尾旗、按钮尖角或徽章。
- 书签贴着纸面、接近正面俯视，无独立金属底座、黄铜包边、铆钉、扣环、
  标签牌、文字区或悬浮投影。
- 只生成基础 `selected` 物件。hover 的暖亮与 pressed 的综合色重／
  `1px` 下压由确定性 runtime 派生，Alpha、磨损位置和轮廓保持同源。

### 明确不继承

- 不继承 Image 1 的完整书体、矩形任务卡、标题牌、指南针、黄铜外框、
  奖励区、页码、文字、彩色书签组或大蜡封。
- 不继承 Image 2 的纸页像素、封皮、书脊、装订、页沟、包角或背景。
- 不继承 QL-B1 墨箭头／墨圈的墨迹材质；只延续其在真实小尺寸下克制、
  可辨且不压过文字的视觉重量。

### 冲突审计

- 锁定图中的书签为垂直悬挂，运行时对象必须从左页外缘水平探入。裁决：
  保留暗酒红织物、厚度、磨损和综合色，不保留原方向与整组构图。
- 全局基线允许黄铜用于重要交互，但 QL-B2 没有独立命中或机械连接。裁决：
  本批完全不用黄铜，避免小尺寸下变成现代 badge／button。
- 模块基线要求真实材料厚度，而 `24 × 14px` 不能承载高频织纹。裁决：
  厚度只由宽阔明暗面、软布边和一处浅折表现，不生成细密纤维与缝线。
- 三个运行时状态必须是同一物件；ImageGen 多状态重画容易产生轮廓漂移。
  裁决：模型只生成一枚基础书签，三格由确定性导出形成。

## 组件合同

### 真实对象与状态

| 状态 | 显示条件 | 运行时表现 | 交互所有权 |
|---|---|---|---|
| unselected | 当前行绝对任务索引不等于 `GetQuestLogSelection()` | 不显示 QL-B2 Texture | 原 `QuestLogTitleN` |
| selected | 非地区任务行等于当前选择，且未 hover／press | 基础暗酒红书签 | 原 `QuestLogTitleN` |
| selected-hover | 同一 selected 行处于鼠标悬停 | 同 Alpha；确定性暖亮 | 原 `QuestLogTitleN` |
| selected-pressed | 同一 selected 行左键按下 | 同 Alpha；确定性色重，并在运行时下移 `1 UI px` | 原 `QuestLogTitleN` |

- 绝对任务索引为显示行 ID 加
  `FauxScrollFrame_GetOffset(QuestLogListScrollFrame)`。
- 选择状态只读取 `GetQuestLogSelection()`，不得解析本地化文字。API 缺失、
  无选择、选择超出可见范围、行无标题或选择指向地区 header 时隐藏覆盖。
- hover／pressed 只附加到现有 `QuestLogTitleN` Button；不得新增命中区、
  接管点击或替换原脚本。未来 adapter 必须先保留并调用原
  `OnEnter`／`OnLeave`／`OnMouseDown`／`OnMouseUp`／`OnClick`，再刷新
  QL-B2 状态。
- 任何时刻最多一条可见非 header 行拥有 QL-B2 Texture。

### 几何、层序与文字安全区

- 真实行盒保持 QL-B0 的 `224 × 15 UI px`、`14px` 纵向步进和 23 行。
- 基础书签可见 content 为 `24 × 14 UI px`。运行时 Texture 占
  `32 × 16 UI px`，在 cell 内各保留左右 `4px`、上下 `1px` 透明 padding。
- Texture 以行左侧为参照，`x=-12 UI px`、selected／hover 的 `y=0`；
  因此可见布片约落在行局部 `x=-8..15`，不得越过 `x=15`。动态任务文字
  从 `x>=18` 的安全区开始，右侧 QL-B1 追踪墨圈与未来 QL-B3 状态区不受影响。
- 层序：QL-A2 `QUEST.LOG.SHELL` → QL-B2 `BORDER` 覆盖 →
  QL-B1／B3 状态 Texture 与任务 FontString。书签无鼠标，只由原行 Button
  驱动。
- selected-pressed 只把同一 Texture 的锚点改为 `y=-1 UI px`；不缩放、
  不旋转、不形变，也不改变命中几何。

### source、Alpha 与确定性状态导出

- ImageGen 只生成一张 `1024 × 1024` 单物件源图。书签全部可见像素必须
  位于画布中心 `384 × 224px` 安全盒内，目标可见占用约
  `352 × 204px`，长宽关系接近最终 `24:14`。
- 生成背景要求全画布均匀 `#00FF00`，物件不得含绿色。若执行器返回不同的
  正方形原生尺寸，只允许整幅无裁切等比归一化至 `1024²`；随后用固定
  色键脚本生成真 Alpha，不能手工重画边缘。
- source 被用户接受后，确定性 exporter 才可把可见 bbox 等比缩放并居中到
  `24 × 14` content box，写入一个 `128 × 16`、四个 `32 × 16` cell 的
  RGBA TGA：
  1. selected；
  2. selected-hover；
  3. selected-pressed；
  4. 全透明保留格。
- 三格 Alpha 必须逐像素相同。hover 只对非透明 RGB 使用固定暖亮变换：
  `R=min(255, round(R*1.07+2))`、
  `G=min(255, round(G*1.04+1))`、
  `B=round(B*0.96)`；pressed 只使用固定压暗：
  `R=round(R*0.82)`、`G=round(G*0.80)`、
  `B=round(B*0.78)`。pressed 的 `1px` 位移只在 adapter 锚点实现。
- 不拉伸、不平铺、不镜像、不添加九宫格；Atlas cell 间必须有透明隔离，
  全透明像素 RGB 清零，避免旧客户端线性过滤渗色。

### 禁止烘焙、预演与回退

- 禁止烘焙任务名、等级、地区名、数量、选中任务文字色、任务卡片、整行
  背景、墨箭头、追踪墨圈、类型章、计时章、完成／失败蜡封、书页、滚动条、
  按钮、奖励槽或任何说明文字。
- 每次 generate／edit 后必须确定性生成三张独立的
  `676 × 464`／100% runtime 真实排版预演：selected、selected-hover、
  selected-pressed。三张都使用同一条代表性中文任务作为当前选择，保留
  QL-A2 最新 shell、QL-B1 当前 runtime atlas、全部 23 个真实行槽、
  代表性地区／任务／等级／追踪状态和右页现实信息密度；每张只出现一个
  书签。未完成 QL-C／D 使用当前原生 fallback；无法取得的简化占位必须在
  work／manifest 标为非权威。
- 另生成一张透明单物件 contact preview 只用于检查边缘；它不能代替三张
  真实排版预演。
- source、runtime 媒体或 API 任一不可用时隐藏 QL-B2 覆盖，保留原
  Quest Log 选择、文字反馈、点击、滚动与 SavedVariables。

## 最终执行正文

使用固定 ImageGen v0.143.0 生成一张供香草时代《魔兽世界》任务日志使用的
单物件 UI sprite 源图。输出只包含一枚“当前任务选中”基础织物书签；不要
生成完整界面、书本截图、三状态展示板或多个书签。hover 与 pressed 将在
后续由同一基础像素确定性派生，本次不得分别重画。

输入图职责：

- Image 1 是最高视觉权威。只继承它体现的 2004 年前后香草魔兽二维手绘
  位图语言：粗厚而略不规则的清楚轮廓、宽阔而有限的明暗切面、左上暖光、
  低饱和暖赭／烟褐／暗酒红综合色、正式公会任务卷宗的沉重年代感，以及
  缩小后仍清楚的材料重量。Image 1 下缘的暗酒红书签只提供织物身份、
  厚度、磨损和综合色；必须把其垂直悬挂构图转译为本批要求的水平短书签。
  忽略并绝不复制完整书体、矩形任务卡、标题牌、指南针、黄铜外框、奖励区、
  页码、文字、彩色书签组或大蜡封。
- Image 2 只是已接受任务书页的次级接触参考。只继承暗酒红旧布贴近暖赭
  纸面时合适的色温、年代、磨损尺度和克制接触感。忽略并绝不复制纸页、
  封皮、书脊、装订、页沟、包角或任何背景像素。Image 2 不得覆盖 Image 1
  的视觉权威。
- 不使用其他输入图。尤其不要把目录墨箭头／墨圈 source 当作织物材料参考。

画布和唯一物件：

- 输出恰好一张 `1024 × 1024` 正方形栅格图。
- 全画布背景必须完全均匀、无纹理、无渐变、无阴影、无压缩噪点，颜色为
  纯 `#00FF00`；不要透明棋盘格或纸张底色。物件内部与抗锯齿边缘不得使用
  绿色。
- 画布上恰好一枚书签，位于正中心。它的全部可见像素只能落在中心
  `384 × 224px` 安全盒内，目标可见包围盒约 `352 × 204px`，长宽关系
  接近 `24:14`。四周留下宽阔、完全干净的绿色区域；不得触边、不得重复、
  不得出现第二件物体。
- 书签长轴严格水平，左端在外、右端向内：它将在游戏中从左页外缘向右探入
  当前任务行。观察角度是贴着纸面的正面微俯视，无明显透视缩短、无斜放、
  无悬浮和无朝向观看者的厚立面。

物理结构和轮廓：
