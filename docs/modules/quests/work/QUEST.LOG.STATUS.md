## 当前批次边界

QL-B3 只新增三类无鼠标覆盖 Texture，不接管任务行 Button、文字、选择、
追踪、滚动或 SavedVariables。三类状态可以在同一任务行同时出现，不能用
“优先级只显示一枚”的方式丢失信息。

QL-B3 不包含：

- QL-B1 的地区展开／收起和任务追踪墨记；
- QL-B2 的当前任务选择书签；
- QL-C 的 Collapse All、两套 ScrollBar、关闭和操作 Button；
- QL-D 的详情分隔、奖励槽和奖励文字；
- 外部 Quest Tracker 或 NPC Quest／Gossip。

## 美术基准继承

### 权威顺序

1. Image 1 与其在 `ART_BASELINE.md`／`SUBMODULE_ART_BASELINES.md` 中的
   Prompt provenance。
2. Quests 主模块与子模块稳定 Prompt。
3. `docs/GLOBAL_ART_BASELINE.md`。
4. `SUBMODULES.md` 的真实对象、状态、几何、层序与禁止烘焙合同。
5. Image 2 的纸张综合色、光向和材料尺度。
6. QL-B1 已接受小尺寸 runtime 视觉，仅用于离线审查线重。

### 必须继承的视觉 DNA

- 2004 年前后香草魔兽二维手绘位图，不是矢量、网页图标或现代 HUD。
- 轮廓粗厚、略不规则，内部明暗切面有限且清楚；缩至 `10px`／`12px`
  时仍先读出剪影。
- 左上方暖光、低饱和暖赭／烟褐／暗酒红／氧化暗金综合色。
- 墨迹像盖在同一批任务纸面上的公会档案压印；蜡封像 Image 1 中旧蜡材质的
  小型同年代衍生物。
- 磨损集中在凸缘和边缘，主体不堆积照片级裂纹、噪点或精细纹章。

### 本批组件级转译

- 类型章是无底座的深乌棕公会压印：四枚符号同一线重、同一视觉面积，
  通过剪影而不是文字或颜色区分。
- 计时章是同一压印家族中的单枚沙漏，信息强度与类型章相当，不做发光警报。
- 状态章使用一枚小型暗酒红旧蜡封的物理两态：完整与沿同一封印破裂；
  不把 complete／failed 简化成现代绿色勾和红色叉。

### 明确不继承

- 不继承 Image 1 的完整双页书、逐行卡片、顶部指南针横条、页脚大蜡封、
  蓝色飘带、黄铜按钮、分隔线、文字占位或整张布局。
- 不继承 Image 2 的完整书壳、页缘、中央装订、包角和全幅纸面。
- 不从 QL-B1 source 裁切、描摹或复制箭头／墨圈。

### 冲突审计

| 冲突 | 裁决 |
|---|---|
| Image 1 有大号立体黄铜徽章与页脚蜡封；QL-B3 是 `10px`／`12px` 高频行内覆盖 | 只继承年代、材料、线重和综合色；类型／计时采用无背板墨压印，状态蜡封去除飘带并极度简化 |
| 当前任务文字使用 `x=18..208`，QL-B1 追踪墨圈使用 `x=212..222`，三类新状态无空间 | 非地区行固定建立 `x=176..210` 三槽状态带，文字宽度改为 `155px`；标题行继续使用原 `190px` |
| 小图标需要清晰；原型包含大量精细纹章 | 每枚只允许一个主剪影、最多一个大负形或一条结构裂缝；禁止微型刻字和细密内部线 |
| 类型、限时与完成状态可能同时成立 | 三槽全部保留并可同时显示；不叠放、不互相替代、不改变任务文字起点 |
| `questTag` 是本地化返回值，当前离线环境未证明 Turtle WoW 的全部等值 token | 资产可按四个稳定语义生产；runtime 只对实机确认的显式等值映射显示，未知值隐藏，禁止解析任务名或做模糊字符串猜测 |
| 生成模型常把透明资产做成卡片、硬币或网格展示板 | 三段正文都明确要求单独 sprite、纯色键背景、无底座、无格线、无标签和严格对象计数 |

## 组件合同

### 真实行几何与层序

- 目标对象：`QuestLogTitle1..23`，每行 `224 × 15 UI px`，纵向步进
  `14px`。
- QL-B2 选择书签：`BORDER`，局部 `x=-8..15`。
- 非地区任务文字：左边固定 `x=18`，宽度从 `190px` 收敛为 `155px`，
  右边界 `x=173`；`x=174..175` 为安静间隔。
- `QUEST.LOG.TYPE.BADGE`：`10 × 10 UI px`，槽位
  `x=176..186`，垂直居中。
- `QUEST.LOG.TIMER.BADGE`：`10 × 10 UI px`，槽位
  `x=187..197`，垂直居中。
- `QUEST.LOG.STATE.SEAL`：`12 × 12 UI px`，槽位
  `x=198..210`，垂直居中。
- QL-B1 追踪墨圈：`10 × 10 UI px`，槽位 `x=212..222`。
- 地区 header 不显示 QL-B3，保留 `x=18` 起点和 `190px` 文字宽度。
- 层序：SHELL → QL-B2 `BORDER` → QL-B1／QL-B3 `ARTWORK` →
  任务 FontString；QL-B3 Texture 不接收鼠标。
- 任何 API、媒体或映射缺失都只隐藏对应 Texture，不移动其余槽位，
  不阻断原始任务行脚本。

### QL-B3-A — `QUEST.LOG.TYPE.BADGE`

- 逻辑对象：`4` 个，顺序固定为
  `elite`／`dungeon`／`raid`／`pvp`。
- 运行时状态：普通任务与未知 tag 无资产；四类可靠 tag 各显示一格。
- source：`1024 × 1024`，`2 × 2` 等分 atlas；每格
  `512 × 512`，格内中央安全盒 `256 × 256`。
- runtime：确定性逐格可见 bbox 裁切、等比缩放、居中到
  `16 × 16` cell 内的 `10 × 10` content；目标 atlas
  `64 × 16 RGBA TGA`。
- 四枚必须同一无底座墨压印家族；不能依靠颜色差异。

### QL-B3-B — `QUEST.LOG.TIMER.BADGE`

- 逻辑对象：`1` 个 `timed` 沙漏压印。
- source：`1024 × 1024`，物件完全落在中央 `320 × 320` 安全盒。
- runtime：可见 bbox 等比缩放、居中到 `16 × 16` cell 内的
  `10 × 10` content；目标为 `16 × 16 RGBA TGA`。
- 只在 `GetQuestTimers()` 与 `GetQuestIndexForTimer()` 同时存在且绝对
  任务索引命中时显示；不烘焙倒计时数字。

### QL-B3-C — `QUEST.LOG.STATE.SEAL`

- 逻辑对象：`2` 个，顺序固定为 `complete`／`failed`。
- source：`1024 × 1024` 左右二等分；每格 `512 × 1024`，物件落在各自
  中央 `256 × 256` 安全盒。
- 两态必须来自同一枚封印：相同外径、综合色、压纹和磨损位置；failed
  只通过物理断裂与分离表达，不改成另一枚徽章。
- runtime：逐格可见 bbox 裁切、等比缩放、居中到 `16 × 16` cell 内的
  `12 × 12` content；目标 atlas `32 × 16 RGBA TGA`。
- `isComplete == 1` 显示 complete，`isComplete == -1` 显示 failed，
  其他值隐藏。

### 三段共同技术与禁止项

- 第一次调用每段都只上传固定 SHA 的 Image 1／Image 2。
- source 使用均匀纯 `#00FF00` 色键；物件本身不得含绿色、绿色反射、
  绿色描边或落在安全盒外的阴影。
- 生成后才进行确定性归一化、色键转 Alpha、可见 bbox 裁切、等比缩放、
  居中、atlas 装配与 TGA 转换；这些操作不得重画、拉伸、旋转或补造像素。
- 禁止文字、字母、数字、任务名、等级、倒计时、勾叉字符、方形 checkbox、
  圆形硬币底座、金属铭牌、卡片底、按钮框、外发光、投射到色键背景的长阴影。
- 禁止现代扁平图标、移动应用 badge、细金线网页 icon、霓虹、玻璃、
  暗黑 3 尖刺黑铁、骷髅、恶魔角、宝石和镜面黄金。

### API、动态内容与回退

- `GetQuestLogTitle` 继续提供标题、等级、`questTag`、`isHeader`、
  `isCollapsed` 与 `isComplete`；任务名、等级和 pfUI 的现有 `level+`
  文本保持动态，不由资产替代。
- 类型映射只允许显式等值表；未实机确认的 token 不显示类型章。
- 每次刷新先通过计时 API 建立绝对 quest index 集合，再按真实滚动 offset
  绑定可见行；禁止把屏幕行号当绝对任务索引。
- QL-B3 不改变任务选中、追踪、展开、滚动、分享、放弃、退出或
  SavedVariables。
- source／runtime 缺失时隐藏对应新覆盖，保留 QL-A2／B0／B1／B2 当前
  runtime 与原生／pfUI 动态文字。

### 真实排版预演

每个 countable output 都必须生成 `676 × 464`、100% runtime 的真实排版：

- 使用当前 QL-A2 shell、QL-B1 四态和 QL-B2 三态 runtime；
- 实例化全部 `23` 行、真实地区 header、中文任务名、等级、选中行和
  追踪状态；
- 非地区行使用 `155px` 文本宽度，显示长标题截断的最坏情况；
- 分布至少覆盖 normal、四类 type、两条 timed、四条 complete、两条 failed，
  且至少一行同时显示 type＋timer＋state＋tracking 四槽；
- 未完成 QL-C／D 使用当前真实 fallback，若无法取得则明确标注为
  非权威占位；
- 预演只写入 `generated/quests/QL-B3/`，不能晋级 source。

## 最终执行正文 — QL-B3-A V1

制作一张只包含四枚《魔兽世界》60 级香草时代任务目录“类型压印”的二维
手绘 UI sprite atlas。它们是盖在旧公会任务纸面上的小型档案墨印，不是四枚
按钮、硬币、金属徽章、任务卡片或独立面板；所有任务名、等级、`Elite`、
`Dungeon`、`Raid`、`PvP` 等文字仍由游戏运行时负责，图中绝不出现任何
文字、字母或数字。

Image 1 是最高视觉权威。继承它的 2004 年前后香草魔兽二维手绘位图语言：
粗厚而略不规则的手工轮廓、有限但明确的亮面／中间面／阴影切面、左上暖光、
低饱和暖赭与烟褐综合色、真实旧墨和克制磨损。只继承年代、笔触、线重、
综合色和材料关系；忽略并绝不复制 Image 1 的完整双页书、逐行卡片、顶部
指南针横条、黄铜边框、页脚大蜡封、飘带、按钮、分隔线、文字和整体布局。

Image 2 只提供当前游戏内任务纸张的综合色、左上暖光、磨损尺度和“墨迹贴在
纸面上”的接触感。不要复制 Image 2 的书壳、纸页轮廓、页沟、装订、包角或
任何全幅背景。最终四枚压印必须是独立物件，周围只有色键背景，不能带矩形
纸片或共同展示板。

输出恰好一张 `1024 × 1024` 图。画布为严格 `2 × 2` 等分布局，每格
`512 × 512`，不要画格线、边框、标题或标签。每个格子只允许一个居中的
压印，全部可见像素必须落在该格中央 `256 × 256` 安全盒内，四周保留宽阔、
均匀、互不相连的纯绿色隔离。四枚正面平视、无透视倾斜、无落地面、无长
投影，视觉面积、外轮廓重量和墨色强度相当。

格位和物件必须严格如下：

1. 左上 `elite`：一枚紧凑的三尖冠军纹章剪影。中尖略高，两侧尖较低，
   下方只有一个粗短承托折角；它像公会书记员用旧印章盖出的精锐标记，
   不是珠宝王冠、盾牌、头盔或字母。
2. 右上 `dungeon`：一座矮而厚的圆拱石门剪影，两侧各一块粗短门柱，
   中央只有一个大而清楚的门洞负形；不是城堡全景、钥匙孔、房屋或方形
   按钮。
3. 左下 `raid`：三面紧凑的竖向行军旗组成一个整体剪影，中旗略高，
   两侧旗略低，底部共用一个粗短基座；不是人物头像、三把剑、字母或
   复杂军徽。
4. 右下 `pvp`：两把短而宽的香草魔兽式战剑交叉成清楚的 X，剑身和护手
   都必须足够粗，只有一个中央交叉负形；不是细针、骷髅、阵营徽记或
   发光武器。

四枚使用同一种深乌棕旧墨，边缘有少量暖赭干刷缺口和纸面压印形成的极短
内侧明暗，但不能生成独立纸张底色、黄铜底座、彩色填充或外发光。每枚只保留
一个主剪影，最多一个大负形；禁止微型刻字、细密纹章、颗粒噪点和缩到
`10 × 10px` 后会消失的纤细线。外缘略有手工误差，但四枚不能变成四种
