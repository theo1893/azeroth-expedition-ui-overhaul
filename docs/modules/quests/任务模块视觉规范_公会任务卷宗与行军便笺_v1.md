# 一、设计结论

任务模块由两个属于同一世界、但处于不同使用场景的实体物件组成：

1. **任务详情面板：冒险者公会任务卷宗**
   - 一本正式装订、长期保存和反复查阅的厚重双页任务簿。
   - 强调仪式感、叙事阅读、章节管理和任务档案感。

2. **任务追踪面板：行军便笺**
   - 从任务卷宗中抽出、随身携带并固定在视野边缘的一叠窄长任务纸页。
   - 强调轻量、快速扫读、临时记录和野外使用痕迹。

二者必须拥有相同的手绘笔触和材料来源，但不能被误认成同一个窗口的放大版与缩小版。

本模块的核心关系是：

> 聊天框像正在记录的战地旧书；任务详情像正式保存的公会卷宗；任务追踪像从卷宗里取出的随身便笺。

# 二、共享且不可变的视觉特征

以下项目同时约束任务详情与任务追踪：

1. **香草魔兽手绘语言**
   - 保持 2004 年前后经典魔兽 UI 的厚轮廓、手工绘制、略微夸张的体积和清晰的明暗分层。
   - 材质可以沉重，但造型不能变成照片级真实古董或现代影视道具。

2. **真实的实体材料关系**
   - 纸张、封皮、织物、蜡封和黄铜必须具有各自明确的厚度、接触阴影与磨损方式。
   - 不能用一张矩形贴图加复古花纹冒充实体书籍或便笺。

3. **统一的制作年代**
   - 纸张使用暖赭、旧象牙或灰赭色。
   - 皮革使用深胡桃棕、烟褐与暗酒红。
   - 金属只使用氧化黄铜和暗哑旧金，不使用镜面高光。
   - 织物书签使用森林绿、暗酒红和褪色蓝灰。

4. **装饰服务于物件结构**
   - 黄铜用于包角、书扣、铆钉和固定件。
   - 织物用于章节书签和当前任务标记。
   - 蜡封用于完成状态、公会档案和重要任务。
   - 羽毛笔、指南针和地图符号只作为小型身份标记。

5. **正文安全区安静**
   - 纸张纹理、污渍、折痕和边注不得进入主要文字列。
   - 主要阅读区域不使用高对比花纹、发光、浮雕或独立卡片。

6. **克制的交互反馈**
   - 悬停通过纸张变暖、局部抬起、压痕变化或书签位置变化表达。
   - 按下通过材质真实下沉和阴影收紧表达。
   - 禁止使用现代外发光、霓虹描边或大面积颜色填充。

# 三、任务详情面板：公会任务卷宗

## 3.1 物件身份

按 `L` 打开的面板必须首先被识别为一本正式展开的厚重双页任务簿，而不是两块并列羊皮纸，也不是放大的聊天框。

它应当带有公会档案、冒险者手册和长期任务记录的气质。装饰程度高于任务追踪，但低于祭坛、军械或史诗装备展示框。

## 3.2 固定结构

从外到内依次为：

1. 深胡桃棕与暗酒红厚皮封面
2. 氧化黄铜包角与少量书扣
3. 三至四层高低不齐的毛边书页
4. 左右双页主纸面
5. 从纸页内部看到的凹陷页沟、隐藏装订、压痕与页缝阴影
6. 左页任务目录
7. 右页任务正文
8. 侧边织物章节书签
9. 底部页码、翻页与操作区

不可移除的识别特征：

- 明确的左右双页关系
- 可见但位于纸页下方的中央装订结构
- 四周与底部的多层书页厚度
- 侧边而非顶部的织物章节书签
- 左页目录、右页正文的传统任务日志结构

## 3.3 比例与信息布局

- 整体宽高比目标：约 `1.40–1.50 : 1`
- 左右物理纸页：接近等宽，且属于同一本打开的书
- 左页任务目录文字安全区：约占可用阅读宽度的 40%–44%
- 右页任务详情文字安全区：约占可用阅读宽度的 56%–60%
- 中央页沟：必须可见且向下凹入，但不得宽到浪费主要阅读面积
- 外围封皮与页叠：视觉厚重，但不得侵入正文安全区

`42%／58%` 只约束 runtime 左右文字列、内边距和滚动控件占用，不能通过
拉宽右侧实体纸页实现。中央层序固定为：封皮与外围页叠 → 页沟底层与装订
线 → 左右顶层纸页 → 左右内折过渡 → runtime 文字与控件。任何皮革束带、
横梁或端帽都不能压在正文纸面上。

参考 pfUI 的 `676 × 440` 双栏布局，书本物理轴线固定为 `QuestLogFrame`
局部坐标 `x=338`。页沟、重复针脚站与上下收口必须共享这条轴线，不能根据
左右文字列宽度重新偏移。左右顶层纸页在离线重组中的可见物理宽度差不得超过
约 `1%`；如果目标客户端文字区不对称，只能调整页内留白、裁切矩形和控件
锚点，不能移动书脊。

装订针脚必须是从内折下方短暂露出的单个横向针脚站，由 runtime 沿纵向重复
放置；不得含连续纵向绳杆。针脚端点必须伸入左右内折的遮罩范围，再由更高
图层的 `GUTTER.LEFT_FOLD`／`RIGHT_FOLD` 覆盖，不能在纸面上留下两块显眼
的接头或独立底板。顶部和底部收口不参与平铺，只能在同一中心线上克制收束。

纸面采用“边缘丰富、正文安静”的纹理分布。中央至少约 `70%` 的文字安全区
只保留低频纤维、大片淡污渍和轻微综合色差；高频裂纹、压花与深色磨损集中在
不可拉伸页边、页角和内折。禁止满页均匀重复的细碎纹样。最终必须使用真实
中文任务标题、长正文、目标和奖励文字，在游戏字号下检查可读性。

左页负责：

- 地域与章节分组
- 任务名称
- 任务等级与类型标记
- 当前选择
- 完成、失败与低等级状态

原生任务日志中的 `QuestLogTitleN` 整行才是任务选择命中区。
`QuestLogTitleNCheck` 只表达“该任务已加入追踪”，不是独立的任务选择框；
美术不得为它新增伪点击区。地区标题的展开／收起箭头另由
`QUEST.LOG.REGION.TOGGLE` 表达。

右页负责：

- 任务标题
- 发布者或来源
- 任务叙述
- 任务目标
- 奖励
- 分享、追踪、放弃等操作

日志右页的 `QuestLogItemN` 只是奖励预览，不拥有“已选择奖励”状态。接受、
拒绝、继续、取消和最终完成任务，以及奖励多选一，发生在 NPC
`QuestFrame`／`GossipFrame` 流程中，必须使用 `QUEST.DIALOG.*` 独立组件，
不能为了让效果图看起来完整而把这些按钮烘焙进任务日志右页。

## 3.4 左页目录规则

- 任务按照地区或章节分组，章节标题使用粗重墨迹、短横线与小型地图符号。
- 每个任务条目可以拥有浅压印或墨线边界，但不能成为浮起的独立现代卡片。
- 当前任务由从书页外侧伸入的暗酒红织物书签指示。
- 悬停只增加轻微暖色和页边抬起，不使用黄色发光。
- 普通、连续、精英、地下城、团队与限时任务使用小型压印徽记区分。

## 3.5 右页正文规则

- 标题区允许使用克制的手抄本花饰、首字下沉位置和发布者签名。
- 叙述、目标和奖励之间使用墨线、留白与印章分区，不使用黑底卡片。
- 奖励图标像放置在任务凭证上的实物或小型图章，直接位于纸面。
- 右下角保留真实页码位置，外侧页边可容纳黄铜书签式滚动控件。

## 3.6 标签与操作

- 分类标签固定使用侧边织物或软皮书签，不复用聊天框顶部皮革频道标签。
- 关闭按钮表现为黄铜书扣。
- 上一页与下一页表现为卷起页角或厚页翻动控件。
- “追踪、共享、放弃”等按钮使用厚皮革或胡桃木底座，保留香草魔兽按钮的厚度与按压感。

## 3.7 状态表达

| 状态 | 视觉表达 |
|---|---|
| 普通任务 | 羽毛笔或普通墨印 |
| 连续任务 | 小型锁链压印 |
| 精英任务 | 旧盾牌压印 |
| 地下城任务 | 石门或拱门徽记 |
| 团队任务 | 暗红公会封印 |
| 限时任务 | 沙漏墨印与克制暗红提示 |
| 已完成 | 完整暗红蜡封、墨迹降低 |
| 失败 | 破裂蜡封或褪色划线 |
| 当前选择 | 暗酒红织物书签向外伸出 |

# 四、任务追踪面板：行军便笺

## 4.1 物件身份

任务追踪必须被识别为从卷宗中抽出的窄长便笺，而不是完整书籍、木板公告栏或现代目标列表。

它需要在主城、野外、五人副本和团队战斗中快速扫读，因此装饰集中在顶部固定件与页边，正文区域保持轻量。

## 4.2 固定结构

从后到前依次为：

1. 两至三张轻微错位的旧纸页
2. 左右不完全对称的页边和折痕
3. 可纵向延展的连续正文纸面
4. 自然破损和撕裂的底边
5. 顶部窄皮带
6. 两枚氧化黄铜铆钉
7. 小型羽毛笔与指南针识别徽记
8. 右侧折页或皮革收起拉环

不可移除的识别特征：

- 窄长、纵向的纸页轮廓
- 两至三层错位便笺
- 不存在完整厚封皮
- 不存在四周封闭金属框
- 顶部皮带固定件
- 自然撕裂的底边

## 4.3 比例与扩展

- 基准宽高比约为 `1 : 2.4`
- 运行时宽度以稳定阅读任务名称与目标为准，不追求极窄
- 中段纸面必须支持纵向平铺或九宫格扩展
- 顶部固定件与底部撕边不得被非等比拉伸
- 任务较少时缩短纸页，不在下方留下巨大空白

## 4.4 内容规则

- 多个任务共享一张连续纸面。
- 任务之间使用留白、短墨线与小型书签标记分隔。
- 禁止每个任务拥有独立背景卡片、圆角框或完整边框。
- 任务名称使用较粗的深褐墨迹。
- 目标文字略小，进度数字靠右对齐。
- 进度表现为手写或盖印的 `当前数量 / 所需数量`，不用数字胶囊。

## 4.5 状态表达

| 状态 | 视觉表达 |
|---|---|
| 未完成目标 | 小型空心墨圈 |
| 部分完成 | 墨迹进度数字 |
| 已完成目标 | 羽毛笔勾选、正文墨色降低 |
| 当前重点任务 | 页边露出一小段暗酒红织物标记 |
| 整项完成 | 标题旁增加小型暗红蜡封 |
| 限时任务 | 沙漏压印与暗红墨迹线 |
| 失败任务 | 克制暗红划线或破裂小蜡封 |
| 悬停 | 局部纸张变暖、页边轻微抬起 |
| 收起 | 保留顶部皮带、徽记与一小段卷起纸签 |

战斗中可以隐藏已完成目标并收紧行距，但不能变成黑色文字列表或透明现代 HUD。

# 五、与聊天框的差异

| 属性 | 聊天框：战地旧书 | 任务详情：公会卷宗 | 任务追踪：行军便笺 |

共享材质不等于共享轮廓。任何生成结果如果把三者画成同一块换尺寸的书本边框，都属于不合格。

# 七、字体规则

- 任务标题：经典奇幻粗衬线字体，重量高于正文，避免现代高对比奢华衬线。
- 地域章节：带旧印刷或手抄本气质的粗衬线字体。
- 任务正文：高可读性的旧印刷衬线字体，不使用难以阅读的花体。
- 任务追踪：名称使用较粗衬线，目标使用同家族较小字号。
- 数字：使用与正文协调的衬线数字，不使用等宽终端字体或现代数字徽章。

# 九、禁止项

以下任意一项出现，都视为偏离锁定方向：

- 半透明黑色或玻璃化背景
- 背景模糊与现代浮层
- 圆角卡片、胶囊按钮和网页标签页
- 扁平矢量图标、科技字体和霓虹状态色
- 《暗黑破坏神 3》式尖刺、骷髅、恶魔角、黑铁牢笼和火焰金属
- 《上古卷轴 5》式纯文字极简菜单
- 照片级写实古董书
- 任务详情缺少中央书脊或双页关系
- 任务追踪拥有完整封皮或四周封闭边框
- 每个追踪任务成为独立卡片
- 大型龙头、武器、翅膀或雕像侵占文字区域
- 通过发光代替材质状态
- 为方便切片而把所有毛边、撕边和页层拉成规则直线

# 十、验收清单

后续效果图或运行时资源必须同时通过以下检查：

- 不看文字时，任务详情仍能被识别为正式双页任务簿。
- 左右物理纸页围绕绝对中心线近 1:1 对称，针脚、页沟和上下收口没有漂移。
- 针脚端点自然消失在内折下方，不在两侧纸面形成显眼接头。
- 不看文字时，任务追踪仍能被识别为从卷宗抽出的便笺。
- 两个组件和聊天框看起来由同一批纸张、皮革与黄铜制成。
- 三个组件的轮廓和装订方式明显不同。
- 纸张区域足够安静，复杂战斗背景中仍可阅读。
- 金属没有镜面高光，装饰没有压过信息。
- 任务追踪在缩短或延长时不会破坏顶部固定件与底部撕边。
- 所有悬停、选择、完成与失败状态通过实体材料变化表达。
- 整体仍属于香草魔兽，而不是 pfUI、现代 MMO、《暗黑破坏神 3》或极简《上古卷轴》界面。
