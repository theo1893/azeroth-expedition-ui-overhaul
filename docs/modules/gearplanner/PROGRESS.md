# Gear Planner 详细进度

## 当前结论

- Gear Planner runtime `1.0-zhCN` 已随 AEUI 0.9.0 接入，阶段 P5；用户已确认
  `0.5-zhCN` 在完整重启客户端后能够打开。本轮已删除截图中的 AEUI 自建
  查询层，改为直接使用 AtlasLoot 原生查询／浏览窗口；新选装流程、方案管理
  已进入实机；同屏属性数值列能够计算。本轮实机指出统计纸文字阴影、表头压线与
  琥珀变更态过亮，运行时现已清除属性纸文字阴影、按纸上线条重排表头／首行，并收敛
  槽位描边与变化值墨色，等待复核。用户已验收 `GEAR-MAIN-V1`
  军需官折叠案板 donor；外壳、平铺皮革、标题／三铰链、顶部控件、槽位和属性纸已从
  accepted source 确定性导出为 `2 texels / UI unit` 的独立 runtime 对象，等待实机层序与物理尺度复核。
  当前环境新增或切换插件入口时，`/reload` 不足以刷新加载状态。
- 普通打开 `CharacterFrame / PaperDollFrame` 时，角色伴随栏默认保持全收起，既有
  SavedVariables 即使记录了“配”也不会自动展开；“装／属／配／双”均可重复点击收起，
  点击其他入口则原子切换。配装窗口的关闭 Button 与 Esc 只收起伴随视图，不关闭
  CharacterFrame。`/aeui gear` 在角色页内只切换“配装方案”的展开／收起；
  `/aeui gear current|stats|plan` 可直接选择角色伴随视图，`on|off|status` 提供
  局部启停与状态。宽屏“双”是独立的互斥视图，在右侧显示第三方当前装备、左侧显示
  StatCompare，不再跨角色页会话保存开启状态；进入配装方案后，由 Gear 自己同屏显示
  装备与属性，不再重复打开左侧 StatCompare。
- 角色页伴随栏按可用 Provider 显示“装／属／配”：BetterCharacterStats 保持
  中心属性，S_ItemTip 提供“当前装备”，StatCompare 提供“装备属性”，AEUI Gear
  Planner 提供“配装方案”。配装视图已由 `368×555` 单内页改为 `560×555`，两列
  19 槽位固定在左、BonusScanner“当前／配装／变化”属性对比固定在右，
  水平合同为 `984 UI`。
  独立回退仍为 `760×555`，同样同时显示两区。
- 配装槽位内容现在采用“已保存基线 + 本次打开的运行时草稿”：选入、导入当前装备、
  清空与 Alt 右键清槽只更新草稿，只有点击新增的“保存”Button 才整体写回当前方案。
  “保存 (n)”显示未保存槽位数并在草稿干净时禁用；关闭／Esc／收起“配”、切到其他
  伴随视图、切换活动方案、禁用模块或 `/reload` 都直接丢弃草稿，下次打开仍从已保存
  方案开始。普通右键不再清空，而是把槽位直接恢复到本次打开时的已保存基线；主手／
  副手按一组恢复，避免破坏双手武器约束。每次草稿改变仍走同一 `UpdateAll()` 收口。
  `/aeui gear status` 的 `draft=n` 可辅助核对当前未保存槽位数。
- 右侧现按属性显示当前装备、草稿配装与 `配装 - 当前`差值，
  正值为绿色、负值为红色、不变为破折号。方案未填槽位按空槽计算；导入当前装备后
  差值应归零。每项属性使用固定高度的独立四列行，长名称不能再挤乱后续行；
  `CHAINLIGHTNING`、武器技能、法术专精等当前 BonusScanner 可产出的键均显示中文，
  未识别键只显示“其他属性”，不再把内部英文键暴露到 UI。
- 属性区现额外固定显示主手／副手／远程武器各自的“秒伤／攻速”：优先只读
  Nampower `GetItemStats()` 的静态伤害区间与 `delay`，不可用时改扫 AEUI 自己的
  隐藏 Tooltip；秒伤按武器平均伤害除以攻速计算，不混入角色攻强、天赋、Buff 或
  当前战斗状态。没有对应武器的一侧显示破折号，变化列显示“新增／移除”；秒伤继续
  用绿／红表示数值增减，攻速只用琥珀色表示变化，不把更快或更慢预判为优劣。
- 配装槽位 Shift 左键按 AtlasLoot 原生方式，用品质色、itemID 与物品名重新拼成完整
  `|Hitem:...|h[名称]|h|r` 超链接，再贴入 WIM 或 Blizzard 聊天输入框；不采用 Turtle
  `GetItemInfo()` 第二返回值中的裸 `item:...` 字符串。聊天栏尚未打开时由原生
  `ChatFrame_OpenChat` 打开待发送文本，但不自动发送。槽位 itemID
  与当前装备相同时保持普通态；不同物品和新增装备显示明显黄铜描边、浅琥珀底色及
  “更换／新增”标签，当前已有装备而方案为空时只显示较弱“未填”态，避免空方案产生
  过强噪声。未保存槽位另加冷灰蓝描边、左缘短标和名称后的 `*`；它不覆盖琥珀底色与
  “更换／新增／未填”标签，因此“相对当前装备不同”与“相对已保存方案未保存”可同时
  识别。实际装备变化时差异态与属性列在同一次事件刷新中更新。
- Gear 视图打开时监听原生 `UNIT_INVENTORY_CHANGED`；玩家实际更换装备后只重算当前列与
  差值，不写真实装备、不开维护循环。
- 点击 Gear 槽位后会记录当前配装目标，直接显示 AtlasLoot 原生窗口并将焦点
  交给原生搜索框。物品名、itemID、Boss／副本、匹配选项、清除、上次结果、
  SearchResult、Wishlist、分页和来源跳转不再由 AEUI 复制，全部交还 AtlasLoot。
- 选装模式只在当前 AtlasLoot 页面与目标槽位兼容的物品行右侧显示独立“+”；
  已在当前槽位的同一物品显示“已”。点击后 AtlasLoot 保持打开，Gear 槽位和
  BonusScanner 属性对比在同一次 `UpdateAll()` 中刷新；可用“结束选装”退出。
  选装期间只临时下调 Gear 自身层级，不改 AtlasLoot 的位置、尺寸或层级。
- AEUI 只在 `AtlasLoot_ShowItemsFrame` 完成后刷新自己的子 Button，不替换
  `AtlasLootItem_1..30` 的脚本。原生普通点击来源跳转、Shift 链接、Ctrl 试穿和
  Alt Wishlist 保持原样，不写 `AtlasLootCharDB`、SearchResult 或 Wishlist。
- “方案管理”窗口已提供分页列表、使用、新建、复制、重命名和删除；删除要求五秒内
  二次确认且至少保留一套方案。活动方案继续按服务器／角色保存，标题旁 `<／>`
  保留为快速循环切换；复制只复制 19 槽内容，不复制观察快照的身份标记。
- 观察页独立会话的“装／属／比／存”保持：默认只显示一个目标 Provider；净空足够
  才允许“比”；“存”在数据就绪后把目标 itemID 快照新建并激活为观察参考。完整
  Gear Planner 与方案管理窗口仍不挂入只读 Inspect 页。
- 首次打开时只读枚举 AtlasLoot 物品、槽位标记、Boss／副本、来源页和掉率；登录
  阶段不扫描全量 Tooltip。既有实机显示 AtlasLoot ready、6360 件索引和
  BonusScanner 可用。
- BonusScanner 缺失时通用属性为空，但可解析的武器攻速／秒伤仍保留；配装、方案管理、
  导入与来源 metadata 继续工作；
  AtlasLoot 缺失时点击槽位明确提示不可用，不再打开 AEUI 自建候选窗口。主配装视图使用
  `addon/AzerothExpeditionUI/Media/GearPlanner/` 下的 `GEAR-MAIN-V1` runtime，但物品图标、
  文字和状态仍由运行时绘制，也不改第三方 Provider Parent、尺寸、数据或 SavedVariables。

## 首版限制

- 不计套装阈值、附魔、随机词缀、触发／使用效果、天赋、Buff 与目标等级；武器秒伤
  只表示物品自身伤害区间／攻速，不计攻强、弹药或临时武器效果。
- 不提供职业／护甲精通自动过滤、唯一装备硬阻止、权重评分或自动 BiS。
- 搜索命中、分组、排序、物品缓存与多来源表现完全遵循当前 AtlasLoot 版本；
  AEUI 不再对其语义做二次修正。

## 回退

- `/aeui gear off` 隐藏 AEUI 的 AtlasLoot 选入子 Button／目标提示、方案管理与配装视图，
  不强制关闭用户正在使用的 AtlasLoot 原生窗口；同时恢复当前角色页会话捕获的
  S_ItemTip／StatCompare 以及当前观察会话捕获的目标／自身面板锚点与显隐；不改变
  已保存方案或其他模块。
- Character 模块禁用、对象缺失或几何不受支持时，配装方案使用 `760×555` 独立
  窗口；第三方 Provider 缺失只省略对应伴随入口。
- AtlasLoot 未加载时点击槽位提示原生浏览器不可用，不提供自建候选回退；
  BonusScanner 未加载时通用属性为空，武器行仍尝试用 Nampower／隐藏 Tooltip 解析，
  方案管理、当前装备导入、已有槽位清理与保存继续工作。
