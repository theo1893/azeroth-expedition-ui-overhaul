# Gear Planner 子模块美术基线

首版没有独立位图资产；以下只限定未来生产边界。

| ID | 当前基线 |
|---|---|
| GEAR.COMPANION.RAIL | 独立窄栏对象；未来普通／悬停／选中／禁用态分别定义，不与 CharacterFrame 外壳烘焙成一张图 |
| GEAR.INSPECT.RAIL | 与 Character 伴随栏同族但保持独立对象；“装／属／比／存”状态不得烘焙到 InspectFrame 或第三方面板 |
| GEAR.INSPECT.SAVE | 真实动态 Button；数据未就绪时由逻辑隐藏，未来美术不得把目标名、槽数或完成状态烘焙进纹理 |
| GEAR.FRAME | 伴随模式为角色页右侧独立外壳，回退模式恢复可移动窗口；两者都不与 CharacterFrame 拼接 |
| GEAR.PLAN.COMBINED | 19 槽与“属性／当前／配装／变化”对比表是同时可见的两个真实内容区；未来外壳可分区，但不得把装备名、属性名、数值或正负差值烘焙进去 |
| GEAR.SLOT | 动态 icon／品质／名称保持独立；槽位普通、悬停、按下、禁用及相对当前装备的“更换／新增／未填”差异态分别定义。当前差异态由运行时黄铜描边、浅琥珀底色和动态短标签组成，不烘焙进未来槽位纹理，也不用红绿表达优劣 |
| GEAR.PICKER | 查询框、选项、清除、上次结果、30 格物品行、分页与来源完全沿用 AtlasLoot 原生视觉；AEUI 只新增与原生 Button 分离的小型“+／已”选入 Button、动态目标文字与“结束选装”，不再生产独立查询外壳 |
| GEAR.TOTALS | 属性名称、数值和差值均为动态文字；未来只允许独立纸面／分隔装饰 |
| GEAR.SOURCES | 来源名称、件数与掉率为动态文字，不烘焙进静态资产 |

开始资产生产时必须先制作确定性几何预演，再按仓库位图流程建立当前 Prompt。
