# 双手武器战伤害与怒气公式

> 独立知识记录：不属于 Azeroth Expedition UI／overhaul 的指导文件，
> 不参与当前设计、实现、验收或发布决策。

本记录整理双手深武器战讨论中形成的计算模型，供独立查阅。
[WarriorArms.lua](../../addon/DoiteDPS/Profiles/WarriorArms.lua) 与
[Core.lua](../../addon/DoiteDPS/Core.lua) 仅作为当前实现快照参考，不构成本文档权威。

公式分为三层，使用时不得混算：

1. 技能 raw 伤害只描述武器、AP、技能系数和固定加值。
2. 攻击表、暴击、公共增伤与护甲把 raw 伤害换成期望落地伤害。
3. 怒气效率还要计入技能标价、被替换白字的怒气收入，以及时间／GCD／冷却机会成本。

讨论样例为双手长柄武器 277–423、基础速度 3.7、加速后白字周期 3.63 秒，
AP 1500、武器技能 313、命中 7%、面板暴击 40%；采用双手规范化速度 3.3、
2/2 穿刺、强化压制、2 秒猛击、3/3 精准斩杀、5/5 怒不可遏和 130 怒气上限。
这些数值只是可重复算例，不是装备或天赋硬编码。

## 符号、基础武器伤害与护甲

| 符号 | 含义 |
|---|---|
| W | 武器纸面平均伤害，即 (最小伤害 + 最大伤害) / 2 |
| AP | 当前攻击强度 |
| s | 武器物品基础速度；计算每刀 AP 伤害和白字怒气固定项时使用 |
| T | 当前加速后的实际挥砍周期；只用于时间轴与每秒换算 |
| U | 未规范化单刀伤害，W + AP × s / 14 |
| N | 双手规范化武器伤害，W + AP × 3.3 / 14 |
| A | 目标当前有效护甲 |
| Marmor | 物理伤害护甲乘数，5500 / (5500 + A) |
| Mcommon | 双手专精、姿态、易伤等对比较双方相同的公共乘数 |

样例：

~~~text
W = (277 + 423) / 2 = 350
U = 350 + 1500 × 3.7 / 14 = 746.43
N = 350 + 1500 × 3.3 / 14 = 703.57
~~~

3.63 秒只改变下一刀时间；不得用 3.63 代替物品基础速度 3.7 计算 U。
普通物理攻击在没有额外特殊规则时：

~~~text
Dfinal = Draw × Ftable × Mcommon × Marmor
护甲减伤 DR = A / (A + 5500)
~~~

撕裂、重伤等流血跳数不乘 Marmor；但首次施加能否命中仍由对应技能规则决定。

## 各输出手段的 raw 公式

| 输出手段 | raw 伤害 | 当前讨论中的怒气标价／备注 |
|---|---:|---|
| 白字 | U | 生成怒气；使用白字攻击表 |
| 致死打击 R4 | 1.30 × N | 30 |
| 猛击 R5 | 1.00 × N | 15；样例实际读条 2.00 秒 |
| 旋风斩 | 每目标 1.00 × N | 25；命中 n 个目标为 n × N |
| 压制 | N + 35 | 5；不能被躲闪，强化压制另加 50 个百分点暴击 |
| 英勇打击 | U + Bhs | 15；Bhs 为客户端当前技能等级的固定加值 |
| 顺劈斩 | 每目标 U + Bcleave | 20；讨论样例用 Bcleave = 50，必须以当前技能数据复核 |
| 斩杀 R5 | 600 + 15 × P × Rextra | 最低成本 E；当前 DoiteDPS 取 E = 15 |
| 撕裂 R7 | 147 + 0.35 × AP | 完整持续时间；7 跳、每跳 0.05 × AP |
| 重伤 3/3 | 0.60 × Dweapon | 6 秒总量；实际每跳与刷新行为须用战斗日志复核 |
| 拳击 | 0.05 × AP | 打断价值通常高于纯伤害价值 |
| 断筋 | 45 | 固定伤害；控制价值另算 |
| 精通打击 | 0.35 × U | 使用未规范化武器伤害 |
| 横扫攻击 | 复制一次既有攻击到另一目标 | 没有独立基础伤害；按被复制技能结算 |

斩杀中 P 为额外怒气转换倍率。3/3 精准斩杀的讨论值为 1.75，因此：

~~~text
Rextra = max(0, Rspent - E)
Execute = 600 + 26.25 × Rextra
~~~

斩杀没有直接 AP 或武器伤害系数；AP、武器伤害与暴击仍会通过白字怒气、
斩杀前可插入技能及攻击表间接改变斩杀阶段收益。英勇打击等级固定加值曾以
R9 的 157 举例，但 Bhs、顺劈固定加值、撕裂基础值和自定义技能系数都应从当前
客户端技能数据读取，不应写进循环代码。

## 63 级 Boss 攻击表

以下只处理 60 级角色从背后攻击 63 级 Boss、武器技能 S 在 300–315 附近的
讨论模型；百分比在公式中写成小数：

~~~text
基础未命中 m0 = max(0.05, 0.08 - 0.002 × (S - 300))
剩余未命中 m  = max(0, m0 - 面板命中)
躲闪 d        = 0.065 - 0.001 × (S - 300)
偏斜概率 q    = 0.40
偏斜倍率 g    = min(0.95, 0.65 + 0.02 × (S - 300))
~~~

令 c 为扣除 Boss 暴击压制后的有效暴击率。样例把 40% 面板暴击近似为
c = 37%。白字暴击上限、实际白字暴击和期望倍率为：

~~~text
WhiteCritCap = 1 - m - d - q
Cwhite       = min(c, WhiteCritCap)
Fwhite       = 1 - m - d - q + Cwhite + q × g
~~~

Fwhite 已把普通命中记为 1 倍、白字暴击记为 2 倍。黄字不偏斜；令 K 为黄字
暴击倍率，2/2 穿刺时 K = 2.2：

~~~text
Cyellow = min(c, 1 - m - d)
Fyellow = 1 - m - d + (K - 1) × Cyellow
~~~

强化压制不进入普通黄字公式。压制不能被躲闪，且增加 50 个百分点暴击。令
cop 为切到战斗姿态后的有效基础暴击；若前述 c 来自含 3% 狂暴姿态暴击的面板，
则样例中 cop 还应再减 3 个百分点：

~~~text
Coverpower = min(cop + 0.50, 1 - m)
Foverpower = 1 - m + (K - 1) × Coverpower
~~~

样例 S = 313、命中 7%：

~~~text
m0 = 5.4%，m = 0
d = 5.2%
q = 40%，g = 91%
WhiteCritCap = 54.8%
Fwhite = 1.282
Fyellow = 1.392
cop = 34%，Foverpower = 2.008
~~~

这解释了该配装的边界：7% 命中相对当前 5.4% 需求约溢出 1.6 个百分点；
白字仍远未达到暴击上限；武器技能同时改善躲闪和偏斜伤害。

## 技能期望伤害与怒气转换效率

先不乘护甲和双方相同的公共增伤，样例期望值为：

| 技能 | raw | 攻击表后期望 | 平均伤害／标价怒气 |
|---|---:|---:|---:|
| 压制 | 738.57 | 1483.1 | 296.6 |
| 猛击 | 703.57 | 979.4 | 65.3 |
| 最低怒气斩杀 | 600 | 835.2 | 55.7 |
| 致死打击 | 914.64 | 1273.2 | 42.4 |
| 旋风斩，单目标 | 703.57 | 979.4 | 39.2 |
| 旋风斩，n 目标 | n × 703.57 | n × 979.4 | n × 39.2 |
| 斩杀每一点额外怒气 | 26.25 | 36.54 | 36.54 |

“最低怒气斩杀的平均效率”和“额外怒气转换效率”是两个不同量。比较是否先施放
一个技能、再让斩杀吃剩余怒气时，正确基准是每一点额外怒气的 26.25 raw，
不是最低斩杀的 600 / 15。若技能与斩杀共用相同黄字攻击表，攻击表和公共乘数
可以约掉：

~~~text
压制替代 5 点额外斩杀怒气：738.57 - 5  × 26.25 = +607.32 raw
猛击替代 15 点额外斩杀怒气：703.57 - 15 × 26.25 = +309.82 raw
致死替代 30 点额外斩杀怒气：914.64 - 30 × 26.25 = +127.14 raw
旋风替代 25 点额外斩杀怒气：703.57 - 25 × 26.25 =  +47.32 raw／目标
~~~

若 40% 面板值并不包含狂暴姿态的 3%，压制期望上界才是 1509.6、每怒 301.9。
所以只看单次怒气边际，压制、猛击、致死和单目标旋风都优于把同一批怒气继续
灌入精准斩杀；这不等于无条件按该顺序施法。姿态损失、GCD、冷却漂移、白字
卡条、目标剩余时间与多目标数量仍可能反转最终选择。

## 白字怒气生成

60 级双手白字在该讨论和当前 DoiteDPS 中使用：

~~~text
Rwhite(D, s) =
    (D / 230.6) × 7.5 / 1.075
    + s × 3.5 / 2.25
~~~

D 是该次实际伤害结果所对应的伤害输入，s 仍是物品基础速度。固定速度项不会
因为暴击而翻倍。样例 U = 746.43、s = 3.7：

| 白字结果 | 不含怒不可遏的怒气 |
|---|---:|
| 普通命中 | Rwhite(U, 3.7) = 28.34 |
| 暴击 | Rwhite(2U, 3.7) = 50.93 |
| 91% 偏斜 | Rwhite(0.91U, 3.7) = 26.30 |
| 未命中／躲闪 | 0 |

5/5 怒不可遏在双手武器下按“75% 概率额外获得 2 点怒气”建模，命中机会的
期望贡献为 1.5 怒；一般化为当前等级 r 每次合格命中贡献 0.30 × r。完整攻击表
期望为：

~~~text
pnormal = 1 - m - d - q - Cwhite
planded = 1 - m - d

E[Rwhite] =
    pnormal × Rwhite(U, s)
    + Cwhite × Rwhite(2U, s)
    + q × Rwhite(gU, s)
    + planded × 0.30 × r
~~~

样例用 c = 37%、r = 5 时：

~~~text
不含怒不可遏：约 34.40 怒／刀
怒不可遏：0.948 × 1.5 = 1.42 怒／刀
合计：约 35.82 怒／刀
每秒：35.82 / 3.63 = 9.87 怒／秒
~~~

这是长期分析模型。当前 DoiteDPS 为避免依赖不完整攻击表，故意使用简化预测：

~~~text
Rdamage = (D / 230.6) × 7.5 / 1.075
Rpredict =
    Rdamage × (1 + 面板暴击率)
    + s × 3.5 / 2.25
    + 0.30 × 怒不可遏等级
~~~

它从装备读取 s、从角色伤害字段读取 D、从 BCS 读取面板暴击并四舍五入；不单独
扣除未命中、躲闪和偏斜。样例用 40% 面板暴击与 5/5 怒不可遏得到
38.87，运行时显示为约 39 怒。35.82 与 39 都是正确的各自模型结果，前者用于
长期伤害分析，后者才是当前插件防溢怒分支实际使用的预测值。

## 怒气上限、英勇打击与顺劈机会成本

130 怒气上限下，按样例的单刀分布：

- 下一刀暴击约回 52–55 怒，当前约 75–78 怒就开始存在暴击封顶风险。
- 下一刀普通命中约回 30–32 怒，当前约 98–100 怒才会封顶。
- 按完整长期均值 35.82，平均意义的软封顶线约为 94 怒。
- 按当前 DoiteDPS 预测 39，实际代码的封顶判断线为 130 - 39 = 91 怒。

“存在暴击溢怒风险”不等于应在 76 怒立即排英勇。英勇打击和顺劈斩替换下一次
正常白字，除了技能标价，还损失原本的白字伤害与怒气收入：

~~~text
Ceff(Heroic Strike) = 15 + E[Rwhite forfeited]
Ceff(Cleave)        = 20 + E[Rwhite forfeited]
~~~

若按 35.82 怒／刀估算，英勇实际资源成本约 50.82，顺劈约 55.82。令 Bhs 和
Bcleave 为当前等级固定加值，净伤害与净效率应按：

~~~text
ΔDhs =
    (U + Bhs) × Fyellow
    - U × Fwhite

DPRhs = ΔDhs / (15 + E[Rwhite])

ΔDcleave,2 =
    2 × (U + Bcleave) × Fyellow
    - U × Fwhite

DPRcleave,2 = ΔDcleave,2 / (20 + E[Rwhite])
~~~

当前 DoiteDPS 因此只在核心瞬发／猛击已经安排完、非斩杀阶段且下一刀预测会达到
真实怒气上限时排英勇；顺劈默认还要求计划技能后至少 95 怒，或同样会封顶，
并额外预留即将可用的旋风／致死怒气和横扫层数。排队后的下一次白字不再提供
上述基础怒气，资源预测必须把首个可收入白字推迟一个挥砍周期。

怒不可遏是否能由英勇／顺劈触发、顺劈两个目标是否各自触发，以及未命中副目标
如何结算，仍须用当前客户端战斗日志复核；在确认前不得把这部分期望额外加两次。

## 猛击、白字与斩杀时间轴

猛击不会在起手时重置白字；如果读条覆盖原定挥砍结束点，该次白字被推迟到猛击
完成时同时打出。定义：

~~~text
clip = max(0, SlamStart + SlamCast - SwingEnd)
严格不卡白字：SlamStart + SlamCast <= SwingEnd
最晚安全起手：SwingEnd - SlamCast
~~~

样例 T = 3.63、SlamCast = 2.00，刚打出一刀记为 t = 0，则最晚安全起手是
1.63 秒。若 t = 0 同时使用瞬发，GCD 在 1.50 秒结束，立即猛击：

~~~text
0.00  白字 + 致死／旋风
1.50  猛击起手
3.50  猛击完成
3.50  可立即斩杀
3.63  下一次白字
~~~

安全余量只有 0.13 秒。猛击读条期间先前瞬发触发的 GCD 已结束，因此猛击与斩杀
不争抢同一个“白字前末槽”；猛击完成后可以立即斩杀，再由下一刀回怒。

当前 DoiteDPS 的实际可用判定为：

~~~text
lock = max(当前 GCD 剩余, 计划中的最小锁定)
SwingRemaining - lock + SlamClipAllowance >= SlamCast
~~~

默认 SlamClipAllowance = 0.17 秒、最大 0.30 秒；每个白字周期最多一次猛击，
移动时禁止推荐。SlamCast 优先读取实际技能／Swing provider 值，读取失败时
运行时回退值不应代替样例已经确认的 2.00 秒。

最低斩杀成本记为 E，当前 E = 15。只看怒气下限：

| 白字周期内组合 | 通用门槛 | 当前门槛 |
|---|---:|---:|
| 猛击 → 斩杀 | 15 + E | 30 |
| 旋风 → 斩杀 | 25 + E | 40 |
| 致死 → 斩杀 | 30 + E | 45 |
| 旋风 → 猛击 → 斩杀 | 40 + E | 55 |
| 致死 → 猛击 → 斩杀 | 45 + E | 60 |

因此当前斩杀阶段在时间窗允许时以 60／55 怒支持“致死／旋风 → 猛击 → 最低
斩杀”；猛击不可用、已用或来不及时，以 45／40 怒回退到“致死／旋风 →
最低斩杀”。目标可信剩余时间小于约 1.25 秒时立即斩杀，不再为理论效率延后；
否则运行时默认在白字前 0.35 秒附近清空余怒，降低清怒后的真空期。

斩杀前后共享同一原则：先花怒气购买比额外斩杀转换更高效且能及时落地的技能，
再用斩杀消化剩余怒气。斩杀期不是无条件停止致死、旋风和猛击，也不是为了完整
组合错过目标死亡。

## 多目标与冷却冲突

旋风每目标伤害为 N，因此其单次怒气效率随有效目标数线性增长：

~~~text
DPRww(n) = n × N × Fyellow / 25
样例       = n × 39.2 期望伤害／怒气
~~~

两个目标起旋风的怒气效率已经高于单体猛击。横扫攻击应按“被复制技能伤害”增加
额外目标收益，而不是另造一个固定技能伤害；顺劈则必须使用上一节的替代白字净
收益，不能只算 2 × (U + Bcleave) / 20。

AoE 猛击必须给将转好的旋风留怒。若 tww 为旋风可用前的时间，简化资源条件为：

~~~text
RafterSlamAtWW =
    Rnow - 15 + 预计在 tww 前真正落地的白字怒气

允许猛击的资源条件：RafterSlamAtWW >= 25
~~~

如果已经排队顺劈，眼前这刀不产生基础白字怒气，第一笔预计收入必须顺延一刀。
同理，临近旋风时先打致死的资源条件为：

~~~text
RafterMSAtWW =
    Rnow - 30 + 预计在 tww 前真正落地的白字怒气

允许致死的资源条件：RafterMSAtWW >= 25
~~~

以下时间价值模型只用于离线比较，当前运行时没有读取目标数量。设致死已经可用，
旋风还有 c 秒可用且 0 <= c < 1.5：

~~~text
先致死造成的旋风冷却损失：
    n × N / 10 × (1.5 - c)

等待旋风造成的致死冷却损失：
    1.3 × N / 6 × (c + 1.5)
~~~

只有左侧大于右侧时，纯时间价值才支持等待旋风。忽略怒气与横扫时：

- 2 目标不会仅因该公式等待旋风。
- 3 目标约在 c < 0.24 秒时等待旋风。
- 4 目标约在 c < 0.45 秒时等待旋风。

若猛击会把还有 c 秒转好的旋风推迟，令 delta = max(0, SlamCast - c)。放弃一发
猛击的纯时间阈值为：

~~~text
n × N / 10 × delta > N
即 delta > 10 / n
~~~

把横扫复制粗略视为旋风时间价值翻倍时，阈值变为 delta > 5 / n；2 秒猛击下，
3 目标约对应 c < 0.33 秒，4 目标约对应 c < 0.75 秒。这个“翻倍”只是敏感性
分析，横扫的真实触发、层数和多目标复制规则仍以实机为准。当前 DoiteDPS 不用
这些目标数阈值，而是直接保护横扫剩余时间／层数、旋风怒气与实际 GCD。

## 属性边际公式

- 命中：只在 m > 0 时降低未命中；达到当前动态命中上限后，额外命中的直接
  PvE 伤害收益为 0。
- 武器技能：在 300–315 区间每点约使基础未命中减少 0.2 个百分点、躲闪减少
  0.1 个百分点、偏斜倍率增加 0.02。仅偏斜一项给白字期望倍率增加
  0.40 × 0.02 = 0.008／点；但躲闪减少也会减少压制触发，武器战估值必须扣除
  这部分机会成本。
- 暴击：未触及白字暴击上限时，每增加 1 个百分点白字暴击，Fwhite 增加 0.01；
  2/2 穿刺黄字的 Fyellow 增加 0.012。白字封顶后，暴击仍可作用于未封顶黄字、
  流血触发和其他 proc。
- 力量与 AP：1 力量 = 2 AP。每 1 AP 的 raw 系数为：白字／英勇／顺劈
  s / 14，样例为 0.2643；致死为 1.3 × 3.3 / 14 = 0.3064；猛击／旋风／压制
  为 3.3 / 14 = 0.2357；完整撕裂为 0.35；拳击为 0.05；斩杀直接系数为 0。
- 护甲穿透：目标剩余护甲为 A 时，小量增加 deltaP 的相对物理收益近似
  deltaD / D = deltaP / (5500 + A)。护甲越低边际越高，但有效护甲到 0 后不再
  继续增伤；流血不受该项影响。
- 急速：挥砍周期 T = s / H。未受资源和 GCD 限制时，增加 1% 急速近似增加
  1% 白字频率与白字怒气／秒；怒气封顶、技能 GCD 饱和或频繁排队英勇／顺劈后，
  实际边际会下降。
- 斩杀期属性：可写为“正常技能直接增伤 + 新增怒气 × 26.25 × 斩杀利用率”。
  AP 对斩杀的直接系数为 0，但会通过白字伤害、白字怒气和可插入技能产生间接收益。
- 重伤：暴击会触发或刷新重伤，其收益不是简单的“暴击率 × 单次总伤害”；
  覆盖、刷新吞跳和旧版本每跳实现差异必须以连续战斗日志建模。
